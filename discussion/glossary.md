## 1. 定義の土台
- 収量の対 y_t＝(y1, y2): 歩 t に二つの区画が出す収量（回路の受容器が読む量）。
- 対比の型 κ(y): 一歩の収量の対の形。
  - 排他: ちょうど一方だけが正（例 (5,0)・(0,5)）。
  - 程度: 両方が正で値が違う（例 (5,2)・(2,5)）。
  - 等量: 両方が正で等しい（例 (3,3)）。
  - 無: 両方 0。
- 向き: 大きいほうの区画（排他・程度で定まる、等量・無では定まらない）。
- 枠（ブロック）: 設計で位置と長さを固定した歩の区間。各枠に一つのラベル（収量の対）を置く。同じラベルの枠が隣り合っても融合しない（枠は値の連ではない、codex r1 #5）。
- 値の連: 同じ収量の対が続く歩の最長の区間（枠とは別の記述量。S44 の「最長の連」は枠のラベルの連で、歩数に換算するときは端の枠の長さを区別する、codex r2 #3）。
- 枠の長さと列の反復周期は別（codex r1 #4）: 枠の長さ＝一枠の歩数。反復周期＝列が同じ形で繰り返す最小の歩数（交互の列では 2 枠分。置換の列では一般に定まらない）。
- 並びの規則性: 枠のラベルの並び方。交互（向きが毎枠替わる）、置換（ラベルの多重集合を保って並べ替えた、S44 の G1）など。
- 条件 ID: 区間は「対比の型・収量の対・枠の長さ（端の枠を含む）・並び」の四つで特定する（codex r1 #3）。

## 3. 替えない語（比喩でなく、構造の名として定義済み）
- 試し（trial）、個体・系統（promise-cutout.md）、区画、受容器、運動、核。
- 出生＝回路の初期化の時点。生まれつき＝出生の時点で与えられている構造（ユニット〈例 m0〉・q0＞0 の辺〈`LC.newborn`〉・規則〈例 段22 の定位反応〉）。過去の用例を調べた範囲（README 項番23・133〜135）では、履歴で得た性質を指す用例はない。履歴で得た性質を「生まれつき」と呼ぶ用例が見つかれば、この判断を撤回して名を替える（codex r1 #6）。

## 4. 使い方
- 区間を言うときは条件 ID を添える（例: 程度の対比の区間〈(5,2)/(2,5)、15 歩×26＋10、交互〉）。総称だけで条件を特定しない。
- S44 の言い直し: G1 は程度の対比の区間の並びを交互から置換に変えた集団。受容器から運動への確かさが確認済みなのは交互のときだけ。
