## 3. 生成器（世界の予定を関数で渡す選択肢。生成器の本体は `experiments/`）

T0 以後の世界の時刻 s（＝t−800）について、区画 k∈{1,2} の収量:
`g_k(s) = clamp(round(M + A·sin(2π(s + θ_u)/P + φ_k) + σ·z_{u,k}(⌊s/L⌋)), 0, 5)`、φ_1＝0、φ_2＝π、A＝2.5。
**θ_u は世界の種子から引く 0〜P−1 の一様な整数**（r1 の R1: 位相が全窓で同じだと σ＝0 で世界が種子に依らない）。z は種子からの標準正規（塊ごと・区画ごと）。両区画とも 0 の歩は引き直さない（Q2）。
乱数と丸めは Julia の実装で決まる。段階 A は Julia だけで走らせ、Rust には写さない（既定オフで照合の場面に入らない）。

格子（案。結果を見る前に全部決め、点を結果で選ばない）:

| 軸 | 値 | 意味 |
|---|---|---|
| P 周期 | 1000、250 | 凍結の季節と同じ周期、速い周期 |
| σ 雑音・L 塊の長さ | σ＝0（L なし）／σ∈{1, 2} × L∈{1, 300} | 予測できなさと、その自己相関（σ＝0 では L が効かないので 1 点、R7） |
| M | 1.5、2.5 | 厳しさ。丸めと切り詰めがあるので、**実現した平均を報告する**（凍結の季節は区画 1 が 2.9、区画 2 が 2.1） |
| K 意味の入れ替え | なし、250、2000（T0 から数えて K 歩ごとに `cross!`） | (c) の境。250 は GREEDY の死までの遅れ 487 歩（F7）の内、2000 は外（R5） |

点の数 2 × 5 × 2 × 3 ＝ 60。格子の外の基準点: 凍結の季節・random（項番81 の設定そのまま）。KC は 0.002（F8）。

## 5. 比べ方と判定（案）

**(b) H-E3b: 行×列の表**（格子の点・法則ごとに n＝12 窓、12×12 の cell）
- 結果の量 S(i, j)＝cell(i, j) の T0＋τ の時点の身体の大きさ（構成体の数。死んでいれば 0）。τ＝2000（主）。τ＝500 と地平（9200）も報告する。
- 統計量 D＝対角の平均 − 非対角の平均。世界の厳しさ（列）と供与元の質（行）は対角と非対角に同じ回数入る。
- 帰無の分布: 行と列の対応づけを並べ替えた D（固定の種子で 10000 回）。片側の p。
- 判定: D＞0 かつ p ≤ 0.05 → **成立**。D＜0 かつ逆側の p ≤ 0.05 → **逆**。それ以外 → **検出不能**。
- 介入になっているかの条件（入力の列だけで決める、S28b）: [T0, T0＋τ) で、窓の組の収量の列が食い違う歩の割合の中央値が 0.2 未満の点は「介入にならない（判定不能）」。
- 供与元が T0＋τ より前に死んだ行は、対角が 0 で非対角が正になりうる（主張に不利な向き）。打ち切りはしない。T0＋τ で生きている ORG の数を点ごとに報告する。
- **負の対照 NC**: 行を、列と無関係な別の窓（577〜588）の ORG から取った表で、番号順の対応づけを「対角」とみなして同じ検定をする。対応に意味がないので、p ≤ 0.05 になる点は偶然の割合のはず。60 点 × 2 法則のうち 15% を超えたら構成が誤っているとみなし、(b) の結果を採らない（境の 15% は案）。

**(c) H-E3c: 窓ごとの ORG_j 対 GREEDY_j**
- 副の統計量（主に読む）: T0＋τ の身体の大きさの差の符号。寿命: 地平までにどちらかが死んだ窓での、寿命の差の符号。
- 判定（どちらも符号検定、同点は除く）: 同点でない窓が 8 未満 → 検出不能。8 以上で、両側 5% の水準で偏っていれば「上積みあり（ORG が大きい・長い）」か「上積みなし（GREEDY が大きい・長い）」、偏っていなければ検出不能。
- 点ごとに二欄: 「その点の予測と一致／不一致／判定できず」と「上積みあり／なし／検出不能」。検出不能は予測の成立に数えない（R6）。
- ORG 対 ORG-FIX、ORG-FIX 対 GREEDY も同じ形で報告（言えるのは「更新を許す総効果」「固定した回路と固定の規則の差」まで）。

**報告項目**（凍結）: 実現した収量の平均、流入が港で頭打ちになった歩数、実効の行為数、答えのあった行為の割合、取得量、費用（行為・維持）、維持した結びつきの数の列、ORG と ORG-FIX の行為の一致の割合。

## 7. 予測（凍結の候補。凍結は冒頭の条件のあと）

- PA1 (a): ORG-SIL は全点・全窓で、T0＋τ の身体が ORG 以下（等しいのは ORG も死んだ窓だけ）。
- PA2 (b): K＝なし・σ＝0 の点（4 点 × 2 法則）で、(b) が成立する点が過半（8 のうち 5 以上）。σ＝2・L＝300 の点では検出不能を予測する（ORG の多くが死ぬ、項番81 の random に近い）。
- PA3 (c、身体の大きさ): K＝なしの 20 点で、「上積みあり」は 0 点（GREEDY が大きいか、検出不能）。**外れの条件: 1 点でも上積みあり**。
- PA4 (c、K＝2000): 過半の点で「上積みあり」（項番46 F2〜F4。ただし維持費を入れる前の結果なので外れうる）。K＝250 は予測を置かない（境を探す点）。
- PA5: K＝なし・σ＝0 の点では、ORG と ORG-FIX の行為の一致の割合が 0.9 以上（学習が T0 以後ほとんど何もしていない）。
- 反証条件: G4 が通らなければ地図は作らない。NC が 15% を超えたら (b) を採らない。PA4 が外れ、K＝2000 で「上積みなし」が過半なら、この KC のもとで学習が得な領域は示されなかったと記録する。
