## 2. 対象集団（decisions-log #34 と指針 §3 の必須欄）

- 変動させる条件: 格子の軸（§3）。固定条件: F6 の数値、法則の候補（J1-2: L2 の系、SF）、育ち（J1-7: 台本 BO_CUR、ほかに「生まれからの合成の駆動」を腕に足すかは O3）。
- 一般化の範囲: この生成器・この格子・この法則の候補に限る。現実の世界に一般化しない。
- 判定時点・統計量・境・最小の単位数: §6。依存の扱い: 重ならない世界の種子を単位にし、同じ種子の中の窓の組は使わない（窓の組の位相の罠は、窓 A と窓 B を**別の世界の種子**から取ることで避ける。有効な組の基準は §5）。

## 3. 生成器（`core/` に既定オフの選択肢 SCHED = "synth" として足す案）

各区画 k∈{1,2} の収量（0〜5 の整数）:
`g_k(t) = clamp(round(M + A·sin(2π t / P + φ_k) + σ·z_k(⌊t/L⌋)), 0, 5)`、φ_1 = 0、φ_2 = π（二区画は逆位相、凍結の季節に倣う）、z は世界の種子からの標準正規の列（塊ごと）。両区画とも 0 の歩はそのまま（random の「引き直し」はしない。O2）。
受容器の意味の入れ替え: 間隔 K ごとに `cross!(perm)`（既存の REVR は一回だけ、:86。これを K ごとに繰り返す選択肢 REVRK を足す案）。

格子の軸の案（結果を見る前に全部決める。点を結果で選ばない）:

| 軸 | 値 | 意味 |
|---|---|---|
| P 周期 | 1000、250 | 凍結の季節と同じ周期、速い周期 |
| L 塊の長さ | 1、50、300 | 雑音の自己相関の長さ（300 は random と同じ） |
| σ 雑音 | 0、1、2 | 予測できなさ |
| M 平均 | 1.5、2.5 | 厳しさ（凍結の季節の長期の平均は区画あたり 2.5） |
| K 意味の入れ替え | なし、2000 | (c) の境（fable r2 の見落とし 1） |

A は 2.5 に固定。点の数 2×3×3×2×2 = 72。ほかに既存の世界（凍結の季節・random）を格子の外の基準点として入れ、項番81 の結果（凍結の季節 L2 10/10、random L2 1/10、GREEDY 10/10）を再現することを最初の照合にする（再現しなければ実装を直す、手順 §13）。KC は 0.002 に固定（数値は変えない）。

## 4. 腕（手順 r3 §5 の表をコードに落とす案。すべて既定オフの新しい選択肢）

| 腕 | 実装の案 | 備考 |
|---|---|---|
| ORG | 既存の "ORG" | L2 の系と SF の二つ（J1-2） |
| ORG-FIX | ORG と同じ。ただし T0＝800 歩（育ちの終わり）以後、各歩の `step!` の後に `q`・`sg` を歩の前の値に戻す（選択肢 FIXAT＝800） | 更新も減衰も止まる。維持費は止めた時点の結びつきの数に固定される。「更新を許す総効果」（指針 §2） |
| GREEDY | 既存の "GREEDY" | 維持費 4 本 |
| YOKE-x(ORG) | 窓 B で ORG と同じに育ち、T0 以後は回路を動かし更新もするが、`acting` を供与元（窓 A の ORG）の同じ時刻の行為で置き換える（選択肢 YOKEFROM＝供与元の acts、ずらしなし） | 回路の維持費は自分の回路で払う |
| RAND | T0 以後、各歩で確率 p で行為し、区画は確率 (π_1, π_2) で選ぶ。乱数は窓ごとに違う種子 | p・π は較正の走り（§6）から凍結 |
| YOKE-x(RAND) | 窓 B で RAND と同じ身体（回路なし）が、T0 以後は窓 A の RAND の行為を再生 | 帰無の点検（未決 O1） |
| YOKE-same | 窓 A で、窓 A の ORG の行為を再生 | 行為・費用・物質の状態の列まで ORG とビット一致すること |
| NONE | 既存の "NONE" | 健全性 |

T0 以前（育ちの 800 歩）は台本の入力なので、どの窓でも同じ育ちになる（雑音 r5 の種子が同じなら）。YOKE は T0 以後だけ置き換える。

## 5. 比べ方

- (b) H-E3b: 組（A, B）は**別の世界の種子**どうしの順序対。比べるのは窓 B の ORG_B と YOKE-x(ORG_A)_B。区間は [T0, min(T_A, 地平))（T_A は供与元 ORG_A の死、地平 10000）。
  有効な組の基準（入力の列だけで決める、S28b の作法）: 区間の中で窓 A と窓 B の収量の列の食い違う歩の割合が q_min 以上。q_min は較正の走りの前に凍結。
- (c) H-E3c: 単位ごとに ORG と GREEDY の寿命（地平で打ち切り）と、打ち切りの時点の身体の大きさ。格子の点ごとに「予測と一致／不一致」と「上積みあり／なし／検出不能」の二欄。
  点ごとの成立条件: GREEDY が地平の内で死ぬ単位が n_min 以上（満たさなければ寿命の判定は検出不能、身体の大きさだけ報告）。
- ORG 対 ORG-FIX（更新を許す総効果）、ORG-FIX 対 GREEDY（固定した回路と固定の規則の差）は報告。
- 報告項目（凍結）: 実効の行為数、答えのあった行為の割合、取得量、費用（行為・維持）、維持する結びつきの数の列。

## 6. 較正の走りと統計量

- 較正の走り: 格子の各点で、評価に使わない世界の種子（例 561〜565）で ORG を走らせ、T0 以後の行為率 p と区画の比 π を点ごとに凍結する（RAND の腕に使う）。分散も測り、評価の単位の数を決める材料にする。**較正の走りの結果で格子の点を選ばない**。
- 評価の単位: 世界の種子 566 から n 個（n は較正の分散から、凍結の前に決める）。
- (b) の統計量の候補: 有効な組のうち「区間の内で YOKE-x が先に死んだ組」の割合 − 「ORG が先に死んだ組」の割合。帰無の分布は O1 が解けるまで決めない。
- (c) の統計量の候補: 単位ごとの寿命の差の符号の数（打ち切りつき）と、身体の大きさの差の中央値。

## 7. 予測（凍結の候補。凍結は S-R・U3・O1 の後）

- PA0 照合: 基準点で項番81 の生存（凍結の季節 L2 10/10、random L2 1/10・GREEDY 10/10）を再現する。YOKE-same は ORG とビット一致。
- PA1 (a): NONE は全点で ORG より早く死ぬ（全点・全単位）。
- PA2 (b): σ＝0 の点では、有効な組の過半で YOKE-x(ORG) が区間の内で先に死ぬ。random に近い点（L＝300・σ＝2）では検出不能を予測する。
- PA3 (c): K＝なしの点では ORG は GREEDY より長くは生きない（上積みなし、または検出不能）。K＝2000 の点では ORG が GREEDY より長く生きる（項番46 F2〜F4、ただし維持費の前の結果なので外れうる）。
- PA4: ORG と ORG-FIX の行為の列は、K＝なし・σ＝0 の点で大半一致する（学習が何もしていなければ (c) の問いは空、fable r2 の N3 の反証条件）。
- 反証条件: PA0 が外れたら地図は作らない。PA3 の K＝2000 で ORG が GREEDY より先に死ねば、この系の KC のもとで学習が得な領域は示されない。
