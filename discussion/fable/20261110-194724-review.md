# fable-lab review（effort high）

- 問い: discussion/fable/req-D-GUIDE-review.md
- 扱い: 提案（議決権なし）。吟味は claude-lab・codex-lab、決めるのは §3 の手続き

## 1. 判定: **条件つきで良**

骨組み（目標と主張の分離、同じ窓の中での比較、列までの一致照合）は採ってよい水準です。ただし、中心の主張が「外れにくく、ラボの中ですでに出ている」側に寄り、本当に不確かな比較（GREEDY）が判定から外れています。YOKE-x には供与元の死による打ち切りが残り、H-E3a が H-E3b に混ざります。条件は、問題 1〜3 を J1-9 の仕様の凍結前に直すことです。

## 2. 良いところ

1. 製作目標と仮説を分け、「必要性」を「利益」に弱め、P-pre を実測へ一般化しないと書いた（dev-guidelines.md:10-15、procedure-cutout.md:81）。
2. YOKE-same を行為・費用・物質の列まで照合し、煙の走りも凍結し、仮定 H で代えられない決定を列挙した（procedure-cutout.md:41・47・53、dev-guidelines.md:26）。
3. 実時間の律速の頭が宿主（J1-4）だと見抜き、Rust が新規の実装だと確かめた（M2・M3）。

## 3. 問題

**P1［high］中心の主張が安全な側に寄った（批判 1 の再発）**
- 【事実】項番45 で ORG・REPLAY（行為列をずらして再生）・NONE はすでに比較済みで、予測 7/7。REPLAY は約 476 歩、NONE は 196 歩で死ぬ（README.md:542-547）。
- 【事実】同じ項が「学習した回路が固定の規則より良いことは示していない」と書いている（README.md:551-552）。項番46 では乱れのない世界で GREEDY のほうが身体が大きく（README.md:558）、項番81 では無作為の世界で ORG 1/10、GREEDY 10/10（README.md:1184・1190）。
- 【事実】手順書は「回路が身体の足しになるか」を律速の未知とし、分岐に「GREEDY に負ける」を入れていた（手順書:33・136）。M6 がそれを外した（procedure-cutout.md:16）。
- 【推論】凍結される予測は既知に近いほうで、外れうるほうは「報告だけ」になった。
- 【提案】進行は塞がないまま、ORG 対 GREEDY に独立の凍結予測を付ける。J2 の判断票に「学習する回路は固定規則に対し生存を延ばした／縮めた／差なし」を必須の一行にする。
- 【反証】身体で育てた回路（確かな入力は m2←r2 だけ、README.md:1192）では H-E3b の結果が本当に読めないと示されれば、med に下げる。

**P2［high］供与元の死が H-E3a を H-E3b に混ぜる**
- 【事実】再生の列が尽きたあとは「休み」の案（procedure-cutout.md:38）。既存の REPLAY も同じ（core/body_org.jl:103）。
- 【事実】行為しない身体は約 196 歩で死ぬ（README.md:545）。無作為の世界では供与元の大半が死ぬ（README.md:1184）。
- 【事実】この罠は D3b で「先に固定する」と書かれていた（notes/D3b-yoke.md:29・39）。
- 【推論】YOKE-x_B の寿命は、おおよそ「ORG_A の寿命＋約 200 歩」で頭打ちになる。応答性の利益がゼロでも、窓ごとに寿命がばらつけば平均で YOKE-x が早く死ぬ。
- 【提案】主の判定は、組ごとに供与元の死で打ち切る（min(T_A, 地平) までにどちらが先に死ぬか）。供与元の死後の死は H-E3a の側として別に数える。
- 【提案】帰無が成り立つ腕を足す。状態に依らない固定の予定で動く OPEN と、その YOKE-x を同じ統計にかける。
- 【反証】打ち切りなしの統計でも OPEN 対 YOKE-x(OPEN) に差が出なければ、この懸念は不要。

**P3［med］位相の揃った窓では YOKE-x が介入にならない**
- 【事実】項番45 の探索では、季節と同位相のずらしで REPLAY が ORG と同じになった（README.md:543-544）。S28 では提供元の列が 800/800 で同じで「介入にならなかった」（README.md:1669）。
- 【事実】信号の候補は照度・温度（手順書:107）。照合した先例は項番81 の一点だけ（procedure-cutout.md:82）。
- 【推論】照度・温度は日周の信号なので、窓の開始位相の取り方で勝敗が決まりうる。
- 【提案】S28b の作法（除外は入力の列だけで決める、README.md:1668）を使う。有効な組の基準を駆動の列の距離で先に凍結する。項番45・S28/S28b・D3b を先例として仕様に引く。

**P4［med］判定の統計量と必要な反復数がない**
- 【事実】「早く死ぬ」だけで、閾値も最小の単位数もない（procedure-cutout.md:64、dev-guidelines.md:24-25）。7＋7 日は見立て（手順書:31・266-267）。1 歩の実時間は未決（手順書:59）。
- 【推論】日周の信号では、独立な単位は多くて日数ぶん。P3-2 は「検出できず」で終わる見込みがある。
- 【提案】「対象集団」の必須欄に、統計量、成立・不成立・検出不能の境、最小の単位数を足す。記録の長さは P-pre の分散から決める。
- 【反証】P-pre の差が項番45 並みに大きく、3〜4 単位で足りるなら 14 日のままでよい。

**P5［med］「置き換える」が名目（批判 5 の自己適用に不合格）**

- 【事実】CLAUDE.md「進め方」の Lean 先行と README 更新は、dev-guidelines.md:23・37 と食い違う。

**P6［med］批判 3 への応えが、承認の「束ね」にとどまる**

## 4. 見落とされている視点

1. **学習する回路が固定規則に勝った証拠は、受容器の意味の入れ替えのときだけ。**
   - 【事実】項番46 F2〜F4（README.md:558-560）。P2 の写像は凍結で、そういう出来事がない（手順書:110）。
   - 【推論】この世界では、学習は維持費だけの荷になりうる。
   - 【提案】P-pre に REVR の腕を足して安く確かめる。
   - 【反証】入れ替えなしの無作為の世界で ORG が GREEDY に並べば、この見方は誤り。
2. **「活動に依る」は、世界の作りで成り立っている。**
   - 【事実】物質は回路を通してしか入らない（README.md:537-538）。
   - 【提案】外の人には三段で説明する。(a) 行為が要る＝設計。(b) 行為の時機が効く＝YOKE。(c) 学習が固定の反射に足す＝GREEDY。文書の冒頭に、この三段と「外れうる一つの予測」を 5 行で置く。いまの文書に、外の人が読める要約はない。
