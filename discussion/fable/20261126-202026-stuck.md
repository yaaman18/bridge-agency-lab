## 1. 見立て（なぜ進まないか）
- **確かめた**: ユーザーの定義は「二つの時点のあいだで…どれだけ変わったか」（`memory-time-openness.md:49`）で、端点で決まる二点関数。順序は痕跡の包含（:50）、時間は網（:54）、目印は個体ごと（:58, :62）。
- **確かめた**: 要件は「時計と独立に場が指定する区間」で進みを数え、率を比べる（`requirements.md:160, 166`）。
- **推論（形のずれ）**: これは変化点検出器の診断精度試験の形。2 値化するので閾値が要り、場の札を正解にするので「個体固有の原点」と食い違う。閾値いじりは定義でなく要件の形から来ている。§5 は検出器を捨てても札との照合が残る。
- **推論（§5 の滑り）**: 一歩の変化の和は経路の長さで、端点の差ではない。Y が確率的なら定常でも予測は約 |y−p|/(rn+α) ずつ揺れ、和は外の歩数に比例して伸びる。S83 の「1/30」はゼロでなく率の比で、ルーティンでも一定に進む。
- **推論（§5 の滑り）**: rn は鍵の珍しさ（入力の性質）で、変化量そのものではない。また λ は α を通じて p を rate へ寄せるので、「ふるまいの変化」にも外の歩数が漏れる。

## 2. 別の見方

**案1: 由来の分け前（反事実の双子の閉形式）**
- 定義: L-FGT の表は入力に線形なので、p_t(k) = Σ_s w_s(t)·y_s + w_0(t)·rate、w_s(t) = λ^{t−s}/(n_k(t)+α) と書ける。w_s(t) は「出来事 s を抜いた双子との差」の係数。
- 順序: s ≺ t ⇔ w_s(t) > 0。出来事の内側の古さは −log w_s(t)。
- 二点間の時間: R(t1,t2) = 1 −（t1 以前の出来事の分け前の合計）。端点で決まり、[0,1]、t2 について単調。
- 法則から導ける（推論、要証明）: 再訪がなく n ≫ α の間、分け前は外の歩数で減らない（年輪の欠落）。減るのは同じ鍵の再訪による希釈と、n が α 付近まで落ちて事前が取って代わる忘却だけ。距離が「つながり方」で決まる。
- 残る数: 鍵をまたぐ集約の重み（一様に固定するのが筋）。
- 確かめ方: 1 生で、閉形式の値と実際に 1 例抜いた双子の走行を照合する（法則の値との一致。閾値なし）。
- 反証条件: 照合が合わない。または定常区間で R が外の歩数にほぼ比例する。
- 弱点: 驚きのない入れ替わり（同じ値の新しい例が古い例を置き換える）でも R は進む。「技能は残り断片は残さない」は、表が一つの L-FGT では分けられない。これは時計でなく学習器の構造の不足。

**案2: 端点の差 N と経路の長さ P を両方持つ**
- 定義: N(t1,t2) = Σ_k |p_k(t2) − p_k(t1)|、P = 一歩ごとの変化の和。
- 分け方: 切替は弾道的（N ≈ P）、定常の揺れは拡散的（N ∝ √P）、行って戻るは N → 0。2 値にせず曲線で報告する。再読で過去が近づく（N が縮む）ことも表せる。
- 残る数: 距離の尺度（L1 かロジット差か）を一度だけ議論で決める。
- 確かめ方: 既存の 48 生で、切替直前を原点に N(T_i⁻, t) と P を全 t で出す。窓は要らない。
- 反証条件: 通常区間でも N/P が形成区間と同程度。または形成区間で N が戻る（つなぎ目との差が出ない）。
- 弱点: N は向きを持たないので、順序は案1 で補う。

**案3: 足踏み不変（理論草稿の余代数の読み）**
- 定義: 刻み ⇔ 状態が観測上の同値類（以後のあらゆる入力に同じふるまい）を出ること。同値類を変えない歩は時間に数えない。
- 要件の形: 「場の札と一致」ではなく、(a) 固定の表は恒等的に 0、(b) 足踏みの歩を挿入しても時計が不変、(c) 同じ場で履歴の違う二個体は目印の並びが違う。どれも閾値なしの負の対照になる。
- L-FGT での厳密なゼロ: 切り詰め [1/200, 199/200] に張り付いた鍵では、1 例足しても予測がビット単位で同じ。法則の数だけで決まる「輪のできない歩」。
- 確かめ方: 切り詰めで変化が厳密に 0 の歩の割合を、形成・通常・つなぎ目で数える。
- 反証条件: 厳密なゼロがほぼ無い（λ が毎歩 n を動かすので、L-FGT では全歩が刻みになる）。その場合、ルーティンは観測の粗さ（行為か予測か、採点の 8 例）に相対的にしか存在せず、粗さの選択が唯一の定義上の選択になる。

## 3. いちばん安く試せる次の一手
- 案2 を既存の 48 生で 1 本走らせる。新しい数は足さない（尺度は L1 と凍結）。同じ走行で案3 の厳密ゼロの歩数も数える。
- 凍結する予測の案: 形成頭で N/P ≥ 0.5、通常区間で N/P が √(歩数) の逆数の桁、つなぎ目は中間。
- 外れたら §5 の「積算」案は採らない根拠になる。当たれば「率の比」でなく指数の違いで分けられる。

**要件の書き直し（Q3）**
- (i) 定義の恒等式（閉形式 = 双子の走行）の照合。
- (ii) 構造の性質（単調、足踏み不変、固定プログラムは 0、個体ごとの目印）。
- (iii) 場の記述（その場が新しさを出したかを場の言葉で記す。存在の合否にしない）。
- つなぎ目は (iii) の記述が誤りだったと読む。Jaeschke の 10 と 0.1 は (iii) にだけ残すか、外す。

**境界（Q4）**
- 判定の問い: 「その数は、生を一つも走らせる前に、法則と定義だけから書けるか」。
- 書ける → 決定論の側: 法則の数、観測写像と尺度、恒等式、雑音の床（定常な鍵の期待変化 ≈ 2q(1−q)/(n+α)）。
- 書けない → 時計の数。廃止する。
- 統計は「世界が何をどの頻度で出すか」（種子をまたぐ主張）だけに使う。
