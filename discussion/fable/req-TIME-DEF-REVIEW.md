## 2. ユーザーが置いた定義（正本はラボの文書）
- `discussion/notes/memory-time-openness.md` §6（47〜63 行）:
  - 時間はタイムスタンプではない。存在にとっての時間は、二つの時点のあいだで自分がどれだけ変わったかで測る。
  - 記憶がなければ前と後の区別はない。順序は「後の状態が前の痕跡を含む」ことで生まれ、内側の時間の向きは痕跡の積み重なりの向き。
  - 年輪は記憶と時間を兼ねる（干ばつの年には輪ができない）。固定のプログラムには、タイムスタンプはあっても自分の時間がない。
  - 二つの時間: 世界の時間（環境の変化の速さ）と存在の時間（記憶が作る）。開かれ＝世界の時間が存在の時間に書き込まれ続けること。
  - 存在の時間は一本の直線ではなく、つながり方で距離が決まる網（再読は過去をいまの近くへ引き寄せる）。
  - ルーティン: 内側の時計が進まないどころか、記憶自体がなかったことになる。技能としてモデルの形に残る（「知っている」が「覚えていない」）。断片は重みを下げるのではなく残さない。
  - 固有の出来事が起点: 重みは時間軸に沿って滑らかに配られず、個体固有の出来事を原点に決まる。目印の並びは個体ごとに違う。
- `discussion/glossary.md` §7（61 行〜）: 記憶の痕跡＝個体の過去の入力と行為が、法則を通して状態に残した差で、後のふるまいを変えるもの。法則が読まない記録は記憶ではない。忘却＝痕跡の差が消えること。痕跡は維持費を払う。
- `~/bridge-protocol/docs/claudeの提示する時間概念.md`（理論側の草稿、読むだけ）: 時間は作動-感受の随伴の反復から内生する。前へ進み、過去は非自明になる（余代数的）。現在は到達できない極限。Lean での形式化はまだない。

## 3. 要件 R-AUE-TRACE-1 r5（`discussion/requirements.md` 159〜178 行）
- 内側の時計（派生量。算式は観測前に凍結）は、時計と独立に場が指定する「痕跡形成区間」で下限以上進み、同じ外の歩数の「ルーティン区間」で上限以下しか進まない。ルーティン区間からは断片を残さない。
- 判定: 形成区間の進み率 d、通常区間の進み率 f に片側 97.5% Clopper–Pearson。成立 d_LB ≥ 10·f_UB かつ 1 − d_LB ≤ 0.1(1 − f_UB)。10 と 0.1 は Jaeschke 1994 の慣例の借用で、導いた値ではない。

## 4. これまでやったこと（事実）
- 場: 1 生 ≈ 5〜6.5 万例。受容器の写像の切替（全反転＋置換）を T_i = 8000・20000・32000・44000 に入れる。12〜14 種子の世界をつなぐので種子のつなぎ目もある。
- 主の学習器 L-FGT: 6 ビット＋行為を鍵に Y = 1 を数える表。λ = 1 − 1/2000 で減衰、予測 (n1 + α·rate)/(n + α)、α = 1、[1/200, 199/200] で切り詰め、8 例ずつ前向き採点。
- 時計の候補 C0〜C5・Page–Hinkley・O-win: どれも「予測の外れ（Y の損失）の増え」を見る検出器。h = 13.75（格子 1〜60 刻み 0.25 から既見 8 生で選択）、δ = 0.01、θ = 0.03、窓 500、O-win θ = 0.0075、区間長 L（500〜3000）などを、データを見て選んできた（S75〜S82）。
- 切替の選び方も、学習器自身の探りで測った効き d_i ≥ 3ε（ε = 0.0025）で選ぶ。学習器から独立でない（codex が S72 で指摘）。
- S83（前回の Fable 案の記述）: 予測時の鍵の経験数 rn を、形成頭 [T+1, T+200]・通常区間・種子のつなぎ目頭で比べた（既見 48 生）。
  - 形成頭の rn は通常の約 1/30（中央値比 0.0325、48/48 生で ≤ 0.1）。的中。
  - つなぎ目頭でも rn は落ちる（中央値比 0.362、48 生中 32 生で 0.5 未満）。「つなぎ目は通常並み」の予測は外れ。
  - 200 例の w̄ = α/(rn+α) の平均: 形成頭 中央値 0.152（最小 0.067）、通常 0.006（最大 0.097）。形成頭 183 件のうち 9 件が通常の最大以下。

## 5. claude-lab の見立て（ユーザーに返した答え。これと「別の観点」がほしい）
- C0〜C5 は「外れの増えの検出器」で、「自分がどれだけ変わったか」を測っていない。検出器だから閾値が要り、閾値はデータで選ぶしかなく、合否が当てはめになった。要件の「派生量（算式は凍結）」が算式を自由にしていたのも一因。
- L-FGT は決定論なので、一歩の予測の動きは法則からおよそ 1/(rn+α) に決まる。S83 の 1/30 は調整でなく法則と場の作りの帰結。
- この定義では、つなぎ目で rn が落ちるのは誤作動ではない（新しい世界で実際に変わった）。場の「ルーティン」の札のほうが定義と食い違う。
- 数を三種に分けた: 法則の数（λ・α・切り詰め。個体の一部で、試験に合わせて動かさない）／時計の数（h・δ・θ・窓。定義し直せば消える）／世界の偶然（種子。統計はここだけ）。
- 注意: λ は毎歩状態全体を一様に縮めるので、「状態の変化」を数えると外の歩数で一定に進む時計になる。だから測るのは「ふるまい（予測）の変化」にする。
- 提案: 刻み＝「法則による一歩の、ふるまいの変化の量」を定義として先に書き（尺度は議論で一度だけ決める）、L-FGT について不等式を導き、試験を「場が新しさを出したかの記述」と「時計の値が法則の値と一致するかの照合」に分ける。閾値を選ぶ系の作業は止める。

- (Q1) §5 の見立て（「ふるまいの変化の量」の積算）の弱点・定義の滑り。とくに: 一歩の変化の和は「どれだけ変わったか」と同じか（行って戻る変化、減衰で消える変化、二時点間の差と経路の長さの違い）。ルーティン（技能は重みに残るが断片は残さない）を、この定義で区別できるか。
- (Q2) §5 とは**別の観点**からの定義の候補を最大 3 つ。たとえば（これに限らない）:
