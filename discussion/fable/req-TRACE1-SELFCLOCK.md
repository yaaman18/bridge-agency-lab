# TRACE1-SELFCLOCK 内側の時計（R-AUE-TRACE-1）が、個体自身の量で満たせない

- 依頼: ユーザー（2026-11-25）「Fable に現状の問題点と突破口を聞きたい」。user 確認の枠で、API クレジットで 1 回（`fable-turn.sh stuck … --api`）。
- この文書だけで読めるように、要点と数をここに写した。ツールで原文を読むのは、必要なときに限ってほしい（費用のため）。
- 答えてほしいこと（§7）: (Q1) 問題の本当の所在（問いの立て方・定義の滑り・隠れた前提）、(Q2) 突破口の候補と、いちばん安い確かめ方、(Q3) 「突破口はない」が正しい答えなら、その論拠と、TRACE-1 の読みをどう収めるか。

## 1. 問い（一文）
個体が自分で計算できる量だけで作った「内側の時計」は、この場で、痕跡形成区間（受容器の付け替えの直後）では進み、ルーティン区間では進まない、という TRACE-1 を満たせるか。満たせないなら、直すべきは時計か、場か、要件か、学習器か。

## 2. 要件（`discussion/requirements.md` 159 行〜、ラボの要件 r5。bridge-protocol の登録判定ではない）
- 命題: 内側の時計（算式は観測の前に凍結）は、時計と独立に試験の場が指定する「痕跡形成区間」（未見の構造の導入など）で事前の下限以上進み、同じ外の歩数の「ルーティン区間」で事前の上限以下しか進まない。外の歩数だけで一定に進む時計と、常にゼロの時計を退ける。
- 測り方（r5、2026-11-25 ユーザー決定）:
  - 生をまたいで、切替（形成区間）を K 件、通常区間を W 件数える。検出 X/K、誤作動 Z/W。
  - 成立: d_LB ≥ 10·f_UB かつ 1 − d_LB ≤ 0.1·(1 − f_UB)。片側 97.5% の Clopper–Pearson（LR+ ≥ 10、LR− ≤ 0.1）。
  - 不成立: d_UB < 10·f_LB または 1 − d_UB > 0.1·(1 − f_LB)。ほかは未決。
  - 区間の長さ・判定点・切替の選び方・生の数は、試験の場が決める（要件には入れない）。
  - 10 と 0.1 は、診断検査の尤度比の慣例を借りた設計基準（Jaeschke ら 1994）。要件の文から導いた値ではない。

## 3. 場と学習器（コードで確認済み）
- 観測: S57 の体（stat 族）の obs 系列。1 種子あたり約 4,650 例。12〜14 種子をつないで 1 生（N ≈ 5〜6.5 万例）。例は、引き出しに残る歩（isex）だけで、全歩ではない。
- 結果 Y: 行為した効果器の連続量 y の符号（y > 0 を 1）。連続の y は捨てている。Y = 0 はまれで、1,000 例あたり中央値 5〜9 個。
- 写像（`experiments/s72_open/s72.jl` 24〜47 行）: 学習器に見せる 8 受容器のうち 6 本の並べ替えと反転。世界・Y・行為は変えない（プリズム順応型）。
  - 切替 T_i = 8,000・20,000・32,000・44,000。毎回、前の写像に「恒等でない置換 × 6 本すべての反転」を合成する。
  - このため T + 1 から、すべての入力の見え方が変わる（どの例でも、表の鍵が必ず変わる）。
- 主の学習器 L-FGT: 6 本の受容器ビットと行為を鍵に、Y = 1 の数を数える表。数は例ごとに λ = 1 − 1/2000 で減衰する（有効な記憶は約 2,000 例）。予測は `(n1 + α·rate)/(n + α)`。8 例の区画ごとに、予測して採点してから更新する（前向きの採点）。損失 ℓ_t = −log q。
- 区間（場が指定）:
  - 形成区間 = [T + 1, T + L]。
  - 通常区間 = 各段の終わりの 3,000 例（R_i）を L で切る（L = 1,000 で 1 生 15 本）。
  - 選んだ切替: 探りの点で測った切替の効きが d_i ≥ 3ε（ε = 0.0025）のものを場が選ぶ（1 生 3〜4 本）。

## 4. 時計（凍結した候補）
- C4（主、個体の量）: Page–Hinkley。μ_t = ℓ の指数平均（係数 1/3,000、ℓ_t の前の値）。c_t = ℓ_t − μ_t − δ（δ = 0.01）。m += c_t、M = min(M, m)。判定点（50 例ごと）で m − M > h なら進み、m = M = 0 に戻す。h = 13.75（既見 8 生で crit2 により選んだ値）。
- C0（副、個体の量）: 窓 500 の損失の平均 − 基準の平均（θ = 0.03）。
- O-win（参照の観測者。時計の候補ではない）: 写像を知る双子 Lc（同じ例・同じ Y で、入力の写像を π₀ に固定した L-FGT）との損失の差 u_t = ℓ_t(P) − ℓ_t(Pc) の、窓 500 の平均 > 0.0075。
- S75 で試したほかの自分の量（いずれも及ばず）: C1 長い窓、C2 ばらつきで割る、C3 自分の予測のエントロピーとの差 ℓ − H(p)、C5 遅い写し（λ = 1 − 1/20,000）との logit の食い違い。

## 5. 経緯と結果（要点）
- S72〜S79（開発、4〜8 生）: 自分の量の時計は、どれも 4 生すべては通らなかった。最多は C4 の 2/4。S79 で、合否を r5 の率の判定に改めた（生ごとの全検出の運用をやめた）。
- S80 診断（既見 8 生）:
  - C4 の誤作動は、種子のつなぎ目ではなく、Y = 0 の塊に出る。
  - Y = 0 の数だけで作った時計は、ほとんど分けられない（誤作動 117/120）。「C4 ≈ Y = 0 の数え上げ」は否定された。
  - Y = 0 の数をそろえても、Y = 0 の例 1 つあたりの C4 の寄与は、8 生すべてで形成区間のほうが大きい（p = 0.0039）。
- S80 本走り（新しい 40 生、予測凍結。ただし生の長さの関門で一度止まり、N を見た後に全生へ同数の種子を足す改訂 1 が入った）:

  - O-win: 149/153、0/600 → 成立。C0: 不成立。予測 V1〜V6 はすべて的中。
- S81（既見 48 生で、C4 と O-win を切替ごとに対にした）:
  - 切替 183 = 両方 125、O だけ 54、C4 だけ 0、どちらも 4（Y = 0 がほぼない）。

  - Y = 0 が 18 個あっても C4 が届かない例が 1 本（s80 生 35）（数の不足だけでは説明しきれない）。

## 6. 二人（三者）の見立てと、その最強の論拠
- claude-lab: 証拠は Y = 0 の例でしか損失に出ない。自分の量では、通常区間の Y = 0 の単発の外れと、切替後の外れを、少ない例では区別できない。O は双子との比で通常の証拠を 0 にできるから届く。突破には、通常区間の外れを打ち消す自分の基準が要る。ただし、その形の候補（遅い写しとの損失比など）は、写しも新しい写像を学ぶので効くか分からない。
- codex-lab:
  - 「−20 の漂いが原因」「単発 5.27 が原因」は、照合なしには言えない。
  - 例の数を情報量に替える要件の書き直しには、必然性がない。
  - 案 A は凍結規則で退けたが、h を選び直せば別の結果になりうる。
  - 時計探しは保留が筋。
- ユーザー: 遅い写しとの比較や、理論上限の計算は「エレガントでない」と感じている。
- 共通の疑い: 候補を一つずつ当てて閾値を選ぶ作業の延長で回っているのではないか。

## 7. 問い（Fable へ）
1. **問題の所在**: いまの不成立は、時計の弱さか、場の作り（Y の二値化、まれな Y = 0、全反転の写像、表の学習器の減衰）か、要件の測り方（例の数で切る窓、LR の 10・0.1）か。隠れた前提や、定義の滑りがあれば指してほしい。特に、TRACE-1 の「痕跡形成」を、外から見た写像の切替の時刻で定義していることは妥当か。
2. **突破口**: 個体が自分で計算できる量で、通常区間の Y = 0 の外れと、切替後の外れを分ける原理的な方法はあるか。例えば、表の鍵ごとの経験の数（新しい鍵に入ったこと自体）、自分の予測の確信の分布の変化、行為と結果の結びつきの崩れ、などは候補になりうるか。いちばん安く確かめる一手を、反証条件つきで。
3. **ない場合**: 「この場の情報では、自分の量の時計は TRACE-1 に届かない」が正しいなら、その論拠（情報理論的な上限など）と、要件・場・学習器のどれを、誰の判断で変えるべきか。
4. 二人がすでに出した案（遅い写し、理論上限、接触時刻、L の延長、h の選び直し）の言い直しは要らない。枠の外の見方がほしい。
