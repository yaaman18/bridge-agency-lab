## 1. 設計の論点
- Q1 「休む」とは何か:
  (a) 新しい運動 m0（patch＝0 か 4）。行為すると、その歩の区画運動を止める（排他）。費用は MCOST より小さいか 0。
  (b) 新しい単位を作らず、「行為なし」をそのまま休みとする。足りないのは、休みが**学ばれない**（結びつきがない）ことだけ、と読む。
- Q2 休みの確かめ（学習の信号）は何か（これが中心）。区画運動は「答え＝餌」で確かめられるが、休みには答えがない:
  (i) 確かめなし: 休みは沈殿・探索（stale）だけで起き、sed_fade で消える。学ばれない。
  (ii) 体の状態で確かめる: その歩の体の損失が直前の平均より小さければ確かめ。体から回路への新しい経路（内受容）が要る（F6）。
  (iii) 世界の状態で確かめる: 両区画の y が 0 の歩に休んだら確かめ。設計者が「餌がないときは休むのが良い」を外から入れることになり、M4（目標の値を外から入れない）と衝突しうる。
- Q3 休みを引き起こす手がかり: 今の受容器では r3（y1＝0）と r4（y2＝0）の両方で θ＝2 に届く（要素の和で表せる）。内受容の受容器（体の量が少ない）を足すかは Q2 (ii) とつながる。
- Q4 世界: F4 により、今の生存の予定表では休むのが得な歩がほぼない。休みの効き目を見るには、両区画とも 0 になる期間を持つ予定表が要る（世界の側の変種、既定は変えない）。今の予定表では「休みは学ばれず、結果も変わらない」が予測になる。
- Q5 S31 との関係（claude-lab の前の説明の訂正）: 「休みが S31 の問題に直接効く」と言ったのは言い過ぎ。S31 で分けられなかったのは「価値に応じた移り」と「探索の移り」で、m* をやめること自体は今でも m* の行為の減りとして測れる（S31 は hiZ の行為だけを数えた）。休みが加えるのは「やめて何もしない」と「やめて他方へ行く」の区別で、効くかどうかは仮説。
- Q6 形式: Lean の statement（休みの一歩: 休んだ歩は区画運動が行為しない・取り込み 0・費用）を先に。既定オフで今の一歩と一致する補題。
- Q7 何を測るか（後の S 段）: (1) 既定オフで既存の走りとビット単位で一致、(2) 今の予定表で休みの頻度（予測: ほぼ 0）、(3) 欠乏の期間を持つ予定表で、休みの有無で生存・体の量を比べる。

## 4. r3 の叩き台: 定義（`notes/R-rest-def.md` §3 r2）と S32（README 項番132）に照らした見直し（claude-lab の叩き台。§5 が優先）
- ユーザー「じゃあ m0 の見直しもコーデックスと議論しながらやって」。設計の見直しで、実装・測定はしない。
- V1 定義の (i) と Rel: m0 を持つ BODY では Rel＝{m0 を候補から外す}（駆動・資源を作らない）。m0 が勝った歩でこの解除をすると、区画運動の候補があればその勝者が行為する（A3）ので A が 1 増える。区画運動の候補がない歩で m0 が勝っても A は増えない（(i) は偽、休みではなく「行為の選択が空」に近い）。定義はこの二つを分ける。
- V2 第一段の m0 は**毎歩候補になる**（規則からの帰結、未確認）: m0 の辺は確かめられないので全期間 q＝sg＝0 → m0 は常に stale → 点いた源からの辺が全部駆動 → 核 c1・c2 は毎歩点く（S32 QP1）ので core_gate を通り、total≥2 → 毎歩候補。
- V3 m0 が勝つ歩（規則からの帰結、未確認）: key(m0)＝total ≤ 10 ＜ 1000 なので、区画運動の候補に確かさか沈殿の駆動があれば（試しでは S が 31238/31360 歩で真、S32）順位では負ける。勝つのは (a) idle の優先: m0 が 100 歩より長く行為していなければ idle の pool に入り、pool の中で区画運動に idle のものがなければ m0 が勝つ、(b) 区画運動の候補に確かさも沈殿もない歩（育ちに多い: S32 の育ちでは候補が空の歩が 8.4%、stale・onset で候補になる歩も多い）。
  → 試しの第一段の休みは、ほぼ **idle の優先による周期的な休み**（約 100 歩に一歩）になる見込み。これは定義 r2 の (i)〜(iii) を満たしうる（解除で A が増える、DC と生存が保たれれば (ii)、次の歩で区画運動が勝って A が上がれば (iii)）。
- V4 定義 r2 の弱さ（問題提起）: idle の優先（探索の時計）による一歩の休みも、r2 では休みに数えられる。r2 は「内側の過程による活動の低下」を要求するだけで、その過程が系の状態（体・感覚）に応じることを要求しない。案: (α) r2 はそのまま（最小の意味の休み）、休みの区間を、それを生んだ過程で分類して報告する（idle の優先／順位で勝った／区画運動の候補なし）。(β) r2 に「低下を生んだ過程が状態に応じる」を足す（idle も lastM という系の状態に依るので、線を引く原理が要る）。claude-lab は (α) を推す（定義を強めると、何が休みかを結果を見て選ぶおそれ）。
- V5 m0 の α（D3・D4）: D-a で「休み＝α＝∅ の出力」と書いたが、ラボの α の照合の手続き（t＋1 で m を sil して受容器を比べる、S12 Q-B）では、m0 を sil すると区画運動が行為し（V1）、たまりが減って受容器が変わる。つまり**操作の上では m0 の α は空でない**（行為しないことが世界を変える）。宣言の α（`core/dc.jl:24`）に m0 をどう書くか（∅ と宣言するか、照合で実現する組を書くか）は D4 の読みに関わる。DC の (ii) を休みの区間で判定するには、この宣言が先に要る。
- V6 生まれつきか、試しから足すか: m0 を newborn から持たせると育ち（台本 800 歩）が変わり、別の個体になる（V3 (b) により育ちで m0 が勝つ歩が多い見込み）。試しの始めに足すと、育ちは同じで比べやすいが、体の途中で出力を足すことになる（BP1〈法則を替えたときの同一性〉、H1 に関わる）。claude-lab は生まれつきを推す（比べるのは同じ種子・同じ台本の別の系統として、系統の側の比較）。
- V7 第一段の意味: 第一段で分かるのは、定義の手続き（Rel・解除の分岐・DC・再開）がこの身体で働くかと、どの過程で休みが生じるかまで。「系が自分の維持のために休む」は第一段では起こりえない（m0 は学ばれず、体の状態を読まない）。第二段（確かめの信号）は bp への照会と比較の基準が要る。

## 5. r3 締め（往復1〜3、両者 accept。§4 に優先）
- 判定は窓の単位（V1 の直し）: 解除の分岐は窓の始めの写しから窓の全歩で m0 を候補から外し、窓全体の A を実際と比べる。一歩の候補の有無から窓の (i) を言わない。(iii) は確定した I の後に完全に位置する窓で。
- 休みの区間は、それを生んだ過程で分類して報告する（idle の優先／順位で勝った／区画運動の候補なし）。定義 r2 は保つ。時計（idle の優先）による低下を休みに数えることは定義と矛盾しない。「維持に役立つか」は別の問い（V4 は (α)）。
- 「m0 は毎歩候補」「試しの休みは約 100 歩に一歩」は規則から読んだ**未確認の予測**。反証条件: m0 が候補から落ちる歩、idle の pool の競合で休みの間隔が崩れること。
- α（V5 の直し）: 宣言の α は世界の規則での到達（`notes/D3.md:53`）で、m0 の行為は申し出・取り込み・たまりに届かない → **宣言 α(m0)＝∅**。m0 を sil して区画運動が代わりに行為する事象は、D3 の前提 P18（`D3.md:55–56`、m 以外の運動の行為が二つの分岐で同じ）を破るので照合に使わない（置換の効果は総効果で、α ではない）。現時点で照合の候補として挙げられるのは、m0 が唯一の候補だった歩（sil しても他の運動の行為は変わらない）で、t＋2 までの P18 の残りの前提（違うのが m の区画のたまりだけ、など）は別に確かめる。S32 の試しでは区画運動の候補が空の歩は未観測で、育ちでの出現・頻度は未確認。
- α(m0)＝∅ が m0 から ε・hSMC・hAct へ何も足さないのは**直接の**寄与に限る。選択の競合を通して区画運動の履歴（行為・確かめ・弱め・lastM）が変わり、DC の値に間接に効くことは残る。休みの窓で DC が落ちれば (ii) が偽で、その窓は休みではない。
- 生まれつきの m0（V6）: 系統の比較として筋が通る。差には育ちの変化も含まれ、試しでの m0 の直接の効果だけに帰属させない。
- 第一段の意味（V7 の直し）: 定義の手続き（Rel・解除の分岐・DC・再開）がこの身体で働くかと、休みがどの過程で生じるかを確かめる。「維持のための休み」は第一段では**立証の対象外**（検証できる条件が未定）で、不可能とは言わない（m0 が状態を直接読まなくても、競合する区画運動を介して選ばれ方は状態に依りうる）。
