## 3. 推論（確認した事実と分離）
1. **N3 逆バイアス仮説の支持と切り詰め緩和単独説の否定**: 基準側境界鍵を除いた両側内点鍵 $K^+_{\text{in}}$ のみでも、全有限容量および $C=\infty$ で $\overline{\delta_{\text{out}}} < 0$ が成立し、かつ $C=\infty$ では $(|M_t|, \Delta G_{\text{O1}})$ の相関が `-0.9476`、$p_K > 1/2$ 内点鍵の `75.8%` が $1/2$ を横断して反転している。S88 で観測された $G_T$ 低下（約 63 → 約 55）は切り詰め緩和単独では説明できず、Q1＋R1＋O1 の合成による逆バイアス（加えて行為別 `rate(a)` への $M.ma, M.ma1$ 混入による `rate-only` 波及 31%）が主因である。
2. **$C=1, 2$ での `ΔG_direct > 0` と $p_K < 1/2$ 側の正の $\delta_{\text{out}}$**: 場の多くが $Y=1$ 優位（$p_K > 1/2$）であるため、$M$ に残る R1 外れは主に $Y=0$ 断片に偏る。この $Y=0$ 断片が（過去の切替等で現在 $p_K < 1/2$ にある鍵や、`rate(a)` 経由で）予測を $0$ 側へ押し下げる結果、$p_K < 1/2$ 側では $1/2$ からの距離が増え、$C=1, 2$ では少数の $p_K < 1/2$ 鍵の正寄与が `ΔG_direct` の平均をわずかに押し上げた一方、全鍵へ波及する `rate-only` が総和 $\Delta G_{\text{O1}}$ を負に決めた（未検証の推論）。
3. **$C=\infty$ で `main keep` が `4` → `24` に増えた機序**: $C=\infty$ では $p_K > 1/2$ だった鍵の多数が O1 逆バイアスで $p_{K+M} < 1/2$ に反転しているため、通常なら多数派の予期どおり（$y_s = 1$）だった主の入力が、反転した $p_{K+M}$ に照らして R1 発火（主保持）した可能性がある（未検証の推論）。

## 4. 規約の順守と次段の選択肢（提案・反証条件つき）
- **規約順守（L2L §7 Q2・#89）**:
  - 本結果をもって $C \in \{0, 1, 2, \infty\}$ のいずれかを最良容量として採択しない。
  - 逆バイアスが観測されたこと単独では R1・O1 を勝手に変えない。
- **次段の判断材料**:
  - S89 により「$C=\infty$ で O1 合成が $p_K > 1/2$ 鍵の 75.8% を $1/2$ 横断反転させ、$G_T$ を `-7.72` 削る（うち 31% は `rate-only` の行為全体波及）」という構造的事実が確定した。
  - 次の一手の候補:
    - **案 1（O1 の見直し議論を 3 者 D 段で開く）**: 行為全体へ無減衰断片を混ぜる `M.ma / M.ma1` の `rate(a)` 混入と、Q1 二重計上による $1/2$ 横断をどう扱うか（R1 は維持し、O1 合成規則の設計案を 3 者で比較。ただし要件未達があるかどうかの確認が先）。
