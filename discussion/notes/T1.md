## 0. 確認した事実
- F1 sed_fade（項番84、`core/circuit.jl:248–257`、Lean `formal/LabCircuit.lean` SedFade）: 確かめられない辺は FORGET の倍数の歩で sg を 1 失う。確かめで時計が戻る。既定に採ったのはユーザー（項番93、SF）。
- F2 S19（項番115）: 沈殿だけの型（確かめのない r2・r8→m2）は sed_fade で試しの更新 391 に支えを失い、切ると確かめのないまま m2 が 396/400 歩行為した。R3-b′ の (2) は sed_fade のもとで落ちる（S16・S18）。
- F3 P033（Egbert & Barandiaran 2014、`papers/text/033.txt`）: 習慣＝くり返しで強まる自己維持的な感覚運動の型（:307–312）。IDSM の節は一定の速さで劣化し（:477、:815）、**使われる（軌跡が通る）ことで補われる**（:816）。使われない型はやがて消える（:963）。
  ラボの sed_fade は「確かめ」（答えの対比）で時計が戻り、「使われる」（駆動して行為する）ことでは戻らない。P033 の劣化と補いの形とは違う。
- F4 項番86: sed_fade なし（S）では道具の L2 が 0/30、SF で 30/30（維持費 KC_trial 0.0015 の下、沈殿だけの辺の維持費が効く、項番83〜85）。

## 1. 提案（変種 SFD、規則は既定オフ）
- 規則: sed_fade に加えて、辺 k が更新で**駆動し（drove[k]）、その運動が行為した**とき、確かめと同じく時計（lastC[k]）を戻す。確かめも駆動もない辺だけが薄れる。名前 `sed_fade_drive`（kwarg、既定 false。sed_fade が真のときだけ効く）。
- Lean を先に: `SedFade` に `stepDrive F old confirmed driven e`（確かめ→old、駆動→age 0・sg そのまま、ほか→fade）と補題 driven_keeps（駆動の歩で sg が減らない）、confirmed_untouched′、clears′（駆動も確かめもない F×S 歩で sg 0）、keeps_before′。
- Julia: `core/circuit.jl` の sed_fade の塊に `(sed_fade_drive && drove[k] && motor acted)` で lastC[k]＝now。既定で `sh core/check/run.sh` 一致（Rust は変えない、照合の場面は既定のまま）。
- 測定（S25、予測を凍結、新しい種子 251〜）: SF と SFD を同じ種子・育ちで比べる。
  (a) 習慣: S18 の judge（R3-b′）を SFD で。沈殿だけの型の出現と (2) の N の側（t＋400 に支えが残る）。
  (b) 兼ね合い: 道具の L2 の真の率（variant_horizon、4 地平・両構造）、生存。項番86 の「沈殿の維持費が L2 を支える」との関係（SFD で L2 が落ちるか）。
- 読み: SFD は P033 の「使われることで補われる」に近い形の一つで、P033 の IDSM を実装したとは言わない。採用（既定にする）はユーザー判断。

## 2. 論点
- Q1: 「駆動して行為した」を補いの条件にするのは P033 の「使われる」の読みとして妥当か（駆動したが行為しなかった、同点で別の運動が行為した場合）。
- Q2: SFD では沈殿だけの癖が自分を保つ（駆動→行為→時計が戻る）ので、確かめのない癖が永続しうる。これは sed_fade を入れた動機（項番84「確かめられない癖は保たれなくなる」）を打ち消す。測る意味はあるか（兼ね合いを測ること自体が T1 の問い）。
- Q3: 予測の形（R3-b′ の成立の率、L2 の率の差）と種子の数。
