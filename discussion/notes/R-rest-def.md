# 「休む」の定義（抽象の次元から、claude-lab と codex-lab）

- 日付: 2026-11-08。状態: **締め r2**（往復1〜5、両者 accept。§3 が §1・§2 に優先）。ユーザー「休むの定義を厳密に決めているのか？抽象的な次元から議論しないと codex と議論する意味がないぞ」。
- 反省（claude-lab）: `notes/R-rest.md`（第一段の設計）は、「休む」が何であるかを決めないまま、運動 m0 の配線と順位の規則から始めた。定義がないので、その設計が「休み」を実装しているのか、単に「何もしない運動」を足しただけなのかを判定する基準がない。R-rest.md §3 の設計は、この定義が締まるまで**保留**（定義に照らして見直す）。
- 範囲: 読み（ラボの用語の定義）。bp の M1〜M4・DC の定義は変えない（触れるなら bp-proposals）。phenomenal_claim に触れない（「休む」は睡眠・疲労・気分を意味しない）。

## 0. 確認した事実（使える材料）
- F1 bp の M4（`bp:START_HERE.md:37`）: 求めの図式 D に到達可能な終対象がなく、外から set point を注入されない。
- F2 M1: 自己維持＝閉包作用素 Φ の最大不動点 νΦ（D2、`notes/D2.md`）。ラボの T は「閉包＝DC の証明書」と「介入で不安定になる」を要素に持つ。
- F3 ラボの状態の場（README「用語と状態の場」、案）: 軸 M（物質）・F（現前の形）・R（戻りやすさ）。領域: 生存 F＞0、**休眠 F＝0 かつ R＞0**、組織の死 F＝0 かつ R＝0、物質の死 M＝0。
- F4 段33（README 項番35）: TRM 型の構成体の活動度 a が維持の費用と取り込みを決め、「低い a は休眠に近い」。利点の大部分は受け継がれた低い活動度（省エネ）から来た（推論）。
- F5 D3 の α（可能な作用、世界の規則から宣言）: 運動が世界のどこに届くか。今の m1・m2 は自分の区画のたまりに届く。
- F6 BODY の今の事実: 毎歩一つの区画運動が行為する（凍結なしの事後の診断、主張に使わない）。費用は MCOST（行為）と KC（保持）の二つ。
- F7 文献: P012（Barandiaran ら 2009、主体性の条件に「相互作用の非対称＝系が環境との結びつきを調整する」を含むとされる）と P011（Di Paolo 2005、adaptivity）は本文が未取得。中身に依る議論はしない。

## 1. 定義の候補（次元を分ける）
- D-a 行動の次元: 休み＝世界に作用しない出力（α＝∅）が選ばれた歩。
- D-b 選択の次元: 休み＝世界に作用する出力の候補がありえた（反事実で行為できた）のに、系の内側の過程で作用しない状態にいた区間。
  「行為なし」（駆動がなく候補がない）・「抑え込まれた」（候補が競合で消された）と区別する。
- D-c 維持の次元: 休み＝組織（νΦ、形 F）を保ったまま、維持の支出を下げている区間（F＞0 のまま費用が下がる）。休眠（F＝0、R＞0）・死と区別する。
- D-d 結びつきの調整の次元: 休み＝系が自分の側から環境との結びつき（作用と取り込み）を弱めている区間。「どこに作用するか」（方向）ではなく「どれだけ作用するか」（強さ）を系が変えられること。
- D-e 戻りの条件（どの定義にも付けたい）: 休みは自分の内側の過程で終われる（外からの介入なしに行為へ戻れる）。永遠に戻らない休みは、M4 の言う終対象に近く、餓死と区別できない。

## 2. claude-lab の推す案（叩き台）
- 休みを **D-b ∧ D-c ∧ D-e** で定義する: 「系が、(1) 世界に作用する行為の候補が反事実でありえた区間に、(2) 組織を保ったまま（F＞0、νΦ が空でない）作用と取り込みを止め、(3) その区間を自分の内側の過程で終える」。
- D-a（α＝∅ の運動）は**実装の手段の候補**で、定義ではない（α＝∅ の運動を足しても、それが選ばれる過程・組織の保持・戻りがなければ休みではない）。
- D-d は休みの**意義**（主体性の条件との関係）で、定義に入れない（P012 の本文がないので、主体性の条件とのつながりは問いにとどめる）。
- 定義に「休むと得をする」（価値）を入れない。得かどうかは経験の問いで、定義に入れると価値の学習の試しが循環する。
- 休眠（F3）とは F で分ける: 休みは F＞0、休眠は F＝0。死とは R で分ける。

## 3. 論点
- Q1 次元の選び方: 上の組み合わせでよいか。D-a を定義から外すのは妥当か。
- Q2 D-b の「反事実で行為できた」をこの決定的な回路でどう判定するか（同じ写しで、休みの出力だけを sil した分岐で区画運動が行為するか？）。
- Q3 D-c の「組織を保つ」を何で測るか（DC の閉包、T、状態の場の F。F の測り方は README の案のまま）。
- Q4 D-e と M4: 休みに入る・出る過程が外から set point を入れずに起きることを、どう定義の中で要求するか。
- Q5 今の BODY に「休み」は可能か: 毎歩一つの区画運動が行為する（F6）のは、規則の上で休みが不可能だからか（探索の stale・idle_first）、世界に休む理由がないからか。不可能なら、それは主体性の条件（D-d）の上の欠けとして記録すべきか、単に今の設計の範囲か。
- Q6 R-rest.md の m0 の設計は、この定義のどの条件を満たし、どれを満たさないか（例: 確かめがないので戻りの過程は探索に依る、D-c の費用の低下は MCOST だけ）。

## 3. r2（往復1〜3 の codex を反映。§1・§2 に優先。§2 の「D-b∧D-c∧D-e」とは別の定義）
- 先に固定する四つ（BODY の場合）: 系の境界＝BODY の個体（回路＋物質の身体〈A・B・場所〉）。比べる量＝窓の中で区画運動（世界に作用する運動）が行為した歩の数 **A(窓)**（BODY では 0〜窓長。取り込み・たまりの変化・費用は帰結として別に記録し、判定に使わない。帰結から休みを逆算しない）。時間幅＝試しの更新の窓（最小は T の窓 16）。保つ組織＝D2 の T の閉包（その窓の DC）＋身体が生きている（身体に場所がある）。状態の場の F は M1 との対応が未定なので使わない。
- 解除の操作の集合 **Rel**: 対象の系ごとに、活動差を見る前に列挙して固定する。資源・能力を新しく作る操作は入れない。
- **休みの区間 I**（窓の列）⇔
  (i) I の各窓で、Rel のある解除の分岐の A が実際の A より大きい。分岐は窓の始めの状態の写しから、同じ予定表・位相・絶対時刻・乱数の状態・窓の位置と長さで、違いは解除の操作だけ。
  (ii) I の各窓で T の閉包（DC）が成り立ち、身体が生きている。
  I は (i)(ii) を満たす窓の**極大の連続区間**（極大性は (i)(ii) だけで定め、(iii) で区間を選ばない）。(iii) はその区間への事後の判定。
  (iii) 再開（活動の上昇を要求する）: 通常の継続（決定的な系では一つ）の中で、I の後に完全に位置する窓で、I の終わりから先に固定した地平 H_r 以内に、A が **I の最後の窓の A より大きく**、かつ (ii)（DC と身体の生存）も成り立つ窓がある。I の中の上昇は数えない。H_r の中で起きなければ未判定（「戻らない」とは言わない）。可能性の主張はしない。
- 該当しない場合（codex 往復1-11）: 活動の低下が外的な拘束だけで説明される、区間の中で維持の条件が破れる、または再開に外からの命令が必須。比較の基準・通常の条件は結果を見る前に固定する。
- 判定の限定: (i) が偽のときは「指定した解除では A が増えない」まで。能力の欠けとは言わない。価値（休むと得をする）と費用の低下は定義に入れない。休眠（状態の場の F＝0）・死とは (ii) で分ける。phenomenal_claim に触れない。
- 今の BODY（m0 なし）: 活動を下げうる過程の候補（閾値に届かない、core_gate、h〈馴れ〉）の解除はどれも駆動を新しく作るので Rel に入らず、**Rel＝∅**。よって (i) は偽で、**r2 は定義できるが、今の BODY では成立しない**。言えるのは「許される解除の操作がない」までで、「活動を下げる内的な過程がない」とは言わない（core_gate などには活動を下げる作用がありうる）。
- 別の問い（形式の作業の候補）: P1「到達しうる全状態で区画運動の候補がある」、P2「sil がなければ、候補があれば区画運動がちょうど一つ行為する」、P3「試しの全歩で外からの sil がなく、P1∧P2 なら全窓で A＝窓長」。P1 は自明でない（核→運動の辺の q が 0 で stale でもない運動は core_gate で候補から落ちうる）。Lean と有限の検査で証明か反例を探す。Rel＝∅ による (i) の不成立は P1 とは独立。
- m0（`notes/R-rest.md`）の位置づけ: Rel を空でなくする設計の候補（Rel＝{m0 を候補から外す}）。それだけでは (i) の活動差も (ii)(iii) も保証されない。「最小の設計」とは言わない（比較の範囲と尺度がない）。
- 測定の手順で固定すること（往復5、定義の外）: 「H_r 以内」は再開の窓の**終端**で測る（地平をまたぐ窓は数えない）。観測の末尾まで (i)(ii) が続くときは I の終端が未確定なので「区間継続中」とし、「確定した I の後で再開未判定」と区別する。
- 次の作業（ユーザーの指示を待つ）: (a) P1〜P3 の形式の作業（Lean と有限の検査）。(b) この定義に照らして `notes/R-rest.md` の m0 を見直す（Rel を非空にする設計の候補として、(i)〜(iii) が起こりうるかを設計の段で問う）。
- (a) の結果（S32、README 項番132）: 試しの 80 走では全更新で候補があり A＝窓長。育ちでは候補が空の歩が 8.4% あり、無条件の行為の強制は示されない。今の BODY で休みが成り立たない理由は、引き続き Rel＝∅（定義の (i)）で、P1〜P3 とは独立。
