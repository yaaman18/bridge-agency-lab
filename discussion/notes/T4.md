- **T4-b（案 E と M4）**: 案 E（閾値を活動に応じて自己調節する）が M4 と衝突するかは、目標の活動の値を規則の定数として書き込むことが M4a の「外から注入された set point」に当たるか（規則の一部か、跡への注入か）、また M4b の求めの図式に終の set point を作るかで決まる。
  これは bp の M4 の解釈の問題で、ラボでは決めない（CLAUDE.md: bp の理論に触れる点はユーザーの事前承認）。案 E を試すときに bp-proposals に問いとして出す、と記録するだけにする（今は起案しない）。
