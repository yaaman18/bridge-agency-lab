## §1 Part I：Stage 0（静的 `PartOfHierarchy`）の紙上破綻証人 〔判断点 O21〕

### 1.1 Stage 0 の観測語彙（`~/bridge-protocol/formal/ERIEC/MetaSelection.lean:279-365`）
現行 Stage 0 が各時刻 $t \in \{0, 1\}$ のスナップショットで観測・表現できる構造は次の 3 点に限られ、**時刻間の比較は同型類（up to isomorphism）でのみ定義される**（確認した事実）：
1. 静的包含半順序 `PartOfHierarchy Node_t`（反対称な薄い圏 $(V_t, \le_t)$）。
2. 固定分解 `WorldDecomposition Part_t PartWorld_t WholeWorld_t`（`inclusion_t : (i : Part_t) → PartWorld_t i → WholeWorld_t`）と、比較写像 `canonicalComparison D_t : (Σ i, PartWorld_t i) → WholeWorld_t` の非全単射性として定義される `WorldIrreducible D_t := ¬ Function.Bijective (canonicalComparison D_t)`。
3. 2 フラグ分類 `classifyIndividuality (upperIrreducible lowerIndependent : Bool) → {individual, colony, aggregate, dead}`。

※`formal/ERIEC/Lineage.lean` は個体全体間の `GenEvent : OpenSystem → OpenSystem → Prop` のみを持ち、$V_t$ 内の下位モジュール間を時間横断で結ぶ関係を持たない。また `Part_t` の添字（スロット）の一致は時間横断の同一性を何ら主張しない。

### 1.2 極小破綻証人（互いに素な担体上の全置換反例：$H_{\mathrm{persist}}$ vs $H_{\mathrm{replace}}$）
時間横断の同一性をラベルや添字で密輸しないため、**互いに素な時間添字付き担体集合**を用いる：
- 時刻 $t = 0$: $V_0 = \{W_0, a_0, b_0\}$、半順序 $\le_0$ は反射対＋$(a_0, W_0), (b_0, W_0)$。
- 時刻 $t = 1$: $V_1 = \{W_1, a_1, b_1\}$（$V_0 \cap V_1 = \emptyset$）、半順序 $\le_1$ は反射対＋$(a_1, W_1), (b_1, W_1)$。
- **具体的な `WorldDecomposition` 証人（`MetaSelection.lean:284-320` にそのまま適合）**:
  - 各 $t \in \{0, 1\}$ について、`Part_t := {a_t, b_t}`（2 元型）、`PartWorld_t _ := Unit`、`WholeWorld_t := Unit`、`inclusion_t _ _ := ()` と置く。
  - このとき `PartWorldCoproduct_t = Σ i : Part_t, Unit` は 2 元 `⟨a_t, ()⟩ ≠ ⟨b_t, ()⟩` を持ち、`canonicalComparison D_t` は両方を `() : Unit` に写す。よって単射でなく全単射でもないため、**`WorldIrreducible D_t` が構成的に成立**する（`upperIrreducible = true`）。
  - **注記（主張の限定）**: `PartWorld_t _ := Unit, WholeWorld_t := Unit` は任意の $|\mathrm{Part}_t| \ge 2$ で `WorldIrreducible` を自明に満たす構成であり、本証人は **Stage 0 の型レベル破綻証人（typing witness）にすぎず、創発（emergence）の実証証拠ではない**。
  - さらに下位モジュール単体は独立生存不能（`lowerIndependent = false`）とすれば、両時刻とも `classifyIndividuality true false = individual`。
  - 写像 $\varphi(W_0)=W_1, \varphi(a_0)=a_1, \varphi(b_0)=b_1$（および $a_1 \leftrightarrow b_1$ 入替）により、Stage 0 の全観測組 $(V_0, \le_0, D_0, \mathrm{cls}_0)$ と $(V_1, \le_1, D_1, \mathrm{cls}_1)$ は**厳密に同型**である。
- **同型な Stage 0 観測を実現する 2 つの異なる動的履歴**:
  1. **$H_{\mathrm{persist}}$（全子モジュール存続）**: $t=0 \to 1$ で身体 $W_0 \to W_1$ および 2 つの下位担体 $a_0 \to a_1, b_0 \to b_1$ がすべて存続する。
  2. **$H_{\mathrm{replace}}$（全子モジュール全置換）**: 身体 $W_0 \to W_1$ は共通維持費と不可逆な生存を保って存続するが、下位モジュール $a_0, b_0$ は維持費枯渇により消滅（`death`）し、新たに 2 つの子モジュール $a_1, b_1$ が生成（`birth`）される。
- **破綻の結論（推論）**:
  - Stage 0 の観測（同型類）は $H_{\mathrm{persist}}$ と $H_{\mathrm{replace}}$ で完全に同一であり、スロット同型性は系譜を与えない。
  - **反証条件**: 同型類比較のもとで上記の具体構成が Stage 0 述語を満たさない（または Stage 0 の現行構造だけで $H_{\mathrm{persist}}$ と $H_{\mathrm{replace}}$ を分離できる）なら、Stage 0 破綻の主張は棄却される。

### 1.3 Stage 1（最小拡張）：整形式則付き隣接時点系譜スパン $L_t$
Stage 0 に追加する最小構造を、互いに素な $V_t, V_{t+1}$ 間のタグ付き関係として定義する：
$$L_t \subseteq V_t \times V_{t+1} \times \{\mathrm{persist}, \mathrm{split}, \mathrm{merge}\}$$
- **消滅と誕生**: $\mathrm{Death}_t := V_t \setminus \mathrm{dom}(L_t)$、$\mathrm{Birth}_{t+1} := V_{t+1} \setminus \mathrm{cod}(L_t)$。
- **整形式則（1 歩あたりの端点排他・種別混在禁止）**:
  - 任意の $u \in \mathrm{dom}(L_t)$ について、$u$ から出る辺はちょうど次のいずれか 1 種に限る：
    1. **1→1 存続（`persist`）**: ただ 1 本の $(u, v, \mathrm{persist})$（かつ $v$ に入る辺もこれ 1 本のみ）。
    2. **1→多 分裂（`split`）**: $k \ge 2$ 本の $(u, v_1, \mathrm{split}), \dots, (u, v_k, \mathrm{split})$（各 $v_r$ に入る辺はこれ 1 本のみ）。※親が存続しつつ子を出芽する（budding）場合は、`persist` と `split` を混在させず、**1→$k$ の `split`（$k \ge 2$）のうち 1 つの出力を親の継続出力として指定する**ことで表現する。
    3. **多→1 合流（`merge`）**: $m \ge 2$ 個の元 $u_1, \dots, u_m$ から同一の $v$ へ入る $(u_r, v, \mathrm{merge})$（各 $u_r$ から出る辺はこれ 1 本のみ）。
  - 同一ノードが同一步の同じ側で異なる種別のイベントに属することを禁じる（端点排他）。
- **M1 担体アンカー（設計者ラベルの禁止）**:
  - `persist` および分裂時の継続出力の指定は、設計者が事後ログに貼る任意ラベルではなく、**M1 力学内の構造的担体連続性基準**（例：同一メモリ構造・維持痕跡スロットの連続更新と非消滅）によって決定されなければならず、将来コード化する際は自然言語の約束にとどめず**実行可能な M1 連続性検査**として実装する。
- **身体コア制約（U-NC1(a)(c)）**:
  - 生存中は身体ノードについて $(W_t, W_{t+1}, \mathrm{persist}) \in L_t$ が成り立ち、一度 $W_t \in \mathrm{Death}_t$（機能終了）となれば以後の時刻 $t' > t$ で復活・再接続を持たない（不可逆性）。
- **極小証人の分離確認**:
  - $H_{\mathrm{persist}}$（$V_0 = \{W_0, a_0, b_0\}, V_1 = \{W_1, a_1, b_1\}$）: $L_0 = \{(W_0,W_1,\mathrm{persist}), (a_0,a_1,\mathrm{persist}), (b_0,b_1,\mathrm{persist})\}$、$\mathrm{Death}_0 = \emptyset, \mathrm{Birth}_1 = \emptyset$。
  - $H_{\mathrm{replace}}$（$V_0 = \{W_0, a_0, b_0\}, V_1 = \{W_1, a_1, b_1\}$）: $L_0 = \{(W_0,W_1,\mathrm{persist})\}$、$\mathrm{Death}_0 = \{a_0, b_0\}, \mathrm{Birth}_1 = \{a_1, b_1\}$。
  - 移り変わる連合 $H_{\mathrm{shifting}}$（固有の担体 $V_0 = \{W_0, a_0, b_0\}, V_1^{\mathrm{shift}} = \{W_1, b_1, c_1\}$；依然として $V_0 \cong V_1^{\mathrm{shift}}$ で Stage 0 観測は同型）: $a_0$ が消滅し、$b_0$ が $b_1$（継続出力）と $c_1$ へ分裂する $L_0 = \{(W_0,W_1,\mathrm{persist}), (b_0,b_1,\mathrm{split}), (b_0,c_1,\mathrm{split})\}$、$\mathrm{Death}_0 = \{a_0\}, \mathrm{Birth}_1 = \emptyset$。全端点が $V_0 \times V_1^{\mathrm{shift}}$ 内に収まり、次数・端点排他の整形式則を満たす。
  - いずれも整形式則を満たし、同型類上でも一意に分離される。
- **Stage 1 の反証条件**: 互いに素な担体上の全置換反例・移り変わる連合反例において、M1 担体基準で定義された整形式 $L_t$ でも識別できない履歴対が見つかれば Stage 1 は不十分として見直す。
- **Stage 2 の再開放条件（現状は持ち込まない）**:
  - **Fibration**: 異なる分解間の再索引付けが**恒等律と結合律**を満たす形で具体化されたときのみ再開放。
  - **Operad**: 多入力 CPC 代入則が**単位元と結合律**を満たす形で具体化されたときのみ再開放。

## §2 Part II：未凍結の紙上探索設計（個体内増殖＋コアなし CPC、`exploration` 草案） 〔判断点 O22〕

> **厳格な位置づけ**: 本節は将来の実験設計を紙上で見通すための **未凍結の設計素案（〔暫定〕）** である。数値定数・種子・凍結ファイルは一切割り当てない。U-BL1 解消および Fable 見直しの後にのみ S 仕様化・予測凍結へ進む。

### 2.1 最小アーキテクチャの 3 層構成（概念仕様・数値未定）
1. **身体層（Body = 不可逆性と共通維持費の器、U-NC1(a)(c)）**:
   - 生存フラグ `alive`（`false` は吸収状態＝不可逆な死）、共通資源プール $R_t$、未払い維持費負債 $D_t$。
   - 外界入力 $x_t$ と連合出力 $a_t$ から資源収穫 $h(x_t, a_t)$ を得て、全モジュールの維持費・活動費を賄う。不足分は $D_t$ に累積し、構造的上限を超えると不可逆的に `alive = false` へ遷移（P-10）。
2. **下位モジュール層（内生的増殖・消滅、O15 非干渉制約）**:
   - 各時刻の活性モジュール集合 $M_t$。各 $i \in M_t$ は局所状態 $s_{i,t}$・局所予測器 $f_i$・局所維持痕跡 $u_{i,t}$・予測残差 $e_{i,t}$ を持つ。
   - 消滅（`death`：`u_{i,t}` 枯渇）および分裂（`split`：共通資源余剰と局所維持条件による子生成＋微少変異）は、**許可された M1 状態・外界入力・宣言済み乱数のみに依存**し、`Φ_rich`・隠れた固定年齢スケジューラ・通訳の語り・設計者目標ラベルのすべてに非干渉（O15）。
   - 各歩で M1 担体連続性基準により Stage 1 の $L_t$ を読み取り専用ログへ記録（系への書き戻し禁止）。
3. **連合・予測符号化層（No-Core Shifting Coalitions、U-NC1(b)）**:
   - 連続配置重み $w_{i,t} \ge 0$ による分散予測合成と、局所隣接モジュール間の残差 $e_{i,t}$ 伝達により、固定ハブや回転する独占仲介規則なしに更新を行う。

### 2.2 対照群（将来の凍結前実験で必ず並べる 5 型）
1. **`CPC-Prolif`（対象系）**: 共通維持費＋内生的分裂/消滅＋分散残差結合（独占仲介なし）。
2. **`Runaway-Cancer`（暴走対照）**: 維持費負債を無視して分裂し続け、資源枯渇・負債発散を起こす系。
3. **`Fixed-Core`（固定コア対照）**: 固定ハブが全修正と行為決定を独占仲介する系。
4. **`Rotating-Mediator-Failover`（回転＋フェイルオーバー仲介対照、U-NC1(b) 検証用）**: 実行ホストが回転し、1 経路遮断時に即座に別ホストへフェイルオーバーする単一必須仲介規則を持つ系（**棄却されるべき負の対照**）。
5. **`Rotating-Mediator-Redundant`（冗長コピー・冗長リンク認可対照、U-NC1(b) 検証用）**: 2 ホストが同一の必須認可規則 $R$ を並列実行、または $R$ の認可信号が 2 本の冗長リンクで運ばれる系（単一リンク遮断でも全修正が生き残り残差伝播も維持されるが、**厳しめにみて「コアあり」として棄却されるべき負の対照**）。

### 2.3 事前登録予定の判別バッテリー（将来の実行前に凍結）
- **検査 E1（暴走 vs 有界な個体内増殖、O17）**:
  - 親→複数活性子孫の分裂をまたぐ資源摂動下で、$N_t$ の有界性だけでなく**未払い維持費負債 $D_t$ と全体生存性（viability）**をクラッシュ時刻と独立に追跡し、誕生率と維持費赤字の負相関を確認。
  - *反証条件*: `CPC-Prolif` を `Runaway-Cancer` から維持費負債・摂動下生存性で分離できなければ設計を棄却。
- **検査 E2（M4 / `Σ-purity` 非干渉、O15）**:
  - 許可された状態・外界入力・乱数を一致させ、禁止入力（外部スコア・隠れた年齢クロック・通訳出力）のみを変化させたとき、turnover 系列と $L_t$ がビット一致することを確認。
  - *反証条件*: 禁止入力の変化で 1 歩でも turnover や $L_t$ が変われば非干渉を棄却。
- **検査 E3′（身体隔離＋規則レベル一括無効化＋交換試験＋迂回証人、U-NC1(b)・O17）**:
  1. **身体維持費の隔離（誤棄却防止）**: すべての情報処理経路検査で共通身体状態 $(R_t, D_t)$ を一致・固定し、U-NC1(a) で許容される身体コンテナ効果と、U-NC1(b) で棄却すべき情報処理上の独占仲介を分離する。
  2. **連合入替をまたぐモジュール間 CPC 伝播**: 維持費一致下でモジュール $i$ の予測残差 $e_{i,t}$ に摂動を入れ、事前宣言した結合窓 $\Delta$ 内に他モジュール $j$ の次予測 $\hat{y}_{j, t+\Delta}$ が変化することを、$L_t$ によるメンバー交代およびローテーション位相切替の前後で反復確認する。
  3. **規則レベル一括無効化（フェイルオーバー・冗長コピー対策）**: 候補となる独占仲介・認可規則 $R$ ごとに、維持費・残差を一致させかつ下層のモジュール間輸送路は保ったまま、**全ホスト・全冗長コピー・全キャッシュ済み認可にわたって $R$ を一括無効化**する。全活性位相で有効なモジュール間修正がすべて停止し、$R$ 復元で復帰するなら、**「コアあり（媒介あり）」として棄却**する（U-NC1(b)）。
  4. **時間固定ステップ切除＋交換試験（Interchange Test）**: フェイルオーバーを禁止した上で当該時刻の候補ホスト集合を時間固定切除する。また、規則 $g$ の出力 $z_t$（どのホストで計算されたかを問わず）を別実行から差し替えたとき、すべての次状態修正 $\Delta s_{j, t+1}$ が $z_t$ に追随するなら「コアあり」として棄却する。
  5. **正の迂回証人（Bypass Witness）と不完全目録の留保**: 各候補規則 $R$ について、$R$ を迂回して成立する有効なモジュール間修正の具体証人を要求し、各時刻の有効修正グラフの最小頂点カット $\ge 2$（かつ全ホスト共有の単一規則 $g$ の不在）を確認する。$\bigcap_t \mathrm{Ess}(t) = \emptyset$ は必要条件のみ。**候補認可経路の目録が不完全な場合、E3′ は「コアなし認証」ではなく「未決（unresolved）」を返す**。
  - *反証条件*: E3′ が `Fixed-Core`・`Rotating-Mediator-Failover`・`Rotating-Mediator-Redundant` のいずれかを通過させる、または身体隔離下で正当な `CPC-Prolif` を誤棄却する、あるいはキャッシュ済み認可が切除窓をまたいで伝播を運び一括無効化の主張を破るなら、E3′（または設計・認可網羅）を棄却／未決とする。
