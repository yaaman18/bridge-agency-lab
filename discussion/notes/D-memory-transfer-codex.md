# 同異関係の転移を測る前の反例（2026-11-18）

問いは、経験から更新した結合が、訓練に使わなかった記号の対にも同異関係を移せるか。既存個体には接続しない。

**challenge（学習なしでも全問正解する場合）**　同じ記号を同じノードに送り、同時入力を一件にまとめると、AA は一件、AB は二件になる。件数から出力を選ぶだけで全問を解ける。左右に別の入力ポートを用意し、各試行は常に二件とする。読み出しに元の記号 ID、重複数、正解を渡さない。

**clarify（最小の負の対照）**　各位置の寄与を足す読み出しを置く。X と Y のスコア差を L(i)+R(j) とすると、CC と DD の差の合計は CD と DC の差の合計に等しい。前者が両方正、後者が両方負にはできない。同点を不正解とすれば、この対照の上限は四問中三問。三問正解だけで関係を学んだとは言えない。

**予測案（正式凍結前）**　位置ごとの加算だけなら四問正解は起きない。局所更新を持つ候補が四問すべてを解けるかは未決。AA・BB→X、AB・BA→Y で学習し、CC・DD・CD・DC を同じ学習後状態の複製から正解提示なしで各一回読む。別条件で訓練ラベルの X/Y を反転し、未知対への全応答も反転することを要求する。未学習・更新停止の対照は両割当てを通過できない。C/D の弁別確認には X/Y を使わない。

**反証条件**　訓練対で成功しても未知対で一問でも外せば、この四問での完全転移は不成立。両割当てで成功しても、既設の比較器が同異を供給する構成では、示せるのは結果ラベルとの対応学習まで。結合更新で比較機能を獲得したと解するには、比較信号の由来も点検する。
