## §0 問い（Fable の見直しではここだけを先に渡す。Opus の答えを含めない）

**問い**: ラボで「退屈」と呼ぶ機構を、何の量に対する、どんな痕跡として定義し、どう検査するか。

**ユーザーがすでに決めていること（変えない）**
- 予測の外れを求めること（退屈）は**報酬として入れず**、**存続によって選ばれる痕跡**として持たせる（2026-11-15）。
- 痕跡は維持費を払い、払えなければ薄れる。記憶の痕跡の定義は用語集 §7（過去の入力と行為が法則を通して状態に残した差で、後のふるまいを変えるもの）。
- O1・O2（予測誤差を予測できる度合い）に対応づく概念は「予測誤差への期待」（「予測誤差がないと人も退屈するでしょ？」）。「飢え」ではない。
- 行為は確率から引き、乱数は電波から取る変種を試す（S55・S57 で引く仕組みを作った）。TRM の出力は「行為ごとの応えられる確率 p_a」と「自分の外れの見込み ê」。
- 順は (1) 決定的な推論と Pi での照合 → (2) 予測器の設計 → (3) 退屈 → (4) 体の傾向を読む仕様（2026-11-16）。予測器の設計の 5 つの問い（D-PRED §4 U1〜U5、ê の使い方を含む）は**未決**。
- 最大化・報酬・先読みを持たない（X5、層の分離）。快・不快は自己維持の回路の上の別の層（2026-11-03）。`phenomenal_claim` に触れない。

**制約と既存の材料**
- 既存の二つの案は食い違っている: D-MEM §6「外れの見込みが長く低いとき引く確率を平らにする度合いを痕跡として持つ」（ê を読む）／D-MEM §9.3「同じ行為が続き、その間に受容器の出来事が変わらなかった長さ r に応じてその行為の重みを下げる痕跡」（r を読む）。
- D-MEM §7 の合意: 退屈は「世界が変わる」だけからは導けない。「存続への因果的な寄与を検証する候補の機構」と読む。`idle_first` と sed_fade を共通の基準にして、上積みがなければ捨てる。実験の骨組み（定常／行為の有効性が逆転する入れ替え、腕＝なし／作用する／費用を払うが作用を遮る、主の量は全個体の決めた時点の生存）。
- 検査 N（D-MEM §9.1）の形。ただし S58・S59 で「体の状態に結んだ保持」は二度とも資格を示せず、費用の単位を作者が選ぶ問題（KC の倍数）が解けていない（D-MEM §10・§12）。
- 予測器（TRM）はまだ個体に入っていない（C0〜C2 は未着手、U1〜U5 未決）。決定的な推論は Mac と Pi で一致（S60）。
- 受容器: r5 は雑音、r6 は時計で、毎歩変わりうる（項番146、S46）。

**答えてほしいこと**: (a) 何を読む痕跡か（ê か r か別の量か） (b) 何に作用するか (c) 痕跡の担体・維持費・薄れ方 (d) 「存続によって選ばれる」をどの水準（個体の中／系統）で読むか (e) 検査の形と反証条件 (f) 言い方の限定。

## §2 合意した紙の定義（〔暫定〕。凍結していない。ユーザーへの問い §4 と D-PRED U1・U4 が先）

- **位置づけ**: 退屈の本体は D-MEM §6 どおり **ê を読む版**（予測器の後、ユーザーの順を変えない）。r を読む版（R 痕跡）は代替ではなく**対照の腕**（予測器なしの安い機構で同じ上積みが出るなら、退けられるのは「この条件で ê が要る」という主張まで）。
- **名**: (c,d) 全体＝「低外れ応答の痕跡」、d 単独＝「平坦化の度合い d」、r 版＝「R 痕跡」。「低外れ」は「保存した ê が θ 以下」という操作的意味に限り、実際の外れの小ささは導かない。本文で「退屈」と書かない（観測名・ユーザーの語の引用だけ）。
- **作用の形（両版で共通、読む量だけ違う）**: π_u＝(1−λ_u)π⁰_u＋λ_u·U（U は候補集合 cs の一様、cs は S57 と同じ）。一行為の減重でなく平坦化で、重み 0 の行為も選べる。
- **一歩の順**: 前歩の (c,d) から仮 λ → 維持費 → 仮 λ>0 のときだけ支払いの判定 → 払えなければ d←max(0,d−δ)、その歩は再請求しない → 新しい d で最終 λ → π → 引く → Y_u → c の更新 → 行為の費用。ê_u は選択の前に保存した値を使い、同じ歩の π には戻らない。不払いは作用の停止ではない（最終 λ>0 が残りうる）。
- **〔判断点 O8〕数え c**: ê_{u,a_u}≤θ なら c+1、そうでなければ 0／捨てた案: 実現した外れで数える（「見込み」でなく結果を読むことになる）／確信度 中／codex 合意。
- **〔判断点 O9〕λ の形**: λ_u＝d·c/(c+W)、W＝4 は D-PRED の窓の作者の数の転用（新しい規則の選択であり、既存値との一致は妥当性の根拠にならない。適用の前に decisions-log に記録）。0≤λ≤d≤d0≤1／捨てた案: 閾値の歩数で 0/1 に切る（作者の数が増え、効きが段になる）／確信度 低／codex 合意（転用は記録の対象と）。
- **d**: 出生 d0。払えれば保たれ、払えなければ一段減る。d を上げる更新則はない（言えるのはここまで。「最大化の向きを持たない」とは言わない）。d は作用と支払い不能の履歴を残す状態で痕跡に当たるが、**低い ê の履歴そのものとはまだ区別が要る**。
- **〔判断点 O10〕θ**: 一つだけ。C0 の検証の種子（退屈の評価とは別）で、凍結した予測器を UNI の腕で走らせた記録の、全個体・全歩の選んだ行為の保存した ê の中央値（重みなし、候補が一つの歩を含め、行為なしの歩を除く。偶数件は中央の二つの平均、0 件なら段を止めて「測れない」）／捨てた案: min(p,1−p) との比（尺度と分母ゼロの問題）、腕ごとの θ（基準が腕で変わる）／確信度 中／codex 合意。
- **腕**: 無痕跡／作用／遮断（同じ規則で c・d・支払いを回すが π に混ぜない）／遮断＋くびき（自分の c・d・支払いを持たず、作用腕の記録した歩ごとの支払い額を同じ位置〈維持費の後・行為の費用の前〉で体から抜く。全額払えなければ払わず「くびきの不払い」、部分払いなし。記録額 0 の歩は抜かず不払いに数えない）。＋R 痕跡の腕（対照）。
- **くびきの比較の成立条件**: (i) 不払いの回数の差 (ii) 歩ごとの実支払い額の差の総和 ÷ 作用腕の実払いの総額、の両方が凍結した幅の内。作用腕の実払いの総額が 0 なら (ii) は作らず比較不成立・帰属保留（比を 0 と扱わない）。
- **採用**: 作用 > 遮断・遮断＋くびきの両方、かつ 作用 ≥ 無痕跡（費用込み）。量は決めた歩 T の全個体の生存の割合。幅と種子の数は凍結。判別不能は採用に数えない。
- **反証**: (i)(ii) とも許容内で、遮断＋くびきが作用腕との差を再現する（＝負担だけで差が出る、S59 の型）。**「再現」の判定は codex の提案を採る**: 差の区間（種子での再標本化、水準は凍結）の全体が ±幅の内なら「再現した」、一部が外なら判別不能（点推定が幅内なだけなら「観測差が幅内」とだけ書く）。この最後の点は codex の challenge を claude-lab が採ったもので、codex の確認はまだ。
- 作者の数の一覧（凍結の対象）: d0、δ、費用の単位（未決）、θ（データから）、W（転用）、採用・再現・くびきの幅、再標本化の水準、種子の数、T。

## §3 割れた点
- **〔判断点 O11〕「存続によって選ばれる」をこの定義が満たすか**: Opus は「個体の中では払える間保たれる（D-MEM §7 の B、存続の条件）まで、系統の比較は存続への寄与まで」と書いた。codex も「選ばれた事実ではない」で一致。満たすとは**二人とも言わない**。語の意味はユーザーへ（§4）。
- 費用の単位: 二人とも決めない（S58・S59 の型）。下調べで「縛りにならない」と「負担そのものの効果」を見分ける関門を置くことに合意。それぞれを何で判定するかは凍結の前に決める。

## §4 ユーザーに決めてほしいこと
- **B1「存続によって選ばれる痕跡」の「選ばれる」の意味**: (ア) 個体の中で、体が払える間だけ保たれる（払えなければ薄れる）こと／(イ) 痕跡を持つ個体と持たない個体を比べ、存続に寄与すると確かめられたものを系統に残すこと（作者の選び）／(ウ) 害に応じて調整されることまで含む（今の定義では言えない）。勧め: (ア)＋(イ) を別々に言う。理由: 今の基体には増殖も継承もなく、(ウ) を示す機構がない。
- **B2 費用の単位**: S58・S59 の二つの失敗の型をどう避けるか。今は未決のまま下調べの関門で見分ける案。
- **B3 D-PRED U1・U4 との関係**: ê 版は ê が行為に作用する初めての段になる。U4 の勧め（ê は退屈の段まで記録だけ）とは整合するが、U1（(a) 凍結の重み）だと ê は合成の世界で学んだ値で、生の世界の「低外れ」を読めるかは別に照らす必要がある（D-PRED §2「生の世界へ」）。
