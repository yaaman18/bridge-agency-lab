## 0. 確認した事実
- F1 ラボの q の読み（D4 R3-a、decisions-log #5）: q＝**確かめられた随伴**（駆動した結びつきの行為のあとに、世界の答えが来た）。sg＝確かめなしでも駆動を続ける傾向。bin3 の答えは二値（答えられたか）で、量の大きさ（報酬の多さ）ではない（`core/circuit.jl:155–160`、統計は 0/1）。
- F2 bp（`bp:README.ja.md:24・53`）: 「維持は最大不動点であって、最大化されるべき報酬ではない」「最適化の物語を語らない」「対象層は外部 set point と到達可能な終対象を禁じる（M4）」。M2 は α ⊣ σ（行為と感覚のガロア接続）、M3 は Act≠∅。
- F3 S33（README 項番133）: 宣言 α(m0)＝∅（m0 の行為は世界のどこにも届かない、177 事象で反証されず）。m0 は確かめられず、休みの区間はほぼ idle の優先の一歩。m0 の系統は生存 75/80（m0 なし 80/80）。
- F4 休みの定義 r2（`notes/R-rest-def.md` §3）は価値（休むと得をする）と費用の低下を入れない。系の境界＝回路＋物質の身体。

## 1. 叩き台の命題
- T1（確かめは随伴の証拠で、報酬ではない）: このラボで「確かめ」は、行為に世界の答えが随伴したことの証拠であって、「その行為が良かった」の評価ではない。休みの確かめを「休んで得をした」で作ると、bp の言う最適化の物語（F2）を対象層に持ち込む。
- T2（休みには確かめる世界の随伴がない）: α(m0)＝∅ なので、休みには世界の側の帰結がない。だから F1 の意味の確かめ（世界の答え）は休みには**原理的に来ない**。休みの確かめを作るなら、世界ではなく**自分の身体**との随伴（内受容）を、回路が読む新しい通り道として足すことになる。これは学習の規則の追加ではなく、身体→回路の新しい経路の追加。
- T3（候補とその問題）:
  - c1 身体の量が閾値より下がらない → 固定の目標値（set point）で M4 に反する。採らない。
  - c2 その歩の支出が、直前の行為の歩の支出より小さい → 規則の上でいつも真（休みの歩は MCOST が 0）。確かめが情報を持たず、毎回確かめられて休みが育ち続ける。随伴の証拠ではなく報酬に近い。
  - c3 両区画の y が 0 の歩に休んだら確かめ（「食べても答えはなかった」の確かめ）→ 回路はもう r3・r4（y＝0）を読んでいる。区画運動の確かめ（答えがあった）の裏返しに見えるが、実際は「答えがないときは休むのが正しい」を設計者が入れている。随伴の確かめ（起きたことの証拠）ではなく、反事実の評価。
  - c4 休みは確かめない（第一段のまま）。休みは「確かな行為の候補がないとき」に生じる（S33 の 92%）。維持に応じた休みは、休みの側ではなく、**行為の側の駆動が身体の状態に応じる**（内受容の受容器が区画運動の駆動に入る）ことで生じうる。
- T4（claude-lab の推す案）: 休みに固有の確かめは作らない（c4）。理由: c1 は M4 に反し、c2 は報酬で、c3 は設計者の規範の注入。どれも F1 の「確かめ＝随伴の証拠」に合わない。代わりに、第二段の問いを「休みをどう確かめるか」から「**活動の強さが身体の状態に応じる経路をどう作るか**」（定義の D-d、結びつきの調整）に置き換える。その最小の形は、身体の状態を読む受容器を足し、その受容器から区画運動・m0 への辺を今と同じ規則（確かめは世界の答えだけ）で学ばせること。
- T5（bp への提案が要る点）: 内受容の受容器を足すと、回路の ε（環境の特徴）に**身体の状態**が入る。M2（α ⊣ σ）は行為と世界の感覚の接続で、身体の状態は系の境界の内側（F4）。身体を環境の特徴として ε に入れてよいか、別の型にすべきかは bp の M2・DC の読みに触れる → BP4 の候補。

## 2. 論点
- Q1 T1 の「確かめは報酬ではない」は、今の bin3（二値）の読みとして正しいか。bin3 の答えも「餌が来た＝良い」を設計者が入れているのではないか（そうなら c3 と区別できない）。
- Q2 T2 の「原理的に来ない」は強すぎないか。
- Q3 T4 の置き換えは第二段の放棄ではないか、それとも問いの改善か。
- Q4 T5 の内受容の受容器は ε に入れるべきか（hSMC の対象になるか）。

## 3. r2 締め（往復1〜3、両者 accept。§1・§2 に優先）
- T1 の直し: このラボの確かめは、世界の規則が定める結果の事象（答え d＞0）と、受容器の状態との**観測上の随伴**の検出（cOn・cOff の対比、`circuit.jl:157–197`）。因果（受容器が答えの確率を変えた）までは示さない。BODY では答え＝取り込みなので、随伴の記録と「養分が来た」の選別は同じ事象で分けられない（「確かめは報酬ではない」とは言わない）。c3 にも同じ帰属の基準（休みがその観測の起こりやすさに関与したか）を要求する。
- T2 の直し: 「現行の行為の帰属と確かめの規則では m0 は確かめられない（答えは onPatch にだけ定義）」まで。原理的な不可能は言わない。
- c1〜c3: 検出の閾値は set point（追従の目標）ではない。c2 の恒真性は MCOST＞0 と体から払えることに依る。どれも報酬とは決めない。
- 内受容→区画運動の辺が確かめられるかは、身体とたまり・行為の履歴の相関しだいの経験の問い（「何も起こさない」は撤回）。
- **第二段の目的**: 休みの選ばれ方が身体の**水準**に応じること（増減は含めない）。試しの始めの自分の Q との比較なら、言えるのは「初期の水準を下回った（上回った）ことへの応答」まで。反証: 同じ写しから体の物質だけを変えた分岐（他の入力・活動の可能性が同じ）で休みの選択が変わらない。その分岐が作れなければ比較の不成立（棄却ではない）。
- 候補: **S-a** 生まれつきの結びつき（内受容の受容器→m0 を q0＞0 で配線、規範は構造として入る）、**S-b** 学習（m0 を身体の事象で確かめる新しい規則、規範が学習の目標に入る）。claude-lab は S-a を推した。S-a の実装は、e_b の有無で m0 の勝敗が反転する条件（競合側の conf と同点時の順位を含む）を示してから。到達しうる状態でその条件が成り立たなければ、その配線案を棄却。
- H2（案、BP4 に依る）: 身体の量を読む受容器 e_b を回路の受容器として扱う。参照を試しの始めの Q にする規則は設計者が与えるもので、それが M4 の「外から注入される set point」に当たるかは**BP4 の判定の対象**（H2 で確定しない）。e_b が α に入らないことと、行為が身体 Q を介して e_b を変えうること（間接の経路）は分けて点検する。H2 が差し戻されたら、測定の記録は残し、撤回する解釈を明示する。

## 4. S-a の配線の設計（往復4、両者の整理。実装は BP4 のユーザー判断の後）
- 向きの問題（claude-lab が往復4 で提起）: §3 の e_b（Q が始めより小さいとき m0 へ）は、体が減っているときに採食を減らす向き。生き物の休みに近いのは満ちたとき（e_s: Q が始めの自分の Q 以上）。ただし (1) 向きの優劣は仮説（休みの消費の減りを含む収支を測っていない。S33 の生存 75/80 は育ちを含む総差）、(2) 「Q≥Q0」は試しの始めには必ず成り立ち、飽食を保証しない（「満ち」と呼ぶならこの限界つき）。
- 辺の案: (A) e_s→m0 だけ q0＝1、(B) c1・c2→m0 も q0＝1。(B) は e_s がなくても区画運動の勝者の conf が 1 以下の歩で m0 が勝つので、「開始時以上のときにだけ休む」を保証しない（言えるのは「開始時以上なら休みの順位を追加で上げる」まで）。
- 反転の条件（codex 往復4-4・5）: 同じ状態で e_s だけを切り替え、区画運動の順位が変わらないなら、勝者が反転する必要十分条件は R₀(m0) ≺ R(W) ≺ R₁(m0)（R は最後の同点の処理までの全順序、W は区画運動の最上位、R₀・R₁ は e_s なし・ありの m0 の順位）。(B) では「K＝2 で e_s なしの同点で m0 が負ける」か「K＝3 で e_s ありの同点で m0 が勝つ」（K＝W の conf）。(A) は K＝0／1 の同点の条件。Lean の命題にはまだしていない。
- 検証の手順（案）: 凍結した予測のもとで、未使用の種子で、K だけでなく下位の順位・辺の q≥1・点灯の条件を記録し、反転の条件を満たす歩を数える。0 なら凍結した試験の集合でその配線を棄却（全状態で到達不能の証明ではない）。
- ユーザーの判断に回すもの（BP4 に追記）: e_b／e_s の**向き**（減ったら休む／始め以上なら休む）と、生まれつきの**辺の集合**（A／B）。どちらも規範の選択。承認の前は条件の命題までにとどめ、試算の前に予測と sha を凍結する。
