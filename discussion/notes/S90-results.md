## 3. 推論（確認した事実と厳密に分離）
1. **なぜ S90-E3 が外れ（全容量・全層で Brier 改善）たか**:
   - 表版 L2L-T（S89）の O1 と異なり、L2L-TRM の R-MID は `(k, a)` 鍵単位に厳密局所化され（他鍵・`rate(a)` への波及なし）、かつ K-UNIQ-CLEAR が TRM の回復済み鍵を自動消去（`C130` で 272 回、結果として `|M|` 中央値は 130 中 `16` に抑制）するため、逆バイアスの蓄積が起きなかった。
   - むしろ、TRM がまだ適応しきれていない `init`（`ΔBrier = -0.42 〜 -0.53`）や `switch`（`-0.019 〜 -0.117`）に加え、`steady` 区間の局所誤りでも直後の再訪時に `0.5*(p^TRM + y)` が正答側へ押し戻したため、全容量で `acc_ON - acc_OFF > 0`（`C1` `+25.8%`, `C2` `+15.7%`, `C130` `+2.7%`）となった。`C130` で 1 ヒットあたりの改善が小さく見えるのは、既に TRM が正しい飽和域の鍵でも `y` 一致スロットがヒットし続ける（`dp>0 & dpi==0` が 5,223 件、中央値 `-1.875e-5`）ことによる希釈であり、全歩合算の改善幅は `C130 (-0.00414) > C2 (-0.00274) > C1 (-0.00198)` の順になっている。
2. **なぜ S90-E2（`h=1000` の `C130` での `ΔD`）が負（`-0.0150 / -0.00539`）に反転したか（R-MID 縮小写像によるアンカリング仮説）**:
   - S87 の `TrmL` 単体（`C0_B8`）では、1 歩反転がミニバッチ SGD（`train_step!`）を通じて重み全体へ伝播し、`h=200 → 1000` でプローブ集合 $Q$ 上の双子差 `D_s(C0_B8)` 自体が大きく成長する（S87 中央値: `h=1000` で `0.021〜0.043`）。
   - 一方 `C130` では main と twin の記憶 `M` に 10〜22 個の共通エントリ（同一 `(k,a) -> y`）が D1 退去なしで残留する。プローブ $q \in Q$ が main・twin 共通のスロットにヒットすると、R-MID の `p_out = 0.5 * (p^TRM + y)` により両者の差は厳密に `0.5 * |p^TRM_main - p^TRM_twin|` へ **半減（縮小写像）** される。
   - したがって `h=50` では `s` 断片固有の差分が辛うじて勝つ（`C1 +0.0107 > C2 +0.0090 > C130 +0.00019`）が、`h=200 → 1000` で TRM 本体側の双子差が育つほど、`C130` の共有スロット群による **R-MID の 1/2 遮蔽・アンカリング効果** が `s` 断片の直接上乗せを圧倒し、`D_s(C130) < D_s(C0_B8)` となる。`C1`/`C2` は占有数が 1〜2 個と小さく共有遮蔽が弱いため、`h=50, 200` で正の `ΔD` を保った（`h=1000` では D1 退去で `s` 断片も失われ 0 付近に収束）。
   - これはオフライン固定軌跡（メモリ出力が次歩の行動・TRM 学習へ還流しない開ループ合成）特有の現象である可能性が高く、**「予測精度を改善する安定アンカー（Brier 改善）」が、同時に「重み側の摂動差を出力面で半分に抑え込む（`ΔD < 0`）」という二面性**を示している。

  - Layer 1 は配線確認のみ、現行系について `phenomenal_claim = :not_certified` 固定。
  - R1 / R-MID / K-UNIQ-CLEAR / D1 の規則変更・未見種子の開封は本段では一切行わない。
- **次段の提案（ユーザー判断待ち）**:
  1. **提案 A（L5 `(β)` 閉ループ身体統合の 3 者 D/S-R へ進む）**: 既に紙設計草案 `discussion/notes/D-L5-BETA-AUE-SEAM.md` を作成済み。S90 で `[memory]` 固定バイト契約（`mem_core.jl`）・R-MID・K-UNIQ-CLEAR・D1 の配線とオフライン Brier 改善が確認されたため、次は「記憶出力が次歩の行動・代謝・生存へ実際に還流し、前払い維持費 `K_MEM` が身体残高を削る」閉ループ試験（`aue_seam`）へ進む。
     - **反証条件**: 閉ループ身体統合でも、`C > 0`（前払い維持費あり）が `C0_B8` に対して生存歩数・予測適合・応答指標のいずれでも有意差を出せず、あるいは維持費超過で即死するならば、`K_MEM`・演算予算（B2）または R-MID の設計前提を見直す。
