## 0. 確認した事実
- Y-F1 S12 の軛（`lab:experiments/clamp.jl`）: 分岐 Z の更新 τ（t＋1〜t＋15）で、経路 ch（感覚 y_sense または答え y_offer）の入力を、同じ分岐点からの無介入の分岐 N の更新 τ が読んだ本物の y_N(τ) に置き換える。
  y_N(τ) は、t の状態・N の環境（交換していない予定表とたまり）・N の中での回路自身の行為（取り込みがたまりを減らす）で決まる。
- Y-F2 回路の入力は y（二つの経路）・時刻・雑音の乱数・保留（BODY では空）だけ（`core/circuit.jl:100`・`:117`・`:151`）。両方を軛すると無介入とビット単位で同じ（S12 CP1）。
- Y-F3 P078（`papers/text/078.txt:19–23`）: 意味情報の必要性は、系と環境の相関をかき混ぜる反事実の介入で定める。

## 1. 提案（定義）

**DY1（自分の N への軛 Y0 が崩すもの）**: 経路 ch について、t より後で
- (a) ch の入力が**介入した後の環境 Z** に依ること（Z のたまり・予定表の変化が ch に届かない）。
- (b) ch の上の**感覚運動の輪**（Z の中での回路の行為が、たまりを通って ch の入力を変えること）。閉じた輪が開いた輪になる（P031 の「習性 habitat」から「環境 environment」への移り）。
**保つもの**: ch の入力と、t までの共通の履歴（t の状態）との相関、元の環境（N）との相関、N の中での回路の行為との相関。
したがって Y0 は「系と環境の相関をかき混ぜる」介入ではなく、「介入した後の環境と行為の輪から ch を切り離す」介入と呼ぶ。

**DY2（かき混ぜに近づく軛の階）**: 崩す相関を段階で増やす候補。
- Y1（別の物の N への軛）: 同じ予定表・同じ分岐点の時刻で、**別の種子の物**の N が読んだ y の列を与える。この系に固有の履歴との相関も崩す（予定表の統計は保つ）。
- Y2（並べ替えの軛）: 自分の N の y の列を窓の中で並べ替える。時間の構造も崩す（値の分布は保つ）。
- 意味情報（P078）に近い読みを言うには、少なくとも Y1・Y2 で生存（または維持の量）の差を測る必要がある。S12 は Y0 だけで、生存ではなく 15 歩の行為の移りを測った。

**DY3（言わないこと）**: Y0 の結果から意味情報の量、相関の大きさ（相互情報量）を言わない。軛は入力の列を与えるだけで、回路の状態は書き換えない（読む・使うの区別、Y-F2）。

## 2. 論点
- Q1: DY1 (b) の「輪が開く」は、ch の入力が Z の中の回路の行為に依らないことで定義してよいか（N の行為には依る）。
- Q2: Y1 で「別の物」をどう選ぶか（同じ腕・別の種子、同じ予定表・同じ t）。別の物の N が窓の中で死ぬときの扱い。
- Q3: Y2 の並べ替えは、窓の中の y の値の多重集合を保つ置換のどれにするか（先に固定した一つの置換、または種子つきの乱択）。
- Q4: これらの定義を D5 R4-c の「軛を相関のかき混ぜと呼ぶ前に崩れるものを定める」の答えとして締めてよいか。

## 3. r2（往復1 の 1〜8 を反映、修正版）

- **DY1′（Y0 が切る因果の経路）**: 自分の N への軛 Y0 は、置き換える 15 更新の範囲で、**介入した後の環境 Z と Z の中の回路の行為から、経路 ch の入力への因果の経路を切る**。条件: 軛の元の N は Z から影響を受けない（別の分岐）。
  これは統計の上の無相関を意味しない。共通の履歴・予定表・もう一方の経路を通して、Z の行為と ch の入力の相関は残りうる（「崩す相関」ではなく「切る因果の経路」と呼ぶ、往復1-2）。
  開くのは **ch を通る輪**で、もう一方の経路を含む系全体の輪ではない。P031 の習性→環境の移りとの対応は解釈の上の仮説にとどめる（往復1-3）。
- **DY2′（候補としての Y1・Y2）**: Y1 は「受け手自身の履歴から入力の列を作る依存を外す」軛（提供元の物の N の列を与える）。同じ予定表・時刻から来る相関は残りうる（往復1-4）。
  提供元の選び方・対応づけ・窓の中で死んだときの扱いは実施の前に固定し、窓の中の生存で提供元を選ぶなら結論はその選び方を含む集団に限る（往復1-5）。
  Y2（並べ替え）は多重集合を保つが、時間の構造を必ず壊すとは限らない（恒等の置換・定数の列が反例）。壊す対象（時刻との対応・自己相関・二つの経路の同期）と、二つの経路で置換を共有するかを先に固定する（往復1-6）。
  Y0・Y1・Y2 を相関を壊す単調な階段とは扱わない。意味情報（P078）への対応には、対象の相関・介入の分布・維持の指標の定義が別に要る（往復1-7）。
- **DY3**（そのまま）: Y0 から意味情報の量・相互情報量を言わない。
- 締め（往復1-8）: 「Y0 が切る因果の経路と、残りうる相関」の定義はここで締める。Y1・Y2 の測定の仕様は未決として残す。D5 R4-c の宿題（軛を相関のかき混ぜと呼ぶ前に崩れるものを定める）への答えは、「Y0 は相関をかき混ぜるのではなく、ch への因果の経路を切る」。
- 元に戻す方法: 軛の実装（S12 の clamp.jl）や回路の入力の事実（Y-F2）が変われば、この定義を見直す。
- 往復2 の限定（codex 3・4）: Y1 の提供元の選び方・対応づけが受け手の履歴に依れば、選び方を通して依存が残る（S 段で点検）。Z の変更が提供元の N や置き換えの値に伝わる経路が見つかれば、DY1′ の適用を撤回して見直す。両者 accept（往復2）。
