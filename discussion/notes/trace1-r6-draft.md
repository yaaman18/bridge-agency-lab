## 0. 何を変えるか
- r5 までは「内側の時計」というスカラーが形成区間で進み通常区間で進まないことを、閾値と率で判定した。r6 では時計を要件から外す。内側の時間を、**痕跡の前順序**（どの出来事が、いまのふるまいに残っているか）として書く。
- 定義は、個体の入出力の型の中の操作だけで書く。ふるまいが同じで内部の違う実装（双模倣）で値が変わらない（H11、S86 で確認）。個体の中身（表・ニューラル網・固定のプログラム）によらず、同じ式で当てる。

## 1. 道具立て
- 個体は余代数とみる: 状態 x、一歩の法則 x' = f(x, e)、入力 e = （文脈、行為 a、結果 y ∈ {0, 1}）、出力は次の入力への予測。
- **像** [x]: 状態 x から先の、あらゆる有限の入力の列に対する出力の列（終余代数への唯一の射の像）。[x] = [x'] ⇔ x と x' は双模倣。
- **反転の双子** x^{¬s}_t: 例 s の結果だけを 1 − y_s にし、ほかの入力は同じ列を受けた状態（入力は型の中にとどまる）。

## 2. 定義
- D1 刻み: t で刻む ⇔ [x_t] ≠ [x_{t−1}]。
- D2 痕跡: s ≺ t ⇔ [x_t] ≠ [x^{¬s}_t]（s の結果がいまのふるまいに残っている）。
- D3 忘却の時刻: τ_s = min{t ≥ s : [x_t] = [x^{¬s}_t]}（なければ ∞）。
- D4 測り: 場が固定した探りの入力の集合 Q と、ふるまいの距離 dist（全個体で一つ。当面は Q の上の予測の平均の差。BP14 (b) が決まったら合わせる）で、D^Q_s(t) = dist(O_Q(x_t), O_Q(x^{¬s}_t))。

## 3. (i) 定義から出る恒等式（試験では関門として照合する）
- I1 不変: 双模倣な実装は、刻み・≺・τ_s が同じ（S86）。
- I2 下に閉じる: s ≺ t' かつ s ≤ t ≤ t' なら s ≺ t。よって痕跡のある時刻は区間 [s, τ_s) で、像の上で一度消えた痕跡は戻らない。証明: 法則が決定的で、像の同値はどの許容入力の一歩でも保たれる（双模倣）。時刻 t で [x_t] = [x^{¬s}_t] なら、同じ後続の入力に沿って t' まで同値が保たれる。対偶で I2〔codex P1〕。
- I3 測りの健全さ: s ≤ t ≤ t' のとき、ある t'で D^Q_s(t') > 0 なら s ≺ t（t から t' までの入力と Q がふるまいの違いの証人）。D^Q_s = 0 は忘却の証拠にならない（TRM で後に正になる原点が出れば、その実例。S87 E2）〔codex P2〕。t < s では双子は主と同じ状態なので ≺ を問わない。
- I4 忘却の証明: 双子と主の状態がビット一致（または既知の双模倣の関係にある）なら [x_t] = [x^{¬s}_t]（S87 の WIN）。
- I5 固定のプログラム: 刻みも痕跡もない（≺ は空）。
- 限界: I4 の証明は、状態が一致する法則（窓など）でしか出ない。減衰や分散した重み（FGT・TRM）では「消えた」は出ず、痕跡は「残る」か未決になる〔neon N2〕。
- 三値: 「残る」（I3 の証人あり）／「消えた」（I4 の証明あり）／未決（どちらもない）。未決はどちらにも数えない。
