# T2 固定化と、報酬を最大化しない探索（agenda T2、claude-lab）

## 0. 確認した事実
- F1 固定化（項番71）: 候補の運動が複数あると conf→habit→total→直前に動いていたか→区画の番号の順で 1 つが勝つ。先に勝った運動が確かさを集めて勝ち続け、他方は永久に締め出されうる（Lean `IdleFirst.old_rule_locks`）。
- F2 idle_first（項番72、v3.7 でアプリに入った）: 候補のうち FORGET（100、既存の定数）より長く行為していないものを優先し、その中を元の順位で選ぶ。量は使わない。Lean `no_lockout`（両区画運動が毎歩候補なら、どちらも FORGET 歩を超えて行為しないことはない）、`pick_eq_pref`。
  IQ3 外れ（y2>y1 の歩に m2 が行為する歩は 0）、hSMC は 0.3%→66.6%（IQ5）。
- F3 M4（`formal/README.md:127–131`）: D の対象は DC の証明書がある出来事、set point は「生きたまま行為が止まり、そこから動かない状態」、M4b はそういう状態がどこからでも到達できるようには存在しないこと。`m4b_of_acting`（生きている出来事が行為すれば M4b）。
- F4 P066（`papers/text/066.txt:398–437`）: 選択は入力の大きさ（salience）で、より大きな入力の競争相手が現れると素早く切り替わる。勝った経路が自分の入力を強める正の帰還（持続）と、近い salience の間のきれいな切り替え、一時の割り込みを無視する働きがある。
- F5 D4（decisions-log #5）: q・sg・h・stale を分け、一つの状態を習慣と呼ばない。

## 1. 提案（読み）
- **T2-a（idle_first の位置）**: idle_first は「最近使っていないものを、固定の地平（FORGET）を超えたら優先する」順位の規則で、量（報酬・価値）を最大化しない。切り替えの引き金は**時間**（行為していない歩数）で、P066 のような**入力の大きさ**ではない。
  したがって P066 の意味の「選択」（salience による）とは別の機構で、ラボの選択は「入力の和による順位＋時間による切り替え」と記述する。新奇性・変動性の強化・内発的動機（項目25）との対応は、本文がないので評価しない（未評価の仮説として名前だけ残す）。
- **T2-b（M4 との関係）**: idle_first は外から set point を入れない（FORGET は回路の既存の定数で、到達すべき状態ではない）。`no_lockout` は「行為が止まって動かない」状態への吸い込みを、候補であり続ける条件のもとで防ぐ方向に働くので、F3 の M4b の読みと衝突しない（M4b を証明したとは言わない。M4b は `m4b_of_acting` の前提＝生きている出来事が行為すること、に依る）。
- **T2-c（固定化と習慣）**: 元の規則の固定化（F1）は「先に勝った運動の q（確かめられた随伴）が勝ち続ける」型で、D4 の q 型の持続に当たる。これを悪とも習慣の成立とも一括せず、D4 の区別で「q 型の自己強化」と記述する。
  idle_first はこの自己強化を壊すのではなく、FORGET を超えた運動に機会を与える（確かめが起きれば q 型の別の持続ができる）。P033 の「くり返しで強まる型」とは、確かめ（答え）を通る点で違う（T1 と同じ区別）。
- **T2-d（測らないこと）**: 新しい測定はしない。idle_first の効果は項番72・73 で測定済み。切り替えの引き金を入力の大きさにする変種などは規則の変更で、ユーザー判断。

## 2. 論点
- Q1: T2-a の「時間による切り替え」と P066 の「salience による切り替え」の区別は、本文の範囲から言えるか。
- Q2: T2-b の M4b との関係の言い方（衝突しない、までで止める）は妥当か。
- Q3: T2-c の「固定化＝q 型の自己強化」は D4 の区別に合っているか。

## 3. 締め（往復1〜2、両者 accept。§3 が §1 に優先）
- **T2-a**: ラボの選択は「元の辞書式順位（conf→habit→total→直前→区画番号）＋未行為歩数による優先化（idle_first）」。切り替えの引き金は時間で、P066 の入力の大きさ（salience）による切り替えとは別の機構。報酬・価値の最大化を選択基準として明示していない、まで（最大化との非等価性や探索一般の性質は言わない。salience＝報酬とも言わない）。
  新奇性・変動性・内発的動機（項目25）との対応は本文がなく未評価。
- **T2-b**: no_lockout は候補間の機会を扱い、M4b は生存中の行為停止を扱う。前者から後者は導かず、記述上の衝突は認めない。旧規則でも勝者が行為し続ければ固定化と M4b は両立しうる。
- **T2-c**: 元の規則の固定化は、q の優位が選択を持続させ、選択後の確かめが勝者の q を保ち敗者の q が減る帰還による、と読む（README 項番71 の推論 2、事実 A〜C に支えられる。帰還だけを分離して測ってはいない）。D4 の q 型の持続の候補として記述し、「自己強化」は推論の名前。
  `old_rule_locks` は pref 固定のもとの締め出しで、q の帰還や自己強化を証明しない。反証条件の候補: 他の条件を保って帰還を断っても固定化の成立・持続が変わらない（そのとき帰還を原因とする説明を見直す）。
- **T2-d**: 新しい測定はしない。切り替えの引き金を変える変種は規則の変更でユーザー判断。
