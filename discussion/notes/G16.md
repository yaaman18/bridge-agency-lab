# G16 R-CON-2 構成体の消滅の不可逆性・同一性・生存代理（gaps C、claude-lab）

- 日付: 2026-11-08。状態: **締め r2**（往復1〜3。§4 が優先）。codex（gaps C 往復1-9）: 状態・同一性・許される遷移を先に定義し、それまでは結論として扱わない。範囲: 定義（ラボの読み）と、定義の上の小さな命題。bp の定義・Σ1 との対応は defer のまま。
## 0. 確認した事実（`core/matter.jl:83–131`）
- 状態: 場所ごとの A（自由の物質）・B（結んだ物質）・C（構成体の印、0 か 1）、ポート、時刻。構成体＝C[i]≠0 の場所。
- 消滅: 構成体の場所で B[i] < THETA_EXIST なら C[i]＝0（結んだ物質は A に戻る、died を数える）。
- 生成: (i) 分裂: B[i] ≥ THETA_DIV の構成体が、空いた 4 近傍のうち A の最も多い場所 j に B の半分を渡し C[j]＝1（born）。(ii) spontaneous が真のときだけ、空いた場所で A ≥ 2·THETA_EXIST なら自然発生（既定は偽、A-gen: 構成体は構成体からのみ）。
- R-CON-1（成立、記述）: 既定則で場全体の C≡0 は吸収的。
## 1. 提案（定義）
- **D-a 状態**: 上の (A, B, C, port, t)。
- **D-b 同一性（系譜）**: 構成体の同一性は**系譜の節**で数える: 出生（初期の種まき、または分裂で C[j] が 0→1 になったとき）に新しい節が始まり、消滅（C が 1→0）で終わる。同じ場所に後で現れた構成体は**別の節**（分裂の子）。場所による同一性は採らない（場所は再び占められうる）。
- **D-c 許される遷移**: 既定則（spontaneous＝偽）の step! だけ。救出・物質の注入・規則の変更は遷移に含めない（D0・約束: 作る側の介入は系統の側）。
## 2. 命題（定義の上）
- **P1（形式、Lean で先に）**: 既定則の抽象の一歩で、場所 i が C 0→1 になるなら、その一歩の始めに i の 4 近傍に B ≥ THETA_DIV の構成体がある（分裂からだけ）。系: C≡0 は吸収的（R-CON-1 の形式の版）。
- **P2（定義からの帰結）**: D-b のもとで、消滅した節は再び現れない（同じ場所の再占有は新しい節）。これは定義の帰結で、経験の主張ではない。
- **照合（Julia）**: 既定則の走りで、すべての 0→1 の遷移に分裂した近傍があったこと（`ctl.on_divide` で数える）。
- **言わないこと**: 生存代理（alive_somewhere を個々の構成体の生存と読むか）、構成体での L3R の対応づけ（G19 から）、Σ1 との対応は、bp の理論に触れるので defer（bp-proposals に出すのはユーザーの事前承認の後）。
## 3. 論点
- Q1: D-b の系譜の同一性は、D0（個体の同一性、約束）と食い違わないか（構成体は個体ではなく個体の構成素）。
- Q2: P1 の抽象化（場の Lenia の流れを捨て、死と分裂の規則だけを抽象する）の対応の取り方。

## 4. 締め（往復1〜3、両者 accept。§4 が §1〜§2 に優先）
- **D-a**: (A, B, C, port, t)。**D-c**: MATTER_DEF の値・トーラスの 4 近傍（`matter.jl:58`）・spontaneous＝偽・sources は既存のポートからの供給（evo_sources）・ctl は記録だけの hook（core の hook は C を書かない。`Ctl` の型は書き込みを防がないので、この限定を外したら対応を点検し直す）。救出・ポートの外からの物質・規則の変更は含めない。
- **D-b**: 同一性は履歴の上の系譜の節（種まきと on_divide に識別子、on_death で閉じる、同じ場所の再占有は新しい節）。構成体の節は個体ではなく個体の構成素の系譜（個体の同一性は系統の層の分岐の操作で扱う、`notes/D6.md:49`）。
- **P1（Lean、`formal/LabCircuit.lean` ConMatter、sorry なし、公理 propext）**: `divStage_source`・`step_source`（死の段の後に確定した分裂候補 order から、pick が 4 近傍を選ぶという前提 hpick・horder のもとで、一歩の後の構成体は前からあるか order の構成体の 4 近傍）、`empty_absorbing`（C≡0 は吸収的、R-CON-1 の抽象の版）。抽象系の性質で、Julia の実装との対応を証明したものではない。
- **P2**: D-b の定義の帰結（死で閉じた節は再び現れない）。物理的な復元不能性の命題ではない。
- **照合（予測なし、`experiments/con_lineage.jl`・`results-con-lineage.json`）**: 3 走（3000・3000・6000 歩）で出生 1371・1371・2529 がすべて親の 4 近傍で親は構成体、0→1 で出生のイベントのない場所 0、同じ一歩の死→再占有 490・490・958（新しい節）、**各走りの終了時に**閉じた節を持つ生きた場所 0（途中の時点の不変条件とは扱わない）。走り 1・2 はポートの資源 2000・300 で同じ結果（資源が拘束にならなかった）。
- **defer**: 生存代理（alive_somewhere と個々の構成体）、構成体での L3R の対応づけ（G19 から）、Σ1 との対応（bp に触れるのでユーザーの事前承認の後）。
