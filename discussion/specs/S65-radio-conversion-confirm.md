## 2. 凍結する C4 型換算規則（設計期間 8,643 行のみから算出、再適合なし）

設計期間 `out-72h/design_72h.tsv`（全 8,643 行有効、`fail == 0` 除外 0 件、SHA `5925386fa4a02791b72e190001d4bcf881d6a1c526853613115c44940569dcad`）の標本平均・標本不偏標準偏差を事前凍結する：
- 区画 1（Wi-Fi 強度和 `w_sum`）: $\mu_w = 297.20108758532916$, $\sigma_w = 39.79874519579147$
- 区画 2（Bluetooth 機器数 `b_n`）: $\mu_b = 2.9924794631493694$, $\sigma_b = 0.8134565410732445$

各期間（設計期間 `k = 0..8642`、確かめの期間 `k = 0..N_valid-1`）の有効行に対し：
1. 標準化実電波摂動：
   $$z_1(k) = \frac{w_{\mathrm{sum}}(k) - \mu_w}{\sigma_w}, \qquad z_2(k) = \frac{b_n(k) - \mu_b}{\sigma_b}$$
2. OneLife 収量 `g[k, a] ∈ {0..5}`（`synth_world.jl:30` と同一離散化）および二値応答 `Y[k, a]`:
   $$x(k, a) = 2.5 + 2.5\sin\!\left(\frac{2\pi \cdot 3k}{1000} + \phi_a\right) + 1.0 \cdot z_a(k) \quad (\phi_1 = 0,\ \phi_2 = \pi)$$
   $$g(k, a) = \operatorname{clamp}(\operatorname{round}(x(k, a)),\, 0.0,\, 5.0), \qquad Y(k, a) = (g(k, a) > 0)$$
   ※`3k` は有効行の 0 始まり通し番号による連続位相であり、再起動境界を跨いでも位相は連続に進む（起動数・境界位置は併記）。

## 3. 対照アブレーションと評価手順（設計期間学習 → 確かめの期間ゼロ再適合評価）

合成周期だけの空合格および「時間構造のない電波雑音」による空合格を双方塞ぐため、以下の **4 系列** を確かめの期間上で同一の行動列 `Mulberry(650001)`・同一ブロック分割で同時評価する（`RATE`・`TAB4` は各系列ごとに設計期間 `design_72h.tsv`［行動列 `Mulberry(650000)`］のみで個別学習して凍結）：
1. **`C4_full`（主対象）**: 合成周期＋実電波摂動 `(z_1, z_2)`。
2. **`C4_noradio`（合成のみ対照、記述併記）**: 同じ位相で $z_1 = z_2 \equiv 0$。合成周期（約 333 行 ≈ 2.8 時間）単独での `RATE - B1` を併記し、`C4_full` との応答不一致率 `radio_flip_rate`（各区画で $Y_{\mathrm{full}}(k,a) \neq Y_{\mathrm{noradio}}(k,a)$ の行割合）および $\mathrm{mean}|g_{\mathrm{full}} - g_{\mathrm{noradio}}|$ を測る。
3. **`C4_zshuf`（無記憶シャッフル電波対照、r3 で行ペア同一置換に確定）**: `C4_full` と同じ合成周期に対し、各期間内の行番号に単一の Fisher-Yates 置換 $\pi$（設計期間 `Mulberry(650003)`、確かめの期間 `Mulberry(650004)`）を適用し、行ペア $(z_1(\pi(k)), z_2(\pi(k)))$ を同時に並べ替える。各列の周辺分布だけでなく同一行の $(z_1, z_2)$ 同時結合分布も完全に保ったまま **時間順序のみを破壊する**。同一行動・同一ブロック上の対比較 $D_{\mathrm{shuf}} = \Delta(C4_{\mathrm{full}}) - \Delta(C4_{\mathrm{zshuf}})$（ここで $\Delta = L(\mathrm{RATE}) - L(\mathrm{B1})$）および $L_{\mathrm{B1}}(C4_{\mathrm{zshuf}}) - L_{\mathrm{B1}}(C4_{\mathrm{full}})$ により、実電波の時間構造が `B1` の追従利得を高めることを直接検証する。
4. **`C4_radio_only`（電波のみ対照）**: 合成周期を外した $Y_{\mathrm{radio}}(k,a) = (z_a(k) > 0)$（`w_sum > μ_w`, `b_n > μ_b`）。実電波単独のドリフト・飽和度・予測性を独立に観測する。

- **予測器（`[1/200, 199/200]` クリップ、二値対数損失 nat、行為等重み平均）**:
  - `RATE`（設計期間学習・凍結）、`TAB4`（`W = 4`, $\alpha = 1.0$, 1250 キー、設計期間学習・凍結）、`B1`（`P_DECAY = 8`, 初期 `m = [0.5, 0.5]`, 確かめの期間先頭から逐次更新）、および未来漏れ負対照 `LEAK`。
- **ブロック Bootstrap 設計（設計期間の行別損失差自己相関に基づく事前凍結）**:
  - 開封前に設計期間（`out-72h/design_72h.tsv`）の行別損失差 $\ell_{\mathrm{RATE}} - \ell_{\mathrm{B1}}$ の自己相関を計測した事実：`C4_full` は lag 30=`0.011`, lag 120=`-0.041` と急速減衰する一方、`C4_radio_only` は lag 120=`0.226`, lag 240=`0.179`, lag 360=`0.153` で相関が残り、**lag 720（6 時間）で `0.028`** へ落ちる。
  - よって **主ブロック長を `L_blk = 720` 行（約 6 時間、非重複、末尾の `< L_blk` 端数行は切り捨てて件数明記）** に固定し、感度として `L_blk ∈ {120, 240, 360}` も算出する。**各ブロック長 `L` ごとに `B = 5000` 回のブロック再標本添字列を `Mulberry(650002)` から 1 回だけ引き、全 4 系列（および `D_shuf` 対比較）で完全に同一の再標本添字を共有する**。
  - **保守判定規則（食い違い時の扱い）**: ブロック Bootstrap による P-S65-4 の判定には、**`L_blk ∈ {120, 240, 360, 720}` の 4 ブロック長すべての中で最も低い 95% CI 下限（$\min_{L} \mathrm{CI}_{\mathrm{lo}}^{(L)}$）** を用いる。※`L_blk = 720` は 72 時間で約 12 ブロックに限られ CI 推定が粗くなる旨を限界として必ず併記する。
- **主列種子の非消費**: 固定 RNG（`650000..650004`）のみを用い、合成世界の主列未使用種子（次番 `1110`）は消費しない。

## 5. 事前予測と反証条件（S-R APPROVE 後に `experiments/radio_confirm/predictions.toml` へ凍結）

- **P-S65-1（関門・データ品質）**: 全 7 関門が合格し、確かめの期間の有効行 `>= 7,000` 行・除外率 `< 2%`・同一起動内最大間隔（全行および有効行の双方）`<= 120 s` である。
  - *順序規則（r3 明文化）*: 全 7 関門のいずれかが失敗した場合は即停止し、P-S65-2〜5 は外れではなく **「未判定（UNDECIDED）」** とする。全 7 関門が合格し、かつ品質条件（有効行 `>= 7,000`・除外率 `< 2%`・最大間隔 `<= 120 s`）のいずれかが不成立の場合は、P-S65-1 を **外れ（MISS）** とし、P-S65-2〜5 の数値は算出して **参考記述のみ（正式確認とはしない）** として報告する。
- **P-S65-2（非飽和・多値収量）**: 確かめの期間の `C4_full` において、**両区画（`a = 1, 2`）とも**応答率が `0.15 <= P(Y_a = 1) <= 0.90` に収まり、**かつ両区画とも** 6 値収量 `g ∈ {0..5}` のうち少なくとも 4 値以上（`distinct(g_a) >= 4`）が出現する。
  - *反証条件*: いずれかの区画で `P(Y_a = 1) < 0.15` または `> 0.90` または `distinct(g_a) < 4` なら本予測は外れ（固定標準化 C4 は長期ドリフト・量子化で破綻したとして棄却）。
- **P-S65-3（実電波の応答反転寄与）**: `C4_full` と `C4_noradio` の応答不一致率 `radio_flip_rate` が **両区画（`a = 1, 2`）とも** `>= 0.05`（5% 以上）である。
  - *反証条件*: いずれかの区画で `< 0.05` なら外れ（実電波が二値応答を実質的に動かしていないため棄却）。
- **P-S65-4（実電波の時間構造と `B1` の非自明追従、3 条件の AND）**: 保守下限 $\min_{L \in \{120,240,360,720\}} \mathrm{CI}_{\mathrm{lo}}^{(L)}$ において以下 3 条件がすべて成立する（3 条件の個別の成否も必ず個別報告する）：
  - (a) `C4_full` で $\Delta_{\mathrm{full}} = L(\mathrm{RATE}) - L(\mathrm{B1})$ の保守 95% CI 下限 `> 0.05 nat`、
  - (b) `C4_radio_only` で $\Delta_{\mathrm{radio}} = L(\mathrm{RATE}) - L(\mathrm{B1})$ の保守 95% CI 下限 `> 0`、
  - (c) 対比較 $D_{\mathrm{shuf}} = \Delta_{\mathrm{full}} - \Delta_{\mathrm{zshuf}}$ の保守 95% CI 下限 `> 0`（周辺分布同一の無記憶シャッフル電波を実電波の時間構造が上回る）。
  - *反証条件*: (a)(b)(c) のいずれか 1 つでも下限が閾値以下なら P-S65-4 は外れとし、落ちた部分条件のみを厳密に特定して報告する（(a) のみ外れを電波単独の追従失敗とはみなさない）。`C4_noradio` の $\Delta_{\mathrm{noradio}}$ と $L_{\mathrm{B1}}(C4_{\mathrm{zshuf}}) - L_{\mathrm{B1}}(C4_{\mathrm{full}})$ も必ず併記する。
- **P-S65-5（`TAB4` 対 `B1`、点推定の探索的予測）**: `C4_full` において設計期間学習済み `TAB4` の点推定損失が `B1` を下回る（`L(B1) - L(TAB4) > 0`）。
  - *反証条件*: `L(B1) - L(TAB4) < 0` なら外れ、`== 0` なら引き分けと判定する（95% CI も併記するが判定は点推定に固定。損失差単独から敗因を電波ドリフトと断定せず、設計期間対確かめの期間の `w_sum`/`b_n` 平均・SD 推移を別途記述する）。
