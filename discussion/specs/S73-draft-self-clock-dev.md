## A. 自己基準の時計で TRACE-1 を分けられるか
- 時計（個体が自分で計算できる量だけを使う）: 本流の前向きの損失 ℓ_t（自分の予測、[1/200, 199/200] で切る）。
  - 窓 w（500 例）の平均 ℓ̄_w と、窓の直前の 3,000 例の自分の損失の平均 m_w を比べる。
  - 窓が「進む」のは ℓ̄_w − m_w > θ のとき。
  - L-REF・探り・写像の情報は使わない。
- 窓の置き方: S72 の TRACE-1 と同じ。
  - 誤作動の窓: R_0〜R_4 の末尾 1,500 例を 500 例ずつ、1 生 15 窓。
  - 検出の窓: [T_i + 1, T_i + 500]。
  - 対象の切替: S72 r4 段 1 で選んだ集合（d_i ≥ 3ε、ε = 0.0025）。全切替の率も主報告に出す。
- 合否: 各生で、誤作動率 ≤ f* = 0.10 かつ検出率 ≥ d* = 0.90。
- θ ∈ {0.005, 0.01, 0.02, 0.04}。L-FGT が全 4 生で満たす最小の θ を選ぶ。なければ「分離できず」。
- 比較のため、S72 r4 の L-REF 基準の時計（θ = 0.04）の結果を並べて出す。

## B. 同じ出来事への驚きが、経験の違いで分かれるか
- 対の個体: 各生で T_1 に本流を写し、二つの履歴に分ける。
  - H（本流の履歴）: [T_1, T_2) を π_1、続けて π_2、π_3 で T_4 まで。
  - H′（別の履歴）: [T_1, T_2) だけを π′_1（S72 の alts[1]）に替え、あとは H と同じ例・同じ写像で T_4 まで。
- 出来事: T_4 から 1,500 例、両方に π_1 を与える（同じ例、同じ写像）。
  - H にとっては、約 24,000 例前に経験した世界の再来。
  - H′ にとっては、未見の世界。π_1 は π_0・π′_1・π_2・π_3 のどれとも違う（S72 の作り方で保証される）。
- 驚きの量: 出来事の最初の 500 例で、自分の損失の平均から、出来事の直前 3,000 例の自分の損失の平均を引いたもの。A の時計と同じ形で、閾値の前の値。
  - S_H と S_H′ を出し、個体差 D = S_H′ − S_H とする。
  - 例も写像も同じなので、稀な事象の出現は二つの個体で揃う。ただし、その例への予測が履歴で違えば、損失の差は残る（codex P4）。
  - D = Δ事後 − Δ直前 と分けて、両方の項を並べて報告する（codex P3）。Δ事後 = 出来事の最初の 500 例の平均損失の H′ − H。Δ直前 = 直前 3,000 例の平均損失の H′ − H。
    Q2 は「自分の水準からの損失の増分が H で小さい」と読む。
- 関門（負の対照）: L-WIN は直近 1,000 例しか持たない。[T_2, T_4) の共通の 24,000 例の後、H と H′ の状態はビット単位で一致するので、D = 0（ビット単位）になる。0 でなければ実装の誤り。直前の平均と事後の平均も、それぞれビット単位で一致することを確かめる（差の相殺による見逃しを防ぐ、codex P4）。
- 枝の乱数はない（表だけ）。

## C. 予測（走らせる前に TOML で凍結する）
- S73-Q1（A）: L-FGT が全 4 生で満たす θ がない（「分離できず」）。
  - 根拠（推論）: この場では Y = 0 が約 0.8% と稀である。L-REF を引かない時計は、日常の区間でも予測できない Y = 0 で跳ねる。500 例の窓の平均のゆらぎ（概算で標準偏差 0.01 前後）が、小さい切替の効果と重なる。
  - 外れるのは、θ のどれかで L-FGT が全生で満たした場合。外れたら、自己基準の時計がこの場で使えると報告する。
- S73-Q2（B）: L-CUM では D > 0 が 4 生中 4 生（再来の世界を覚えている個体のほうが驚きが小さい）。
- S73-Q3（B）: L-FGT では、4 生すべてで |D_FGT| < D_CUM。
  - 根拠: λ^24000 ≈ 6 × 10⁻⁶ で、24,000 例前の経験はほぼ残らない。忘れる個体には、経験からの個体差がほぼ出ない。
  - 履歴の最後の違いは T_2 の直前にあり、そこから出来事までの共通区間は 24,000 例（T_2 = 20,000、T_4 = 44,000）。
  - D_CUM ≤ 0 の生では Q3 は必ず外れる。その外れを FGT の記憶の残りとは解釈しない（codex P5）。

## D. 報告
- A: 生ごと・θ ごとの誤作動率と検出率（全切替と選んだ切替）。L-REF 基準の時計の結果も並べる。
- B: 生ごとの S_H、S_H′、D（FGT・CUM・WIN）。出来事の直前の水準 m。出来事の最初の 500 例の Y = 0 の件数。
- 判定には使わない記述: 二つの履歴の、出来事の前の 3,000 例の損失の差（履歴の違いが、出来事の前からどれだけ効いているか）。

## E. 結果（2026-11-24、`experiments/s73_selfclock/out/s73.out`。codex S-R 14:29Z、I-R 14:31Z の P1・P2 を直した後に実行。51 秒）
- 関門:
  - H の本流の履歴 [1, T_4] は、S72 r4 の保存結果と P（ビット表現）・Y とも一致した（12 本）。
  - L-WIN は、T_4 直後の状態・直前の平均・事後の平均・D がすべてビット単位で一致した（4 生）。
- **Q1 は成立**（自己基準の時計は、L-FGT で全 4 生を満たす θ がない）。L-FGT の生のうち満たした数は、θ = 0.005 で 0/4、0.01 で 1/4、0.02 で 2/4、0.04 で 0/4。
  - θ = 0.02 では、誤作動率は 0〜0.067 で基準内。落ちたのは検出のほう（生 1 は 1/3、生 2 は 3/4）。
  - 比較: L-REF 基準の時計（θ = 0.04）は、L-FGT で全生を満たす。
  - 記述（判定には使わない）: 自己基準の時計では、L-CUM の誤作動率が 0〜0.13 と低い。L-REF 基準では 0〜0.53 だった。
    - 推論: L-REF 基準では、L-CUM が回復しきれない状態がずっと「驚き」として数えられていた。自己基準では、それが自分の水準として吸収される。驚きを個体の側に置いた帰結で、慢性の不適応は時計に現れない、という仮説。反証条件は、同じ生の慢性の区間で、自己基準が持続的な偏りに追随しなくても誤作動が減ること（codex P3）。
- **Q2 は成立**（L-CUM で D > 0 が 4/4 生）。D は 0.016〜0.135。
  - 生 1・生 4 では、H（π_1 を経験した個体）の S_H が負だった（−0.012、−0.021）。再来した世界のほうが、直前の世界より損失が低い。
  - 生 3 は Δ直前 = 0.014 で、出来事の前から H′ の損失が高かった。D の一部は直前の差による。両項は `s73.out` に並べた。
- **Q3 は成立**（|D_FGT| < D_CUM が 4/4 生）。D_FGT は 1 × 10⁻⁵〜3 × 10⁻⁵ で、0 ではないが小さい。
- 推論:
  - 経験を保つ個体は、同じ出来事に対して、経験の違いから驚きが分かれた。忘れる個体ではほぼ分かれず、窓の表では厳密に分かれなかった。「何に驚くかは経験から出る」（notes §10.6）を、表の学習器の範囲で支持する。
  - 自己基準の時計は、この場（Y = 0 が約 0.8%）ではまだ切替を拾いきれない。誤作動は抑えられたが、検出が足りない。基準の置き方を変える余地がある。例: 窓の長さ、自分の予測の分散で正規化する、自分の遅い写しとの差。これらは次の問い。
