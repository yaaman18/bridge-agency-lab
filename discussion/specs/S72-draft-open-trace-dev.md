## 1. 場: 受容器の付け替え（プリズム順応型）
- 観測の列: S57 stat 族の obs 系列（`c0r_dev/lib.jl` の `obs_stream`、1 種子あたり約 4,650 例）を 12 種子つなげて一つの生（約 5.5 万例）にする。
  例の順は種子の順・種子内の時刻の順。生ごとに種子の並びを回す（生 ℓ は TRAIN∪VAL の 18 種子 1050〜1067 から、ℓ だけずらした 12 種子）。
- 付け替え: 学習器が見る受容器の 6 本（TAB_R1 の r1 r2 r3 r4 r7 r8）に、置換 σ と反転の組 π を掛ける（受容器 k の値を、π が指す受容器の値から作り、反転の印があれば 0/1 を入れ替える）。
  標的 Y と行為は変えない。生理学のプリズム順応と同じ形で、世界は同じまま、受容器と意味の対応だけが変わる。
  - π₀ = 恒等。生の最初は π₀。
  - 年齢 T_i（例の番号、i = 1..4）= 8,000、20,000、32,000、44,000 で、π_i に切り替え、次の切替まで保つ。
  - π_i = ρ_i ∘ π_{i−1}（直前の写像に対する相対の変換、codex P3）。ρ_i = 6 本すべての反転 × 恒等でない置換で、生の種子から Mulberry で引く。直前に対して全反転なので、どの例でも鍵は必ず変わる。以前のどの π とも重複しないことを確かめ、重複したら引き直す（決定的）。
- **未見性・難度の根拠と記録**: ρ_i はどれも同じ群（置換 × 全反転）の元。表の学習器では空の表からの鍵の付け替えとして難度が等しいが、学習済みの表からの切替では等しさは保証されない（codex P3）。そこで各切替で、同じ例に旧・新の写像を当てた鍵の変化率と、切替直後 250 例の損失の差を記録する。
  TRM にとっての等しさは仮定。新鮮な対照（§3.1）で課題の難しさを年齢の効果と切り分ける。
- 区間のラベル（時計と独立に、場が指定する）:
  - 形成区間 F_i = [T_i, T_i + 1,500)。
  - ルーティン区間 R_i = [T_{i+1} − 3,000, T_{i+1})（最後は生の終わりまでの 3,000 例）。R_0 = [T_1 − 3,000, T_1)。

## 3. 測るもの（算式は走らせる前に凍結）
### 3.1 OPEN-1（適応の速さが落ちない）
- 前向きの損失 ℓ_t = −log q（p は [1/200, 199/200] で切る）。移動平均は切替より後の例だけで取る（窓 250 例、最初の値は T_i + 250 で出る。codex P1）。
- 直前の水準 a_i = R_{i−1} の ℓ の平均。後の水準 b_i = R_i の ℓ の平均（その切替の後、学び終えた水準）。
- 測れる切替の条件（codex P1）: 切替直後 250 例の平均 ≥ a_i + 3ε（ε = 0.005 nat）。満たさなければ、その切替は「測定不能」（切替で損失が悪化しない学習器、例えば p = 0.5 に張りつくものは、回復の速さを測れない）。
- 回復の条件: b_i ≤ a_i + 2ε。満たさなければ「未回復」。
- 到達: 移動平均が b_i + ε 以下になった最初の例。上限 6,000 例で、届かなければ「未到達」。速さ s_i = 切替から到達までの例の数。
- 非劣性: s_i ≤ 1.5·s_1 + 250（i = 2..4）。
- 未到達の扱い（codex P3）: 測れる切替を分母に残し、到達時間は上限 6,000 例で右打切り。到達率（例: 測れる 10 件中 8 件到達なら 8/10）と回復率を報告する。
- 判定（学習器ごと、dev は記述的）: 全生・全切替で「測れる・回復・到達」かつ非劣性 → 成立。一つでも測定不能・未回復・未到達・非劣性の違反があれば不成立。測定不能・未回復・未到達・違反の件数を別々に報告する（codex P7）。
- 新鮮な対照（codex P2、報告のみ）: 各 π_i について、同じ種類の学習器を初期状態から、同じ例の列 [T_i, T_i + 6,000) を π_i で与えて学ばせ、同じ算式の到達の速さ s_i^fresh を出す。s_i / s_i^fresh で課題の難しさと年齢の効果を切り分ける。新鮮な対照の「後の水準」は、R_i がないので、その 6,000 例の末尾 1,500 例の平均とする（codex I-R P2、実行前に明記）。比は両方が到達した組だけで出す。

### 3.2 OPEN-2（固定化しない）
- 各 T_i で、学習器の状態の写し A・B を作る。A には π_i、B には別の未見の π'_i = ρ'_i ∘ π_{i−1} を、同じ例の列 [T_i, T_i + 1,504) で与えて学ばせる。
  続けて両方に同じ共通区間 D = 1,000 例（π₀、例 [T_i + 1,504, T_i + 2,504)）を与えて学ばせる。D は入力の窓（4 歩）と L-TRM の輪（512 例）を超える（codex P5）。
- 枝の乱数（輪からの抽出）は A・B で共有する（同じ種子・同じ位置。codex P4）。
- 探り: 例 [T_i + 2,504, T_i + 2,904) の 400 例を π₀ で、更新なしに予測させ、Δ_i = mean |p_A − p_B|。D の前（枝の終わり）の Δ も同じ探りで出して併記し、枝ごとの前向き損失も記録する。
- 自己検査: 同じ写像の枝の対（A = B = π_i）で Δ = 0（ビット単位）。違えば実装の誤り。
- 判定: 全生・全年齢で Δ_i > δ（δ = 0.01）→ 成立。試験した年齢の一つでも Δ_i ≤ δ → 不成立。
- 写しは本流の生に影響しない（本流は π_i で続ける）。

### 3.3 TRACE-1（内側の時計）
- 時計（学習器に依らない共通の算式）: 50 例ずつの区画 b で、z_b = Σ(ℓ_t − H_t) / sqrt(Σ V_t)。H_t は自分の予測の下での期待損失 −[p log p + (1−p) log(1−p)]、V_t はその分散 p(1−p)(log(p/(1−p)))²。
  増分 c_b = max(0, z_b − 3)。Σ V_t = 0 の区画（すべて p = 0.5 で ℓ = H）は c_b = 0（codex P6）。
- 判定（学習器ごと、各生・各 i）: 形成区間 F_i の 30 区画の進みが L_F = 2.0 以上、かつ R_i の末尾 30 区画の進みが U_R = 1.0 以下（L_F > U_R）。全生・全 i で満たせば成立。
- 較正済みの対照（本実行の前の関門、codex P6）: p を一様 [0.05, 0.95] から引き、Y を p から引く完全に較正された予測器で、30 区画 × 10,000 回の試行。R の条件（進み ≤ U_R）の合格率が 0.95 以上であること。満たさなければ本実行に進まず、算式を見直す（その見直しは記録する）。
- 負の対照（関門の自己検査）: 外の歩数で一定に進む時計（区画ごとに増分 1）は、F と R が同じ 30 なので不成立になる。常にゼロの時計は L_F に届かず不成立になる。

### 8.1 参照つきの超過損失（§7 (a)）
- 参照 L-REF: 付け替えを知っている学習器。受容器を写像の前（もとの受容器）の座標で読む累積の表（L-CUM と同じ式、忘れない）。生の最初から同じ例を同じ区画の順で前向きに採点する。場は stat（定常）なので、写像を知っていれば忘れる理由がない。

- 確認（段 1 で報告）: 区間ごとの水準のばらつき（R 区間の平均の標準偏差）が、生の ℓ より e で小さくなるか（codex P10）。小さくならなければ (a) は失敗と記録する。

### 8.2 OPEN-2 の差（§7 (b)、codex P11）
- 差の物差し: Δ = 探り 400 例の mean |logit p_A − logit p_B|（p は [1/200, 199/200] で切った後）。
- 絶対の閾値ではなく、**対の対照**と比べる: 写像の対 (A: π_i, B: π'_i) と、データの対 (A: π_i, B'': π_i を別の 1,504 例で学ばせる)。どちらも共通区間 D・探りは同じ。
- B'' の定義（codex P17）: A と同じ切替直前の状態から分岐し、例 [T_i + 2,905, T_i + 4,408]（1-based、1,504 例）を π_i で同じ学習齢（同じ区画数）として与え、続けて A と同じ D [T_i + 1,505, T_i + 2,504] と同じ探り [T_i + 2,505, T_i + 2,904] を与える。別窓は D・探りと重ならない（探りの直後から始まる）。両窓の Y = 0 の件数を併記する。
  Δ_map は写像の違い、Δ_data はデータの違いだけによる差。判定は Δ_map > κ·Δ_data（κ は段 1 で、L-FGT が全生・全年齢で満たし、かつ同写像・同データの対では Δ = 0 になることを確かめて決める）。
- 同写像・同データの枝の自己検査（Δ = 0）は r1 のまま。

### 8.3 時計（§7 (c)、codex P12）
- 較正を前提にしない: 50 例の区画の超過損失の平均 ē_b を使い、増分 c_b = max(0, ē_b − θ)。
- 二つの率を別に測る:
- 単位をそろえる（codex P19）: どちらも 10 区画（500 例）の窓で数える。誤作動率 = 切替のない窓（R_0〜R_4 の末尾 1,500 例を 3 窓ずつ、1 生 15 窓）のうち c_b > 0 の区画を一つ以上含む窓の割合。検出率 = 形成区間の最初の窓（F_i の最初の 10 区画）のうち c_b > 0 を一つ以上含むものの割合。
