## 0. 確認した事実（コードから、claude-lab）

- 項番74 SQ1 の育成は**身体の外**で行う: `b = newborn(false); c = init(b); nz = Mulberry(seed)` から、`curriculum(cur)` の 800 歩を
  `step!(c, b, [y1, y2, 0.0]; noise = nz, contrast, idle_first)` で与える（`eval_body_bin3.jl:13–16`）。物質・身体・世界の状態はこの区間にない。
  世界は台本（収量の列）で、個体の行為は台本を変えない（開ループの方策）。
- 「元の規則」は contrast＝なし、idle_first＝偽、ほかの任意規則（core_gate・seen_both・sed_fade）は既定の偽（`core/circuit.jl:95–97`）。
- 学校期の集計は 401〜800 歩の、区画の運動（patch ≤ 2）ごとの行為の歩数、強制選択、勝者の入れ替わり、終わりの確かな受容器入力（`eval_body_bin3.jl:17–28`）。
- 乱数は `Mulberry`（`core/jsmath.jl:108–111`、状態は UInt32 一つ）。
- `core/circuit.jl`・`jsmath.jl`・`LabCore.jl` に `global`・`Ref(`・`rand(`・`time(`・`ENV` の読み取りはない（grep で確認、2026-11-06）。状態は `CState`（`circuit.jl:73–80`）と `Mulberry` にある。

## 1. 要件

- S1-1（出生状態 B の意味）: B は育成の第1歩の直前の三つ組《回路の配線 b、回路の状態 c、乱数の状態 nz》。D1 §4 の「回路・物質・世界・時計・乱数」のうち、
  物質と世界はこの区間に存在しない（§0）。時計は c の中の歩数 `t`。これは契約を弱める変更ではなく、S 段で全状態の意味を固定したもの（codex R9）。
- S1-1b（B の十分性、codex 2）: 育成の各歩は B と台本と固定の規則の引数だけで決まる。すなわち step! は外部の可変状態・別の乱数・壁時計を読まず、
  二つの腕は可変の参照を共有しない（腕ごとに newborn・init・Mulberry を新しく作る）。どれかが破れたら B の十分性への反証で、その走りは H の対照に使わない。
  試験: 腕を作ったあと、`b`・`c`・`nz` とその中の**入れ子のすべての可変オブジェクト**（配列、`Pend` など）が二つの腕で別のオブジェクトであること（`!==`）を、
  フィールドを再帰的にたどって確かめる（codex S-R2 の 2）。片腕の更新が他腕に届く共有が一つでもあれば不合格。
- S1-2（B の一致、codex 3）: 二つの腕（:std と :swap）の B を、同じ種子から別々に作り、第1歩の直前に**ビット単位で同じ**であることを確かめる。
  直列化を定める: b・c・nz の全フィールドを、型名・フィールド名の順（`fieldnames` の順）に、配列は要素の順に、数値は `reinterpret(UInt8, …)` のバイト列、
  文字列は UTF-8 のバイト列、`nothing` は印のバイトで並べたバイト列。
  曖昧さをなくす（codex S-R2 の 3）: 各値の前に型の印（1バイト）を置き、配列・文字列は長さ（UInt64）を前に置く。`nothing` と値のある場合は別の印。判定はこのバイト列の**直接比較**（`==`）。sha256 は記録と表示のためだけ。
  一致しない種子は H の対照から外し、その種子の支持を数えない。
- S1-3（同じ法則）: 二つの腕は同じ `step!` を同じ規則の引数で呼ぶ。規則の引数を結果の記録に書く。
- S1-4（宣言した方策差だけ、codex 6）: 宣言する位置は保育期（Julia の 1〜400 歩＝Lean の 0〜399）だけ。二つの腕の台本は長さが等しく、宣言の外（学校期 401〜800 歩）で要素ごとに等しい。
  台本の差の位置を記録し、そのすべてが保育期にあることを確かめる。学校期に差があればその走りは契約違反（宣言を広げて通すことはしない）。
- S1-5（再現の対照、codex 4）: :std を同じ種子で二度走らせ、対象の 10 種子・対象の集計（S1-6 の (a)(b)）と 800 歩後の B と同じ直列化が等しいこと。
  これは「対象種子・対象集計の再現性」の確認で、育成一般が決定的であることの証明ではない。H の証拠でもない（D0 決2 の再現の対照）。
- S1-6（形成差の観測、codex 7）: 各歩の `step!` の返り値（行為した運動、選択）を観測の列とし、(a) は観測の列の 401〜800 歩の部分から、(b) は 800 歩後の状態 c（確かさ q）から計算する。
  (a) 学校期の 400 歩で m1・m2 が行為した歩数（期間の集計）、(b) 800 歩後の m1・m2 への確かな受容器入力（時点）。二つを別々に報告する。
- S1-7（判定の語）: S1-2〜S1-5 がすべて通った種子で (a) か (b) が二つの腕で違えば、その種子は「契約のもとで H の支持」。成立とは書かない（D・N は別、R-BODY-1）。
- S1-8（停止条件、R10）: B を取り出して比べられなければ、S1-2 の GATE を未確認として止める。契約は弱めない。

## 6. 形式（Lean、`formal/History.lean`）

- 法則を決定的な関数 `step : σ → ι → σ × ο` とし、腕を《出生状態・台本》で表す。`run` は《最後の状態、観測の列》を返す。S1-6 の (a) は観測の列から、(b) は最後の状態から計算するので、
  定理は `run` の対全体の等しさで述べる（codex 7）。
- 対応（codex 5）: S1-2 ↔ `Contract` の births の等号。S1-4 ↔ `Contract` の長さの等号と宣言外の台本の等号、および `NurseryOnly`（宣言は 0〜399 だけ、codex 6）。
  S1-3 は `Contract` の欄ではなく、二つの腕に**同じ `L`** を渡す定理の形で表す（Julia では同じ `step!` を同じ規則の引数で呼ぶ）。S1-1b は Lean では `step` が関数であることに含まれる（Julia 側の試験で確かめる）。
- 証明した statement（2026-11-06、`sh formal/check.sh`、sorry なし）: `replay_control`（同じ出生状態・同じ台本なら run が等しい）、`no_declared_no_difference`（宣言が空なら run が等しい）、
  `difference_needs_declared`（契約のもとで run が違えば、宣言した位置のどこかで台本が違う）、`difference_in_nursery`（`NurseryOnly` のもとでは、その位置は 0〜399）。
- (3) が言うのは「宣言した位置のどこかに台本の差がある」ことの存在だけで、どの位置が観測の差に寄与したかの特定ではない（codex 8）。
