## 1. Q-A 経路への依存（系列 A・B）
- 系列 A: N（無介入）と、Z（S9 の区画の交換: 予定表の入れ替え＋t の後の pool の交換）の 4 条件: (o) 軛なし、(i) y_sense を N の y の列に軛（答えは本物）、(ii) y_offer を N に軛（感覚は本物）、(iii) 両方を N に軛。
- 系列 B: t＋1 から結合した受容器 r1〜r4・r7・r8 を、N_B にも Z にも sil。軛の元は N_B。同じ (o)〜(iii)。
- 軛: Z の更新 τ（t＋1〜t＋15）で、N の同じ τ の更新が読んだ本物の y を与える。
- 共通の生存の対象: 系列ごとに、N と 4 つの Z のすべてが窓の中で生きている t だけを比べる。除外の件数と t を記録。
- 測るもの: 行為の差 D＝窓の中で「行為した区画運動の集合」が N と違う更新の数。移り＝S9 の hl の手順（予定表の厳密な大小のある更新で h＞l が N・Z の両方で成り立つ）。
  ここでは S9 の「t＋1 の読む y が同じなら未判定」は使わない（軛で感覚を同じにするのが介入そのもの、codex 2）。数える更新（予定表の厳密な大小）が N・Z のどちらかで 0 なら移りは未判定のまま。
- **同一性の対照**: (iii) では回路の入力が N と同じなので、行為の列と窓の終わりの回路の状態（q・sg・h・active・cOn・cOff・lastM・lastC・pend・t）が N とすべて同じであること。一つでも違えば Q-A の帰属を止める。

## 2. Q-B α の照合の二段
- S9 の C／Bm（t＋1 だけ m を sil）と同じ使える条件で、(1) t＋1 の後の m の区画の pool の差、(2) t＋2 の更新で読む y の差、(3) t＋2 の後の受容器の差、を記録。
- 飽和の予測の検証: 使える事象で、m の区画の t＋2 に読む y が C と Bm の両方で 5。
- 閾値の近くの条件 NT（先に固定、codex 3）: t の更新の後の状態の写しで、m の区画の pool を 3U に置き（t＋1 の更新でその区画を y＝3 と読む）、それから C・Bm を作る。
  t＋1・t＋2 に実際に読んだ y（両区画）と、m の区画の特徴（y≥3・y＝0・二区画の大小）が C と Bm で変わったか（閾値の通過）を記録する。補充（予定表の g）によっては t＋2 の読みが閾値の近くに来ないことがある。
  宣言にない組（m1→r2・r4、m2→r1・r3）の差は不一致、宣言の組の差は実現。実現がないことは宣言の誤りの証拠にしない。

## 3. Q-C 価値への鈍さ（R-BODY-6 の R3-d）
- 型の同定（先に固定、codex 5）: m*＝N の窓（t＋1〜t＋15）で最も多く行為した区画運動（同数・行為なしは「他」）。分類は t の更新の後の状態で、m* に入る受容器 r1〜r8 からの辺について:
  どれかが q≥1 なら q 型、すべて q＝0 でどれかが sg≥1 なら sg 型、それ以外は他。
- 対象の条件（codex 6）: Z の t＋1 の予定表で高い区画の運動が m* と違う点だけ（交換で m* から離れる必要がある点）。
- 条件 V: Z（区画の交換）で y_sense を N に軛（感覚を揃える）、答えと pool は本物。価値の変化は答えの経路でだけ届く。
- 記録（codex 4）: 答えの経路が使う量 d（各更新の d1・d2 の値）の列と、その正負（d＞0）の列の、N との違いを別々に。d の値の列が N と同じならその t は「入力の差が足りない」で判定しない。
  移るまでの更新の数＝窓の中で、Z の高い区画の運動が初めて行為した更新（t＋1 を 1 とする）。窓の中で行為しなければ 15 で打ち切り（「移らず」）。型ごとに集計。両方の型で移った例がなければ判定を保留（D4 R3-d）。
