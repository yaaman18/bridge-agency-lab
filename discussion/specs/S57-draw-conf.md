# S57（A1）回路の確かさから作った確率で引く: 確かさは応えを見込めているか、引くことは生存を変えるか（r2、2026-11-15、claude-lab。codex-lab S-R: r1 に challenge 3・clarify 3・accept 3 → 全部採った）

- 出どころ: ユーザー 2026-11-15「1 の仕様を書き始めて」（A1）。設計は `notes/D-MEM.md` §3（codex と合意した順 A0 → A1 → B → C）。前の段は S55（項番165）。
- 位置づけ: 系統の側、合成の世界。**予測器も痕跡も入れない。** 電波はつながない。乱数は S55 と同じ「凍結した代わりの入力ビット列」。
- 守る線（D-MEM §3）: 確率は回路がすでに持つ量（結びつきの確かさ）からだけ作る。引く写像と下限は前もって固定。収益・費用・割引・先読みを持たない。受け取りを増やすための調整をしない。言えるのは「釣り合わせ」で、「最適化なし」は言えても「目的に向かう性質なし」とは言わない。
- しないこと: `core/` の変更。既存の数値の変更。Rust への写し。法則を決めること。

## 1. 介入（S55 の `step_draw!` に腕を一つ足す）
- 腕: **DET**（もとの選び方）、**UNI**（均等）、**CONF**（新）: 選ぶ集合 cs の各運動 m に整数の重み **w_m ＝ 1 ＋ conf[m]**（conf[m] は `core/circuit.jl` の `step!` がその歩に数えている量: その運動を駆動した結びつきのうち、確かさ q≥1 のものの重みの合計。下限の 1 は、どの候補も引かれうるための床）。引き方は S55 と同じ（（区画、添字）の順、棄却つきの整数の抽選、一歩に一度）。
- 育ち（T0 まで）は三つの腕とも DET。
- 記録（S55 の I-R の指摘を直す。ビットの位置を実行の状態に持つことは S55 から引き継ぐ）: 引いた歩ごとに、cs の（区画、添字）、key の三つの成分（確かさ・習慣・合計）、重み、選ばれた運動、DET なら選んでいた運動、使ったビットの数と捨てた回数、**その行為が応えられたか**。
- **「応えられた」の定義**（D-MEM §3、前もって固定。codex 3）: 行為した歩に、行為した区画 p の**収量の入力 y[p]（回路の受容器がその歩に読む量）が 0 より大きい**こと。観測の時点は行為と同じ歩。受け取りの量・費用・身体の変化は使わない。
  - 既存の数え方との関係: `core/body_org.jl` 172 行の「答えのあった行為」は d[p]＞0（回路の配分）。一つの区画だけが行為した歩では y[p]＞0 と同じになるはず。**歩ごとに二つを照らし、食い違った歩の数を報告する**（D7）。一つでも食い違えば「同じ出来事」とは書かず、PB2 は y[p]＞0 の定義で読み、食い違いの数と中身を並べる。

## 3. 下調べと採否（評価の前に、下調べの窓だけで。規則は変えない）
- 各法則・各腕で、T0＋2000 に生きている窓が 4 のうち 3 以上、引いた歩が窓ごとに 200 以上。一つの腕でも満たさなければ、その法則は三つの腕とも評価を走らせず「測れない」。
- 加えて CONF について: 引いた歩のうち、二つの候補の重みが違う歩（w が同じでない歩）が窓ごとに 100 以上。4 窓すべてで満たすこと。満たさなければ「PB2 の前もっての採否の条件に届かない」として、PB2 は測れないと報告する（CONF が UNI と同じだという証明ではない。PB1・PB3・PB4 は走らせる）。引き直し・窓の追加はしない（codex 7）。

## 4. 量と読み
- (a) 仕組み: 指定した確率と選ばれた頻度（S55 の PA2 と同じ規則。指定した確率ごとに組にする）。
- (b) **確かさの大きい候補と小さい候補の、応えられた割合の差**（CONF の腕、重みが違う二つの候補のある引いた歩）。主の量（codex 5）は、窓ごとに、重みの違う引いた歩 N について **平均 [ I(重いほうを選んだ)·Y／p_H − I(軽いほうを選んだ)·Y／p_L ]**（Y は応えられたら 1。p_H・p_L はその歩に指定された確率）。引かれる確率が状態で変わることを、その歩の確率で割って均す。併記: 実際に選ばれた二つの群の応えられた割合の単純な差、p_L の最小と分布（小さい確率は分散を大きくする）。
- (c) **引くことと生存**: 死の歩（T0 からの歩数。共通の地平 T0＋9200 まで生きた走りは 9201 とする打ち切り。両方の腕が地平まで生きた窓は同点で、地平の後の寿命の差は読めない）。腕の対ごとに、窓の対の符号検定。勝ち・負け・同点の数を報告する。**検出不能を「同じ」と読まない**（codex 6）。
- 読みの限定: (b) は「**CONF の腕が訪れた状態に限って**、確かさの大きい候補のほうが応えられやすい」という記述で、確かさが応えを引き起こすとは言わない（区画の収量が高い時期は両方が上がりうる）。ほかの腕が訪れる状態には言い及ばない。(c) は生存の差の記述で、どの仕組みで差が出るかは言わない。
