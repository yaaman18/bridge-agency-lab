### 2.2 内部射影 $\mu(s)$・厳密 1 歩後方因果閉包・質量方針
- **内部射影 $\mu(s)$（ビット一致比較対象）**:
  $$\mu(s) := \bigl(\text{circuit},\; \text{pool},\; \text{noise},\; C_{\text{body}},\; \{(i, w.A[i], w.B[i], w.C[i]) \mid i \in C_{\text{body}}\}\bigr)$$
  ここで $C_{\text{body}} = \{i \mid w.C[i] \neq 0\}$（分裂による新娘セルが次歩に $C_{\text{body}}$ へ入る場合はその新娘セルの `(A, B, C)` も $\mu(s_{t+1})$ に含める）。**`w.port.reservoir` は外部環境資源として $\mu$ から除外する**。
- **厳密 1 歩後方読取閉包（`core/matter.jl:86-122` に基づく）**:
  - `step!(w, ())` で $C_{\text{body}}$ および分裂候補 `nb4(C_body)` の次状態に影響しうるセルは：
    - 1 歩フラックスの流入元は `nb4(C_body)`（さらに娘候補の流入元は `nb4²(C_body)`）、そのスケーリング `scl` は `out` 経由で `P` を `nb4³(C_body)` 上で読み、各 `P[x]` は `kIdx(x)`（半径 `RING=3`）を読む。
  - よって厳密 1 歩因果ハロを次で定義する：
    - `ring1(C)`: $\mathrm{nb4}(C) \setminus C$
    - `halo1(C)`: $\bigl(\mathrm{nb4}^3(C) \cup \bigcup_{x \in \mathrm{nb4}^3(C)} \mathrm{kIdx}(x)\bigr) \setminus C$（半径最大 6）
    - `mid1(C)`: $\mathrm{halo1}(C) \setminus \mathrm{ring1}(C)$
    - `far1(C)`: $\{1..n\} \setminus (C \cup \mathrm{halo1}(C))$
  - **2 歩後方閉包（$t=39 \to 41$、すべて $39 \to 41$ で統一）**:
    - 1 歩閉包作用素 $\mathcal{H}(S) := S \cup \mathrm{nb4}^3(S) \cup \bigcup_{x \in \mathrm{nb4}^3(S)} \mathrm{kIdx}(x)$ を 2 回適用した `halo2(C_39) := H(H(C_39)) \ C_39`、`far2(C_39) := {1..n} \ (C_39 ∪ halo2(C_39))`。
    - **トーラス飽和の誠実な処理**: 正本 `24×24` トーラスでは半径 12 の 2 歩閉包が全 576 セルを覆い `|far2| == 0` になりうる。そこで (i) 正本 `24×24` では `|C|, |halo1|, |far1|, |halo2|, |far2|` を実測報告し（`|far1| == 0` なら即 FAIL、`|far2| == 0` なら空集合を偽の合格にせず「24×24 では 2 歩閉包が全格子を飽和」と明記）、(ii) **非空な 2 歩履歴 D-BaSS の実測検証として、`core/matter.jl` 既存の `make_world(; W=40, H=40, reservoir=300.0)`（`core/` 無変更）上で 20 評価種子（`938..957`）の `s_39 → s_41` 遷移を走り、`|far2| > 0` を必須条件として `far2` 漏れ 0/20 を検証する**。
- **質量・ポート方針（凍結）**:
  - `ΔA ∈ {+0.05, +0.20, +0.45}` を対象セル集合の `w.A[j]` へ独立に加算する（`w.port.reservoir` は開始時に一致させ、`naive` と `shell` で同一のポート条件を適用）。各対で開始時の `port_take!` 受取量が一致することを確認する。
  - **ポート成分の最小性検証（別フィクスチャ）**: 正本 `reservoir = 300.0` では `port_take!` の上限クランプが発火しないため、ポート成分の非冗長性（最小性）は、`s_40` のコピーで **`reservoir_low = 0.02 < 5*U = 0.10` に設定した低貯留フィクスチャ**上で `reservoir` を `0.02` vs `0.08` に変えたとき `pool` と $\mu_{41}$ が変化する（20/20 検出）ことで検証する。

### 2.3 起点・GB4 介入仕様（すべて種子・乱数固定）
- **起点 $s_{40}$**: 各評価種子（`938..957`）で `onelife_birth(seed, LawL2)` を 40 歩、交互駆動 `g_t = ((t ÷ 10) % 2 == 0 ? (5, 1) : (1, 5))` で進めた状態（全 20 種子で生存・非空身体であることを前提確認）。
- **恒等ラッパ負対照（GB4 前提）**: `core/one_life.jl` を変更せず介入用に構成した外部ラッパ関数 `_live_wrapped` を「介入なし」で 20 評価種子×20 歩走らせ、全歩で `onelife_encode(wrapped) == onelife_encode(canonical onelife_step)`（20/20 バイト一致）を確認する。
- **GB4a（外向き因果作用：P-04 運動発信停止、送信端遮断）**:
  - 回路内部の状態更新（`step!(circuit, ...)`）には触れず、**運動出力の受け手側（`acting` / `d` の消費箇所、`core/one_life.jl:56-71` 相当）で対象運動 `m1, m2` の発信のみを遮断**する。起点 $s_{40}$ から 20 歩（周期 5 歩の切替駆動 `drive_A: (5,0) ↔ (0,5)`）で、通常腕と発信停止腕の `(pool, paid_sum, body_B_sum)` の差を測る。
- **GB4b（適応的設定選択の随伴性：軛再生・乱数消費一致確認）**:
  - 同一初期状態 $s_{40}$・同一 `s.noise` から、
    - **Live 腕**: 切替駆動 `drive_A`（5 歩ごとに `(5,0) ↔ (0,5)`）で 20 歩閉ループ実行し、各歩の乱数消費後の `noise` 状態と実受取総量 `taken_live`・最終身体結合量 `B_live` を記録。
    - **Donor 腕**: 逆位相駆動 `drive_B`（5 歩ごとに `(0,5) ↔ (5,0)`）で 20 歩実行し、各歩の行為列 `(acting_donor[t], d_donor[t])` を記録。
    - **Yoke 腕**: 受信側駆動 `drive_A` のもとで、回路更新は同一乱数ストリームで行い（各歩の `noise` 遷移の一致／不一致歩数を監査記録）、行為の消費箇所のみ Donor の `(acting_donor[t], d_donor[t])` を再生し、`taken_yoke`・`B_yoke` を記録。
  - **符号付き指標と判定**: $\Delta_{\mathrm{taken}} = \mathrm{taken}_{\mathrm{live}} - \mathrm{taken}_{\mathrm{yoke}}$ と $\Delta_B = B_{\mathrm{live}} - B_{\mathrm{yoke}}$ の全 20 種子の勝ち／引き分け／負け数・中央値を報告。
- **GB4c（内向き翻訳作用 $\eta \to \mu$：2 つの独立整合フィクスチャ、$t \to t+1$ の `y` 読取タイミング修正済み）**:
  - `core/one_life.jl:52` は `y = min(5.0, floor(pool/U))` を歩頭で読むため、歩 $t$ の駆動 `g_t` の差は**歩 $t+1$ の回路入力 `y_{t+1}` と歩 $t+1$ の回路状態**に現れる。
  - **区別対フィクスチャ（低プール）**: $s_{40}$ のコピーで `pool = [0.0, 0.0]` に揃え、歩 $t$ に `g = (5, 0)` vs `(0, 5)` を入れて 2 歩（$t, t+1$）進める → 歩 $t+1$ の回路入力 `y_{t+1}` が `[5.0, 0.0]` vs `[0.0, 5.0]` で**異なり、かつ $\mu_{t+2}$（回路状態含む）も異なること**を 20/20 検証。
  - **身体翻訳同一視対フィクスチャ（`y` 上限 5 飽和）**: $s_{40}$ のコピーで `pool = [0.06, 0.06]`（$= 3U$）に揃え、歩 $t$ に `g = (4, 4)` vs `(5, 5)` を入れて 2 歩進める → 歩 $t+1$ の生プールは `0.14` vs `0.16`（`< 50U = 1.0` で異なり $\mu$ 全体は異なる）である一方、**身体が回路へ渡す量子化入力 `y_{t+1}` は両腕とも `[5.0, 5.0]` で完全一致（かつ歩 $t+1$ の回路出力 `out` がビット一致）**することを 20/20 検証（`y` 一致と $\mu$ 一致を分けて報告）。
