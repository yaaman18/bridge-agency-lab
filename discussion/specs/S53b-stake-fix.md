# S53b T0 以後に更新を続けることの価値は、ほかの存在の多さで変わるか（ORG 対 ORG-FIX。賭け金の「激しさ」の測り直しとして始めた段）（r2、2026-11-15、claude-lab。codex-lab S-R: r1 に challenge 3・clarify 2・accept 4 → 全部採った）

- 出どころ: ユーザー 2026-11-15「1,2,3は普通にやってくれ」の 3（項番161 の「次の段」）。S53 の PK4 は、黙らせた腕が全窓で T0＋48〜148 に死んで検出不能だった（claude-lab の仕様の欠陥）。
- 問い: ほかの存在の多さ s を上げると、**T0 以後も学習を続ける個体（ORG）と、T0 で学習を止めた個体（ORG-FIX）の身体の差**は広がるか。
- **問いの読み替えの明示**: S53 の「激しさ」は「回路があること」の効き方だった。この段が測るのは「T0 以後の更新を許すこと」の効き方で、同じものではない（S47 の読み: ORG 対 ORG-FIX＝更新を許す総効果。維持費は T0 の数に固定される）。「回路があること」の効き方は、黙らせるとすぐ死ぬこの体では、この形では測れない。
- 位置づけ・しないこと: S53 と同じ（系統の側、合成の世界、電波はつながない、s は走りの中で一定、`core/` は変えない、既存の数値は変えない、Rust に写さない）。

## 2. 対照の適格（結果を見る前に決める）
- ある法則・ある λ について、s＝0 と s＝3 の**両方**で、T0＋2000 に ORG と ORG-FIX がともに生きている窓が 8 以上あること。満たせば主の量は **G2000**（その窓だけ）。
- **適格な窓の作り方**（codex 2）: 同じ種子で、s＝0 の ORG・s＝0 の ORG-FIX・s＝3 の ORG・s＝3 の ORG-FIX の**四つの走りがすべて**その時点で生きている窓の共通集合。点ごとに別々に数えない。8 以上で適格。
- **読みの限定**（codex 3）: G は「四つの走りがともに生きている窓での身体の差」で、死を含めた更新の総価値ではない。生き残った窓だけを使うので、腕・s・λ に依る選択が入る。死の歩の併記はこの偏りを消さない。報告にこの文を付ける。
- 満たさず、T0＋500 では満たす場合は、主の量を **G500** に替える（この順は凍結。両方を見て良い方を選ばない）。どちらも満たさなければ、その法則・その λ は検出不能。
- 「弱い」の確認（併記、予測 PL-FIX）: s＝0 の点で S_FIX ≤ S_ORG の向きか（符号検定）。逆向き（FIX のほうが大きい）なら、G の読みは「更新を許すことの損」になる。その場合もそのまま報告する。
- ORG と ORG-FIX の T0 までの状態はビット一致のはず（関門 K4）。

## 5. 言えること・言えないこと
- 言える: この格子・この 12 窓・この二つの法則で、s と λ が「更新を許すことの効き方」をどう変えるか。
- 言えない: 「回路があること」の効き方。現実の電波。s が途中で変わる場合。ほかの雑音。λ の正しい値。賭け金の一般の形。個体が何かを感じるか（主張しない）。
- M の傾きと λ の格子は作者が置いた数（S53 と同じ限定）。
- ORG と ORG-FIX の差は、行為・学習・維持費（ORG-FIX は T0 の結びつきの数で払い続ける）を含む総効果。削る側は維持費の後なので、実際に取れた量が腕で違いうる。これは不公平ではなく効き方の経路として扱い、**請求した量と実際に取れた量を腕ごとに報告する**（codex 7）。
