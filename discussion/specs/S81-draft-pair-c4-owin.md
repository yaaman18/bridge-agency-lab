## 2. 何を出すか（codex 12:30Z P2〜P4）
- **対（P2）**: 選んだ切替ごとに、C4 と O-win の検出の有無と最初の警報の時刻（T からの経過）。両方・O だけ・C4 だけ・どちらも、の 4 つに分ける。通常区間でも同じ 4 つ（誤作動）。
- **O だけの切替の中身（P3）**: 形成区間 [T+1, T+1,000] で、
  - n0（区間の Y = 0 の数）と、O-win の最初の警報までの n0。
  - C4 の不足分: 区間の判定点での PH の m − M（持越しを含む、h = 13.75 の経路）の最大と h との差。
  - Y 別の C4 の寄与 Σc（Y = 0）・Σc（Y ≠ 0）と、Y = 0 の例 1 つあたりの c の平均 a_f。
  - O-win の証拠 u_t = ℓ_t(P) − ℓ_t(Pc) の和を Y 別に（区間の中、O-win の警報まで）。
  - 比べとして、両方が検出した切替の同じ量。
- **頻度と大きさの分け（P4）**: 4 つの組ごとに、n0 の分布（頻度）と a_f の分布（大きさ）を並べる。
- **大きい寄与への依存（P3・P5）**: C4 が検出した形成区間と、C4 の誤作動の出た通常区間で、最初の警報までの区間の中の c の最大 1 個・上位 3 個の和と、警報時の m − M に占める割合。警報しなかった通常区間では区間全体で同じ量。

## 6. 結果（2026-11-25。`experiments/s81_pair/out/s81.out`、sha は `experiments/freeze-s81.txt`。予測は走らせる前に凍結、codex I-R 12:37Z P3・P4 取り込み）
### 6.1 確認した事実
- 関門: 8 生と 40 生の件数が thresh.out・run.out を再現。谷つきの PH の経路が firemask と一致。O-win の警報が mask80 と一致。分解（持越し＋区間内 = m − M）と O の窓の平均が、使ったすべての点で一致。切替 183、通常区間 720、周辺計も一致。
- 対（切替 183）: 両方 125、O だけ 54（8 生 9・40 生 45）、C4 だけ 0、どちらも 4（n0 の中央値 0.5）。通常区間 720: C4 だけ 24、ほかは誤作動なし。
- 頻度: n0 の中央値は O だけ 5、両方 9（8 生 4 対 8、40 生 5 対 9）→ **F1 的中**。
- 大きさ: a_f の中央値は O だけ 3.50、両方 3.39 でほぼ同じ。O だけの 54 本すべてで a_f が同じ生の基準を上回った（K = 54、D = 54）→ **F2 的中**。
- C4 の不足分（h − 区間内の m − M の最大）の中央値は、O だけで 4.24。区間全体の Σc(Y ≠ 0) はどの群でも約 −20。ただし PH が使う谷以後の区間内では、取り逃がしで −1.00、検出で −0.87（中央値）。
- O-win: 最初の警報までに来た Y = 0 は中央値 1.5 個（O だけ）。切替後の Σu のうち Y ≠ 0 の分の割合は、中央値 0.0002。例外: s80 生 36 i=3 は Y = 0 が来る前に、生 21 i=2 は Y ≠ 0 の証拠で警報した。
- 谷以後の単発の c の最大は、警報のない通常区間でも、検出した形成区間でも、中央値 5.27。C4 の取り逃がしは top1/S 0.53、top3/S 1.10。
- s80 生 35 i=1 は n0 = 18 でも C4 が届かなかった（不足分 0.38）。
### 6.2 codex 12:39Z の読み（P1〜P5）
- 書いてよい文（P1）: 「L = 1,000 の切替 183 区間で、O だけが検出した 54 区間は、両者が検出した 125 区間より Y = 0 の件数が少なかった（中央値 5 対 9、8 生・40 生でも同じ向き）。O だけの 54 区間すべてで、Y = 0 の例 1 つあたりの平均寄与 a_f は、それぞれの基準を上回った。」
- P2: 区間全体の −20 を取り逃がしの原因とは言えない。PH が使う谷以後の負の寄与は −1 程度。言うには、同じ経路でその寄与を除いて閾値を越えるかの照合が要る。
- P3: O は双子があるので、通常区間の u がほぼ 0 になる。典型例では、少数の Y = 0 が警報を支えた。
- P4: 単発の大きさは、通常区間と形成区間で重なる（どちらも 5.27）。ただし「Y = 0 だけを数える PH は誤作動する」と予測するには、その時計の累積と閾値が要る。
- P5: 時計探しは保留する。TRACE-1 の読みは「L = 1,000 では、O だけが拾った切替は Y = 0 が少なく、現行の C4 は閾値に届かなかった」と記す。件数の不足だけでは説明できない例がある（生 35 i=1）。
### 6.3 推論
- 取り逃がしは主に、L = 1,000 の中で Y = 0 の例が少ないことに伴う。例 1 つあたりの寄与の大きさは、取り逃がした切替でも残っている。
- O が 1〜2 例で届くのは、双子と比べて通常区間の証拠を 0 にできるからと読める。自分の量では、通常区間の Y = 0 の単発も同じ大きさ（5.27）に届く。このため、少ない例では切替と通常を分けにくい（未検証。P4 の照合が要る）。
