## 0. 確認した事実（`core/circuit.jl` 271〜283、`core/body_org.jl` 117〜160。codex も確認）
- **沈殿の減衰のための年齢**は sed_fade（L2+SF）だけにある: a＝今の歩 − `lastC[k]`。確認された辺は `lastC` を今の歩にし、されなかった辺は a が FORGET（100）の倍数のとき sg が 1 減る。変種 SFD は「その辺が運動を駆動し、運動が行為した」ときも `lastC` を今の歩にする（支払いなし）。腕は **L2+SF の上だけ**に立つ。
- 体の一歩の順: 回路の一歩（中で年齢の更新と減衰）→ 体の大きさによる上限 → 維持費（保たれた結びつきの数 × KC を、体の場所 `body`〈`w.C[i] != 0` の場所〉が等分に `w.B[i]` から払う。**足りない場所は持っている分だけ払う＝部分払い**。払った分は `port_give!(w.port, paid)`）→ 行為の収量。

## 1. 腕（`lastC` を今の歩にする条件だけが違う。形成と q・sg の強化は全部同じ）
| 腕 | `lastC` を戻すもの | 支払い |
|---|---|---|
| A-ret | 確認だけ（＝今の L2+SF） | なし |
| AB-free | 確認、または使用（＝今の SFD） | なし |
| AB-ret | 確認、または支払えた使用 | 支払えた使用 1 回につき KC |
| B-ret | 支払えた使用だけ | 同上 |
| B⊥遅れ・B⊥くびき | B-ret と同じ規則で、支払える回数だけを別の記録から読む（§3） | §3 |
- 「使用」: SFD と同じ判定。**確認と使用が同じ歩に重なった辺**: AB-ret では確認が戻すので使用の支払いは起こさない。B-ret では確認は戻さないので、使用として支払いを試みる。
- **支払える回数 s_t**（歩 t に一つの整数。これが検査 N の s）: 歩 t の頭（回路の一歩の前）の在庫で、s_t＝floor( min_{i∈body} w.B[i] ÷ (KC ÷ |body|) )。死んだ後は 0。使用のない歩も毎歩記録する。
- 歩 t に使用された辺（支払いを試みる辺）を、始点＝t mod（その辺の数）から辺の番号の順に並べ、**先頭から s_t 本まで**が「支払えた」。支払えた辺は `lastC` を今の歩にする（もとの規則と同じく、その歩の減衰は受けない。戻らなかった辺はもとの規則どおり減衰の判定を受ける）。これは回路の一歩の中、減衰の判定の位置で行う（R1 と両立: 支払いのない腕では何も変わらない）。
- 引き落とし: 回路の一歩と上限の後、維持費の前に、支払えた本数 × KC を `body` の各場所から等分に `w.B[i]` から引き、`port_give!(w.port, 引いた量)`。B-ret・AB-ret では s_t の定義により全額が引ける（部分払いなし）。**根拠: 歩の頭から引き落としまでの間（回路の一歩と上限）は `w.B` と `body` を変えない。これを関門 R5 で歩ごとに確かめる**（変わる歩が一つでもあれば、この仕様は成り立たないとして止める）。**維持費の部分払いとは別の、新しく置いた全額の判定である**（構造が似ているだけ）。維持費はその後、減衰の後の保たれた数に今のとおり課す。
- 新しく形成された辺: もとの規則のまま（支払いなし）。育ち（T0 まで）は全部の腕が A-ret。
- 仮説（凍結のとき H 番号）: 単位 KC、全額の判定、頭の在庫で数えること、辺の順（固定の順の偏りを緩和するだけ。周期と同期すると同じ辺が先になる）。

## 3. 対照と妥当性の条件
- B⊥遅れ: s_t の代わりに自分の s_{t−Δ} を読む。**Δ＝375**（駆動の周期 L＝300 の 1.25 倍。L・L/2・FORGET の倍数を避けた。それでも位相との関係は残る。限界）。T0＋Δ より前は自分の s_t。
- B⊥くびき: 同じ窓（同じ外部入力）で誕生の種子だけ替えた B-ret の走りを先に走らせ、その s_t を歩の番号で読む。相手が死んだ後は 0。
- 対照が戻す本数＝min（読んだ s、その歩に使用された辺の数）。引き落としは**実際に戻した本数** × KC を等分に引く。足りない場所は 0 まで引き、足りなかった分を**不足**に数える。収支は「実際に引いた量 ＋ 不足 ＝ KC × 戻した本数」。
- R3 の同一性: Δ＝0 の遅れ、相手を自分にしたくびきは、B-ret と全歩ビット一致（s が歩ごとの一つの整数なので成り立つ）。
- 妥当性の条件（**設計上の許容幅であって、交絡がないことの証明ではない**）。集計は窓ごとに、T0〜tp−1 のうち B-ret と対照の両方が生きている歩（乱しの前なので類によらない）:
  - v1 戻した本数の合計が B-ret の 0.5〜2 倍。v2 作り直しに実際に引いた量が B-ret の 0.5〜2 倍。v3 不足 ÷（引いた量＋不足）≤ 0.2。v4 読んだ s の平均の差が B-ret の s の平均の 50% 以下。
  - **v1〜v4 のどれかが成り立たない窓**、B-ret の分母が 0 の窓、どちらかが T0＋Δ＋300 より前に死んだ窓は「無効」。
  - 無効の窓はその対照との主の解析から除く。**有効な窓が評価の 36 のうち 27 未満なら、その対照との比較全体を「帰属を保留」とし、資格は成り立たない**（両方に勝つことが要るため）。
  - 有効な窓への限定は**腕に依存する選別**である。だから対照ごとに、(1) 有効な窓だけの判定、(2) 全 36 窓の判定、(3) 除いた窓の Z と D の一覧、を併記する。結論は「その対照の有効な窓について」と書く。**(1) と (2) で D の正負の偏りの向きが逆になったら、その対照との比較は「帰属を保留」**。

## 5. 量と判定
- **主の量 Z（走りごと、0 か 1。選別なし）**: 歩 tp＋T の時点で生きていて、tp＋T−300〜tp＋T の 300 個の観測で体の大きさが全部帯の中。tp より前に死んだ走りは帯を作れないので Z＝0。名前は「**乱しの後 T 歩の帯内生存**」。
- 判定の単位は**窓**: 窓ごとに D＝Σ_{類 (a)(b)(c)}（Z_B-ret − Z_対照）（−3〜3）。D≠0 の窓で符号検定（両側 5%、D≠0 の窓が 8 未満は検出不能）。**勝ち＝有意で、かつ D>0 の窓が多い**。下調べで除いた類があれば残りの類で同じ式。
- 併記: 類ごとの Z の勝ち・負け・同点。類 (0) の同じ量（乱しがなくても同じ差が出るなら「乱しからの回復への寄与」とは読まず「帯内生存への寄与」と書く）。
- 二次の量（**乱しの後で選別した推定で、対がそろわない**と明記して報告するだけ。判定に使わない）: tp〜tp＋300 に帯の外へ出た走りのうちの Z の割合（「凍結した帯への回復」）。片方の腕だけ出た窓の数も出す。
- 別に出す: 生存の割合、帯の外で生き続けた走りの数、支払えなかった本数（使用された辺の数 − 支払えた本数）、辺の番号ごとの保持の差、消えた辺の数、消えた辺が FORGET 歩のうちに形成し直された回数（腕ごと）。

## 7. 言えること・言えないこと
- 言える（成り立ったとき）: この世界・L2+SF・残った乱しの類・その対照の有効な窓について、「体が払える回数への結びつきが、乱しの後 T 歩の帯内生存に寄与する」。類 (0) で差が有意でないことは、回復に特有の効果の証拠にはしない。**類 (0)（乱しなし）でも同じ向きの差が有意に出たときは「乱しの後の」を付けず、「帯内生存に寄与する」とだけ書く**（乱しからの回復への寄与とは言わない）。
- 言えない: 必要条件であること。規範一般。M1・M4 との適合。ほかの世界・法則。個体が何かを感じるか（主張しない）。
- 限界: (i) 検査 N だけでは、内在的な規範と、作者が体の量に結んだ報酬の設計を識別できない。(ii) s の遅い成分への結びつきは遅れの対照で判定不能。Δ と駆動の位相の関係が残る。(iii) くびきは行為が変える入力との相関を残せない。(iv) 帯は作者が決めた。適応的な体の変化も失敗に数える。(v) 支払いの単位・判定・順は仮説で、腕の効果に混ざりうる。(vi) 引き分けは「資格の基準を満たしたとは言えない」。(vii) 妥当性の幅は許容の設計。
