## 2. 厳密な因果順序・会計順・閉形式勾配・決定的 IEEE `binary32` 更新則

毎歩 $s$ の実行順序（未来漏れゼロ、全算術は FMA 禁止の IEEE 754 `binary32`、添字 `k = 1..32` 昇順固定）：

1. **窓保持判定（読取専用・S66 継承）と推論（当歩の行為決定前）**:
   - S66 §2 に従い、身体残高 $R_s = \sum_{i \in \mathrm{body}} w.B[i]$ の読取のみで 4 暦歩窓の保持条件（`K_win = 0.002`、ここでは $R_s$ を引き落とさない）を適用する。
   - `B_max` 枠内で決定的 TRM 推論を実行し、問い位置 `pos ∈ {45, 46}` の最終隠れベクトル $h_1, h_2 \in \mathbb{R}^{32}$ を得る（$0$ 巡フォールバック時は $h_a = H_{\mathrm{init}}$）。
   - ロジットと確率を以下の**厳密な演算順**で算出する：
     - $l_{8,a} = \sum_{k=1}^{32} (w_8[k] \cdot h_a[k])$、$l_{7,a} = \sum_{k=1}^{32} (w_7[k] \cdot h_a[k])$（左結合 `acc = acc + w[k] * h[k]`）
     - $s_{8,a} = (l_{8,a} \ge 0.0\mathrm{f}0)\ ?\ (l_{8,a} + 1.0\mathrm{f}0) : (1.0\mathrm{f}0 / (1.0\mathrm{f}0 - l_{8,a}))$（$s_{7,a}$ 同様）
     - $p_a = s_{8,a} / (s_{8,a} + s_{7,a})$
     - $z_{e,a} = (\sum_{k=1}^{32} w_e[k] \cdot h_a[k]) + b_e$、$e_a = 1.0\mathrm{f}0 / (1.0\mathrm{f}0 + \mathrm{exp\_det}(-z_{e,a}))$（S60 `TrmDet` と完全同一の決定的 `exp_det` を使用、`e_a` は記録専用）
   - S66 と同一の比例写像 $\pi_a = 1/8 + (3/4)\cdot p_a/(p_1 + p_2)$ で行為 $a_s \in \{1, 2\}$ を抽選する。

2. **環境・身体 1 歩（`core` 正本実行）**:
   - `core`（`OneLife`）を 1 歩進め（`MCOST`・`KC` 引落、収穫、物質更新）、行為した区画 $a_s$ の応え $Y_s \in \{0, 1\}$ と歩終了後の生存身体 `body_post = {i | w.C[i] != 0}` を得る。
   - **死亡歩の吸収規則**: `isempty(body_post)`（この歩で代謝死）の場合は、**`K_head` 引落・薄れ・勾配更新を一切行わず**、97 重みを最終状態で凍結して歩を終了する。

3. **頭痕跡維持費 `K_head` の実引落・不足時薄れ（生存歩のみ）**:
   - 頭痕跡維持費 $C_{\mathrm{head}} = K_{\mathrm{head}}$（暫定値 `0.002`、S66 窓保持 `K_win` とは独立。S-R で確定）を `core/body_org.jl:157-158` と同一の規則で生存身体から実引落する：
     ```text
     paid = 0.0
     for i in body_post:
         m = min(w.B[i], K_head / length(body_post))
         w.B[i] -= m; paid += m
     port_give!(w.port, paid)
     ```
   - **判定と分岐（端数・不足時の厳密仕様）**:
     - 引落後に `w.B[i] < THETA_EXIST` となっても当歩の生死は次歩先頭（`body_org` 正本と同一タイミング）で判定され、実引落分 `paid` は必ず `w.port` へ返還されて物質保存を保つ。
     - **`paid < K_head - 1e-12`（維持費不足）のとき**: オンライン勾配更新は **スキップ** し、97 パラメータすべてを誕生重み $w^{(0)}$ へ向かって決定的に薄れさせる（$0$ 崩壊させない）：
       $$w_i \leftarrow \mathrm{clamp}\!\left(w_i^{(0)} + 0.875\mathrm{f}0 \cdot (w_i - w_i^{(0)}),\, -16.0\mathrm{f}0,\, 16.0\mathrm{f}0\right)$$
       （$0.875\mathrm{f}0 = 7/8$ は 2 進有限表現）。

4. **オンライン勾配更新（生存 かつ `K_head` 完済 かつ 行為 $a_s \in \{1, 2\}$ 実行 かつ `B_max` 残枠 >= `OPS_HEAD_UPDATE` の歩のみ）**:
   - **`B_max` 枠不足時の扱い**: `K_head` を完済したが `B_max` 残枠が足りない歩では、勾配更新のみスキップし、**薄れは掛けない**（薄れは資源不足のみを原因とする）。
   - **行為した区画 $a = a_s$ のみ**（未行為区画の応えは観測不能なので一切更新しない）：$h = h_{a_s}$, $l_8 = l_{8,a_s}$, $l_7 = l_{7,a_s}$, $p = p_{a_s}$, $e = e_{a_s}$。
   - **厳密な演算順（全 `Float32`、FMA 禁止、`k = 1..32` 昇順）**:
     1. $g_{l8} = (p - \mathrm{Float32}(Y_s)) / (1.0\mathrm{f}0 + \mathrm{abs}(l_8))$
     2. $g_{l7} = (\mathrm{Float32}(Y_s) - p) / (1.0\mathrm{f}0 + \mathrm{abs}(l_7))$
     3. $Y_e = (p \ge 0.5\mathrm{f}0)\ ?\ (1 - Y_s) : Y_s$、$g_{be} = e - \mathrm{Float32}(Y_e)$
     4. 各要素 `k = 1..32` について（$w_8, w_7, w_e$ 共通形）：
        `prod = g_scalar * h[k]` → `gc = clamp(prod, -1.0f0, 1.0f0)` → `delta = eta_head * gc` → `w_raw = w[k] - delta` → `w_new = clamp(w_raw, -16.0f0, 16.0f0)`。
     5. バイアス：`gc_b = clamp(g_be, -1.0f0, 1.0f0)` → `be_new = clamp(be - eta_head * gc_b, -16.0f0, 16.0f0)`。
     6. **非有限値ガード**: 97 要素のいずれかに `NaN` または `Inf` が生じた場合は（`clamp` で隠さず）即時 `NonFiniteWeightError` として関門失敗で停止する。
   - **歩幅 $\eta_{\mathrm{head}}$ の選定規律**: 開発種子（評価種子と完全分離）のみで事前 3 点候補 `{0.015625f0, 0.03125f0, 0.0625f0}`（$= 1/64, 1/32, 1/16$）から 1 点を選び、評価前に凍結する。

## 4. 必須関門（G-C2-GRAD〜G-C2-CORE）

1. **G-C2-GRAD（数値微分・境界ビット照合）**:
   - 参照損失 $\ell_{\mathrm{ref}}(l_8, l_7; Y) = -Y\ln p - (1-Y)\ln(1-p)$（`Float64`）に対し、**中心差分刻み `h_fd = 1e-6`**（`<< 1e-4` により `±1e-4` で $l=0$ の 2 階微分折れを跨がない）で、`l8, l7 ∈ {-10, -1, -1e-4, 0, +1e-4, +1, +10}`（49 格子）×`Y ∈ {0, 1}` の全 98 点で相対・絶対誤差 `<= 1e-6` を確認（`l=0` 点は片側極限一致確認）。
   - さらに `±0.0f0`、勾配クリップ `±1.0f0`、重みクリップ `±16.0f0` および各隣接 `Float32` 値（`prevfloat`/`nextfloat`）において、除算・乗算・クリップ・減算・重みクリップの各段の `Float32` ビット列（`reinterpret(UInt32, x)`）が Julia と Rust で全一致すること、および意図的 `NaN` 注入が `NonFiniteWeightError` で停止することを確認。
2. **G-C2-CAUSAL（因果・非未来漏れ）**:
   - 決定的に選んだ 50 歩で、**学習器へ渡す応答入力 $Y_s$ のみ**を反転する（`core` 身体の収穫 $R$ や池は変えない）。
   - 全 50 歩で「当歩の推論出力 $(p_s, e_s)$ と行為 $a_s$ がビット一致する」ことを必須とし、そのうち更新可能（生存・`K_head` 完済・`B_max` 残枠あり）かつ重み非飽和（クリップ境界 `±16` に張り付いていない）かつ少なくとも 1 要素で `|grad| > 0` かつ `eta_head * grad` が `Float32` 丸めで消失しない（`w - eta_head * gc != w`）な歩すべてで「更新後重み $w_{s+1}$ が必ず変化する」ことを確認する。
   - 未行為区画の応答を変化させても $w_{s+1}$ がビット不変であることを確認する。
3. **G-C2-ACCOUNT（会計境界ユニットテスト）**:
   - (a) `K_win` 適用後・`core` 実行後・`K_head` 引落の間で残高が尽きる歩（部分引落＋`0.875` 薄れ＋更新スキップ＋物質保存誤差 `<= 1e-12`）、(b) 死亡歩（引落・薄れ・更新すべて 0、97 重み凍結）、(c) `B_max` 不足歩（更新スキップ・薄れなし）の 3 境界で期待値ビット一致を確認。
4. **G-C2-BIT（Julia↔Rust・Mac↔Pi 1,000 歩ビット一致）**:
   - オンライン更新＋維持費不足薄れ発火を含む 1,000 歩で、全 97 パラメータ・全歩 `(p_a, e_a)`・`exp_det` 出力が Julia 正本と Rust 写し（Mac・Pi 5）で **1 ビットも狂わず完全一致**すること（負対照：初期重み 1 ulp 改変で不一致検知）。
5. **G-C2-BOUNDARY**: S62b の GB2（`b_shell` 漏れ 0 件）・GB3（未申告書込・RNG 違反 0 件）を再監査通過。
6. **G-C2-CORE**: `sh core/check/run.sh` exit 0、`~/bridge-protocol` 差分 0。

## 5. 事前予測案と厳格な採否規則（反証条件）

- **P-S67-1（関門）**: 全 6 関門（`G-C2-GRAD`〜`G-C2-CORE`）合格。
- **P-S67-2（反転後・OOD 両族での損失改善、Bonferroni 97.5% CI 保守統一）**: `rev` の反転後窓および `ood` の **両方** で、対比較 $L(\mathrm{C1}) - L(\mathrm{C2})$ の 97.5% CI 下限（2 族多重比較 Bonferroni $\alpha = 0.05/2 = 0.025$ 固定）`> 0` かつ勝利種子数 `wins > losses`。
- **P-S67-3（閉ループ非劣化・随伴性）**: 閉ループ生存・構成要素維持において `C2` が `C1` を有意に悪化させず（95% CI が非劣化域）、かつ `C2` が `C2-DELAY`（$\Delta=737$ 軛）を上回る。
- **P-S67-4（実電波 `C4` 系列の非劣化、記述・安全確認）**: `radio_c4` において `C2` の対数損失が `C1` 以下であり発散しない。
- **採択・棄却規則（P-S67-2・P-S67-3 と厳密統一）**:
  - **採択条件**: **P-S67-1 かつ P-S67-2（`rev`・`ood` の両方改善）かつ P-S67-3（閉ループ非劣化・軛優越）かつ P-S67-4（`radio_c4` 非劣化）のすべて**を満たすときに限り、第一号 AUE へ C2 を採択する。
  - *反証条件*: `rev` と `ood` の片方だけしか改善しない、あるいはいずれかで C1 に勝てない／閉ループ生存を悪化させる場合、**頭のみオンライン学習 `(c)` は不採用**とし、第一号 AUE は `C1`（凍結頭＋窓保持）構成で切り出す。
