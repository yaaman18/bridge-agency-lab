## 1. 容量集合（案 D1）と各点の根拠

$C \in \{0, 1, 2, \infty\}$ の 4 点を固定する（いずれも構造上の最小境界・対照であり、S88 分布に依存しない）:
- **$C = 0$**: 断片層 $M$ を空に固定する構成上の負の対照。L-FGT との毎歩ビット一致（L2L §4 P1）および $\Delta G_{\text{O1}} \equiv 0$ の関門。
- **$C = 1$**: 満杯状態からの「単独候補の退去」（R1 非発火時は不変、R1 発火時のみ既存 1 件を捨てて新 1 件を置く）を検査する最小有限容量。
- **$C = 2$**: 満杯状態からの「複数候補からの退去先選択（最古＝FIFO の識別と 2 件目の繰上げ）」を検査する最小有限容量。
- **$C = \infty$**: 退去なしの対照。S88（`experiments/s88_l2l/out/l2l.out` および `life88` 再計算）の再現関門、および有限 $C \in \{1, 2\}$ との比較基準点。

※ 有限 2 点（`1, 2`）の通過は任意の有限 $C$ での正しさの自動証明にはならない（任意 $C$ の正しさは独立参照実装との一致関門 G6 とコードレビュー I-R で担保する）。

## 2. 学習器と D1（古い順退去）の厳密仕様

- 学習器は `specs/L2L-draft-two-layer-learner.md` の表の版 **L2L-T**（比較対照は公式 **L-FGT**）。
- 状態 $x = (K, M)$:
  - $K = (n, n_1, rn, rn_1)$: L-FGT と同じ計数。毎歩「減衰（$\lambda = 1 - 1/2000$）→ 加算」で更新（全例で更新、Q1）。
  - $M$: 長さ $\le C$ の順序付き断片列 `list`（要素は 4 整数 `(t, k, a, y)`、先頭が最古・末尾が最新）と、鍵別・行為別集計 `(m, m1, ma, ma1)`（整数 `Int` または厳密一致する集計）。$M$ は減衰しない。
- 出力 **O1**（表の版固有、S88 と完全同一の式）:
  - 鍵 $k$（行為 $a = \text{akey}(k)$）に対し、
    $$\text{rate}(a) = \frac{n_1[a] + ma_1[a] + 1}{n[a] + ma[a] + 2}, \quad p^{\text{raw}}(k) = \frac{rn_1[k] + m_1[k] + \alpha \cdot \text{rate}(a)}{rn[k] + m[k] + \alpha}, \quad p(k) = \text{clip}(p^{\text{raw}}(k))$$
    ここで $\alpha = \text{ALPHA\_R1}$、`clip(x) = clamp(x, LO, HI)` は既存基体（S72/S84/S88）の定数をそのまま用いる。行為別集計 `ma[a], ma1[a]` が `rate(a)` に入るため、$m_t[k] = 0$ の鍵であっても同一行為の断片により $p(k)$ が変化し得る（`rate-only` 寄与は恒等的に 0 ではない〔claude #7〕）。
- 1 歩の手順（例 $t$、鍵 $k_t$、行為 $a_t$、結果 $y_t \in \{0, 1\}$）:
  1. 更新前の状態 $(K, M)$ で $p_t = O1(K, M, k_t)$ を読む。
  2. 残す規則 **R1**: `kp = (y_t == 1 && p_t < 0.5) || (y_t == 0 && p_t > 0.5)`（$p_t = 1/2$ は残さない）。独立式 `(2y_t - 1)(2p_t - 1) < 0` と毎歩照合する。
  3. $K$ を L-FGT と同一手順で更新する。
  4. 捨てる規則 **D1（FIFO）** 付きで $M$ を更新する:
     - $C = 0$: `kp` によらず $M$ は空のまま（何も追加・削除しない）。
     - $C \ge 1$（有限）: `kp == false` なら $M$ は一切変えない（満杯でも追い出さない）。`kp == true` なら、更新前に `length(M.list) == C` のときに限り先頭（最古）の 1 件 `(t_old, k_old, a_old, y_old)` を削除して集計から引き、末尾に `(t, k_t, a_t, y_t)` を追加して集計に足す。
     - $C = \infty$: 削除なし（`kp == true` なら末尾追加、S88 と完全同一）。
- データ列・切れ目・原点: S84・S86・S87・S88 と完全同一（既見 48 生、`origins84` の群 `F, R, C`、遅延 $h \in \{50, 200, 1000\}$）。

## 3. 観測と診断量の定義

### 3.1 痕跡（TRACE-1 r6 D4、BP14 (b) 併記規約）
- **表 $T$**: 全 130 鍵の予測表。距離は L1 和（S86・S88 規約）。
- **探り $Q$**: 場の探り 2000 入力（`qkeys`）。距離は平均差（S87・S88 規約）。
- **反転の双子**: 原点 $t_0$ の主の状態 $(K_{t_0}, M_{t_0})$ から例 $s = t_0 + 1$ の結果のみを $1 - y_s$ に反転し、同一の後続入力を同一容量 $C$・D1 で進める。読み取り点 $t = s + h \le N$ で $D_s(s+h)$（$T, Q$）、$N_T$、$G_T$ を読む。

### 3.2 N3 逆バイアス診断（同一 `(生, t, K)` 上の O1 前後比較）
- **読み取り集合 $U$**: 既見 48 生にわたり、`origins84`（群 `F, R, C`、$h \in \{50, 200, 1000\}$）に対応する読み取り時点 $t = s + h \le N$ のうち、各生でユニークな `(生, t)` の集合。同じ `(生, t)` が複数の原点・遅延から参照されても **1 回（重み 1）** だけ数える〔claude #9〕。全 4 容量 $C \in \{0, 1, 2, \infty\}$ で全く同じ集合 $U$ を用いる。
- 任意の `(生, t) ∈ U` では、関門 G1 により主の $K_t$ は全 $C$ および FGT でビット一致する。同一の $K_t$ に対し:
  - O1 適用前（$K$ 単体）: $p_{K,k}(t) = O1(K_t, \emptyset, k)$、$p_{K,k}^{\text{raw}}(t)$、表 $T_K(t)$、出生時距離 $G_T(T_K(t)) = \sum_{k=1}^{130} |p_{K,k}(t) - 1/2|$。
  - O1 適用後（$K + M_t^{(C)}$）: $p_{K+M,k}(t) = O1(K_t, M_t^{(C)}, k)$、$p_{K+M,k}^{\text{raw}}(t)$、表 $T_{K+M}(t)$、出生時距離 $G_T(T_{K+M}(t)) = \sum_{k=1}^{130} |p_{K+M,k}(t) - 1/2|$。
- **出生時距離の差と鍵集合別分解**:
  - 総量 $\Delta G_{\text{O1}}(t) = G_T(T_{K+M}(t)) - G_T(T_K(t))$ は二つの表の距離の差として独立に算出する〔codex P3〕。
  - 鍵別変化 $\Delta g_k(t) = |p_{K+M,k}(t) - 1/2| - |p_{K,k}(t) - 1/2|$ を鍵集合で二分する:
    - **直接断片あり鍵（$m_t[k] > 0$）**: $\Delta G_{\text{direct}}(t) = \sum_{k: m_t[k] > 0} \Delta g_k(t)$。注: O1 の式上、この側にも行為別 `rate` 変化が混ざるため、二分が測るのは「鍵集合別の総変化」まで〔codex P5〕。
    - **直接断片なし鍵（$m_t[k] = 0$、`rate` 経由のみ）**: $\Delta G_{\text{rate-only}}(t) = \sum_{k: m_t[k] = 0} \Delta g_k(t)$。
- **向き付き変化（元の偏りに逆らう変化、基準側内点の切り出し）**:
  - 直接断片あり鍵集合 $K^+(C) = \{(生, t, k) \mid (生, t) \in U,\ m_t^{(C)}[k] > 0,\ p_{K,k}(t) \ne 1/2\}$ の各要素 `(生, t, k)`（各 1 票）に対し、元の偏りの向き（$1/2$ から離れる向き）を正とする符号付き変化を定義する:
    $$\delta_{\text{out}}(t, k) = \operatorname{sign}(p_{K,k}(t) - 1/2) \cdot \bigl(p_{K+M,k}(t) - p_{K,k}(t)\bigr)$$
    注: 例えば $p_K = 0.6 \to p_{K+M} = 0.3$ のように $1/2$ を横断すると $\delta_{\text{out}} = -0.3 < 0$ でも $\Delta g = +0.1 > 0$ となり得る〔codex P5〕。よって $\delta_{\text{out}} < 0$ は「元の偏りに逆らう変化（$1/2$ 側への引き戻し）」として読み、$1/2$ 横断件数と $\Delta g$ の平均を必ず併記する。
  - $K^+(C)$ を基準側の切り詰め前値 $p_{K,k}^{\text{raw}}(t)$ と既存定数 `LO, HI` で排他分割する〔claude #5、codex P6〕:
    - **基準側内点鍵 $K^+_{\text{in}}(C)$**: $\text{LO} < p_{K,k}^{\text{raw}}(t) < \text{HI}$（厳密不等号。$p_{K,k}^{\text{raw}} = \text{LO}$ または $\text{HI}$ は境界側へ入れる）。
    - **基準側境界鍵 $K^+_{\text{clip}}(C)$**: $p_{K,k}^{\text{raw}}(t) \le \text{LO}$ または $p_{K,k}^{\text{raw}}(t) \ge \text{HI}$。
  - さらに $K^+_{\text{in}}(C)$ の内訳として、追加後も内点にとどまる「両側内点」（$\text{LO} < p_{K+M,k}^{\text{raw}}(t) < \text{HI}$）と「追加後に境界到達」を分けて記述出力する〔codex P6〕。

## 5. 予測（結果を見る前に `experiments/s89_l2l_d1/predictions.toml` へ凍結）

### 共通の判定規約〔codex P7、claude #9〕
- 等号（`= 0`、あるいは $\overline{\Delta D}_C = \overline{\Delta D}_\infty$）はすべて **外れ（miss）**。
- 複数容量にまたがる予測で、空集合（判定不能）と反例（外れ）が併存する場合は **反例（miss）を優先**する。反例が 1 つでもあれば `miss`、反例 0 かつ空集合が 1 つ以上あれば `undecidable`、全容量非空かつ全成立なら `hit`。

### 凍結予測（S89-E1〜E3）
- **S89-E1（同一 K 上の出生時距離低下、N3 予測）**〔codex P7〕:
  - 単位: 重複を除いた集合 $U$ の各 `(生, t)` を 1 票。
  - 予測: 平均 $\overline{\Delta G_{\text{O1}}} < 0$ が $C \in \{1, 2, \infty\}$ の **3 点すべて**で成立する。
  - 注（事後性明記）: S88 では $C=\infty$ の群別 $G_T$ 四分位低下が既知だが、重複除去した $U$ 上の対応差平均は未計算のため $\infty$ も含めて判定し、事後性を明記する。
- **S89-E2（基準側内点鍵での元の偏りに逆らう変化、N3 対切り詰め緩和の識別）**〔claude #5、codex P5・P6〕:
  - 単位: 基準側内点鍵集合 $K^+_{\text{in}}(C) = \{(生, t, k) \mid (生, t) \in U,\ m_t^{(C)}[k] > 0,\ p_{K,k}(t) \ne 1/2,\ \text{LO} < p_{K,k}^{\text{raw}}(t) < \text{HI}\}$ の各 `(生, t, k)` を 1 票。
  - 予測: 平均 $\overline{\delta_{\text{out}}} < 0$ が $C \in \{1, 2, \infty\}$ の **3 点すべて**で成立する（全 $K^+(C)$ は境界鍵の機械的偏りを含むため独立予測とせず記述へ格下げ）。
- **S89-E3（有限容量 D1 退去による $h=1000$ 痕跡上乗せの減少）**〔codex P1、claude #4〕:
  - 対象集合（固定積集合）: 既見 48 生の `origins84`（群 `F, R, C`, $h = 1000$）から `(生, s)` を一度ずつ取り、$s + 1000 \le N$ かつ **$C \in \{1, 2, \infty\}$ の 3 容量すべてで更新前 $p_s^{(C)} \ne 1/2$** を満たす共通適格原点集合 $S_{\text{common}}$（各 `(生, s)` を 1 票）。
  - 予測: $S_{\text{common}}$ 上の表 $T$ 対応差平均 $\overline{\Delta D}_C = \text{mean}_{(生,s)\in S_{\text{common}}}(D_s^{\text{L2L}(C)}(s+1000) - D_s^{\text{FGT}}(s+1000))$ について、$\overline{\Delta D}_1 < \overline{\Delta D}_\infty$ かつ $\overline{\Delta D}_2 < \overline{\Delta D}_\infty$ が成立する（各容量の除外件数と容量単独集合の集計も記述に併記）。
