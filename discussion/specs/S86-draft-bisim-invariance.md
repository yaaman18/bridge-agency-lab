# S86 草案: 定義がふるまいの同値で変わらないかの試験（双模倣の不変性、既見 48 生だけ）

- 起こした日: 2026-11-26。ユーザー「その方向で進めて、bp-proposalsに追記して試験を組んで」。BP14・仮定 H11。
- codex S-R 2026-11-26: P1・P3 accept、P2・P4〜P6 を取り込み（〔P番号〕）。
- 位置: 数の大小の予測ではない。定義の形の試験。(i) ふるまいが同じで内部の違う実装で、定義の値が変わらないか（不変性）、(ii) 中身の違う個体に同じ定義を当てて、構造の性質が成り立つか。**新しい種子は開けない**。法則の数（λ・α・切り詰め・区画）は変えない。

## 1. 個体（余代数）と入出力の型
- 入力の型: 各例で（鍵 k、行為 a、結果 y ∈ {0, 1}）。出力の型: いまの状態での全 130 鍵の予測の表 T(x) ∈ [1/200, 199/200]^130（一歩先のふるまい）。
- 型の中の操作だけで書く定義（H11）:
  - 一歩の変化 d(t) = L1(T(x_{t−1}), T(x_t))（S84 の d）。二点の差 N(t0, t)（S84）。
  - **痕跡** D_s(t) = L1(T(x_t), T(x_t^{¬s}))。x^{¬s} は、例 s の結果だけを 1 − y_s に変え、ほかは同じ入力を受けた双子（入力は 2 値のまま、型の中）。s ≺ t ⇔ D_s(t) > 0。D_s は後続の入力を固定した条件での、結果 1 個への感度（例を抜く案は減衰 1 回を省く効果まで含むので採らない〔P3〕）。
  - G(t) = L1(T(x_t), T(x_0))（出生時の表からの距離、S85）。
- 型の外の操作を使う定義（対照）: S85 の刻み Θ（結果に分数の見込みを入れる）。

## 2. 三つの同値な実装（どれも L-FGT と同じふるまい）
- A: 公式の L-FGT（`s72r2.jl` update2!）。
- B: 結果を y² で数える（n1[a] += y²、rn1[k] += y²）。y ∈ {0, 1} では y² = y がビット単位で成り立つので、2 値の入力の列すべてで A と同じ状態・同じ表。分数 p̂ を入れると p̂² になり、A と違う。
- C: 数を 4 倍で持つ（加算 4、4y、表は (rn1 + 4α·r)/(rn + 4α)、r = (n1 + 4)/(n + 8)）。2 の冪の倍は、値が正規の範囲にある限りどの演算でも丸めを変えないので、A とビット単位で同じ表（法則から先に言える。演算の順は A とそろえ、非零の数の最小値が正規の範囲にあることを関門で確かめる〔P2〕）。分数の入力でも同じ（線形の書き換え）。
- D: C の 4 倍の表現に B の加算（4y²）を組み合わせたもの。状態は A と違い（4 倍）、分数の入力の受け方も違う〔P1〕。
- 同値の根拠（法則の側）〔P4〕: B は状態の恒等の関係、C・D は「数 = A の 4 倍」の関係。この関係は出生時に成り立ち（すべて 0）、2 値のどの入力でも一歩の後に保たれ、表を保つ。よって双模倣。走行で確かめるのは、既見 48 生の各接頭列（と反転の双子の列）の上での一致まで。
- 中身の違う個体（構造の性質）: F0 = 固定のプログラム（入力を読まず、表は常に 1/2）。

## 3. 予測と関門の区別（走らせる前に凍結）〔P5〕
- 構成から決まるもの（関門として扱い、外れたら実装の誤り）:
  - G1: B・C・D は 48 生のすべての歩で、A と表がビット単位で一致。反転の双子の列でも一致。
  - G2: d・N・G・D_s（群 F・R・C の原点を s とし、h ∈ {50, 200, 1000}）が、A・B・C・D でビット単位で一致。
  - G3: F0 では d・N・G・D_s がすべて 0。
- 予測（構成からは決まらない）:
  - E1（型の外の定義は不変でない）: 群ごと・h ごとに集めた S85 の Θ の中央値が、B と A で違う（h = 200 の群 F・R・C のどれか 1 つ以上）。D と A でも同じ。C と A は全原点でビット単位で一致。3 実装とも「減衰 → 切り詰め前の見込み raw → 各実装の加算」を通す〔P6〕。

### 6.1 確認した事実
- 関門（構成から決まるもの）はすべて通過: G1 A・B・C・D の表は 48 生の全歩と全反転双子でビット一致。G2 型の中の定義（D_s・N・G・d の和）は 4 実装でビット一致。G3 固定のプログラムではすべて 0。非零の計数の最小値 1.9e-14（正規の範囲）。反転の効き、Θ_A = S85 の twin のビット一致。
- **E1 的中**: S85 の Θ は、ふるまいが同じ実装 B（y² で数える）・D（4 倍＋4y²）で A と違う。全 4114 原点でビット単位で違い、中央値の比 Θ_B/Θ_A は F h=1000 で 15.3、F h=200 で 5.0、R h=1000 で 0.91、C h=200 で 1.00。C（4 倍）は全原点で A とビット一致。
- **E2 的中**: D_s(s + 1000) > 0 は 1229/1229（除外 48）。1 個の結果の痕跡は 1000 例後も像の上に残る。
- 記述: D_s(s + h) の中央値は、つなぎ目で大きい（C h=50 で 0.530、h=1000 で 0.400）。形成は 0.119・0.032、通常は 0.055・0.034。D_s = 0 の原点は 0。
### 6.2 推論
- S85 の刻み Θ は、2 値の入出力のふるまいだけでは決まらない（同じふるまいの B で最大 15 倍違う）。型の外の操作（結果に分数を入れる）が、実装の任意の延ばし方を拾う。H11 のとおり Θ は根拠にしない。形成と通常の分離（S85 E1・E2）も、A の延ばし方に依っていた可能性がある。
- 型の中の定義（反転の痕跡 D_s など）は、構成から不変で、実装を替えても同じ値。ルーティン・形成・つなぎ目の違いは、D_s では「つなぎ目の結果 1 個が最も強く残る」形で出る（その鍵の経験の数が少ないため。S83 と同じ向き）。
