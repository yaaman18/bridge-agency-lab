## 1. 量
- ふるまい: L-FGT の予測表 p(t) ∈ [0,1]^130。鍵 k（6 ビット＋行為、`s72.jl` r1key_map、k = 2b + a、a = 1 は奇数の k、a = 2 は偶数の k）ごとに p_k(t) = clip((rn1[k] + α·rate_a)/(rn[k] + α))、rate_a = (n1[a] + 1)/(n[a] + 2)、α = 1。未訪問の鍵も含めた全 130 鍵（どの入力に対しても個体がどう予測するか）。
- 時刻 t の表 = 例 t までの更新を終えた状態の表。法則の一歩 = 1 例の更新（減衰と加算、`s72r2.jl` update2!）。
- 尺度（一度だけ決める、Fable §3「L1 と凍結」）: d(p, q) = Σ_k |p_k − q_k|。
- 端点の差 N(t0, t) = d(p(t0), p(t))。経路の長さ P(t0, t) = Σ_{s=t0+1}^{t} d(p(s−1), p(s))。比 ρ(t0, h) = N/P（P = 0 なら未定義）。
- 地平 h ∈ {50, 200, 1000}（記述）。判定に使うのは下の 2 点だけ。

## 2. 原点の群（各生、S83 と同じ定義を流用）

- 回し直した表から各例の予測時の値（区画の頭の表の p_{k_t}）を取り、保存した P とビット単位で一致。
- 区画の途中でも、各歩の表を、そのときのカウンタから別の関数で全 130 鍵について作り直し、ビット単位で一致〔P6〕。

- 減衰だけの双子: n・n1・rn・rn1 の全成分が、原点の値に λ を h 回、update2! と同じ順にかけた値とビット単位で一致（加算がない）〔P6〕。

### 6.2 推論
- 通常区間は拡散的でなく、ほぼ一方向に動いている（ρ ≈ 0.3）。双子の対照値から、その大半は λ の減衰で表が rate へ寄る決定論的な流れで説明がつく（対照値で寄与率ではない）。これは「外の歩数で一定に進む」成分で、Fable と claude-lab が挙げた懸念が数で出た。
- 形成頭は一歩の変化も端点の差も通常の約 4 倍で、ほぼ一方向（ρ ≈ 0.9）。ただし分布は重なり、ρ も N も一本の線で分けられない。
- E4: L-FGT では、ほぼすべての法則の歩で表が変わる。一方、訪れた鍵の予測は 9 割の歩で変わらない（切り詰めに張り付き）。変化の多くは訪れていない鍵の減衰と rate の動きから来る。Fable 案 3 の読み「L-FGT では全歩が刻みで、ルーティンは観測の粗さに相対的にしかない」を支える。
- つまり、L-FGT の「自分の変化」には、出来事による変化と、減衰（忘却）による一様な変化が混ざり、後者が通常区間の変化の大半を占める。端点と経路の比では二つを分けられない。
### 6.3 提案（未決）
- 忘却（減衰）を「自分の変化」に数えるかは定義の問いで、データで決めない。数えないなら、法則を「加算の項」と「減衰の項」に分けて、加算の項だけの変化（Fable 案 1 の出来事の分け前）を測るのが筋。
- L-FGT は一つの表しか持たないので、技能（表の傾き）と断片（個別の出来事の痕跡）を分けられない。ここは学習器の構造の問い（ユーザー判断）。
