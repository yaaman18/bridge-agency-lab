## 0. 起草で見つけた点（codex に見てほしい）
- 「入力がなかった双子（減衰だけ）」との差を刻みにすると、完全なルーティンでも刻みが進む。定入力では表は不動点にあり（x = I(D x)）、入力は減衰を打ち消して技能を保つだけだが、減衰だけの双子は離れていくので差が溜まる。これは維持（痕跡の維持費の支払い）を刻みと数える誤り。
- そこで反事実を「入力がなかった」でなく「**予期どおりの入力だった**」にする。同じ鍵に、結果 y の代わりに自分のいまの予測 p̂ を受け取った双子（数は実数なので分数の加算ができる）。完全なルーティン（y ≈ p̂）では刻みは 0 に近く、減衰は両方に同じくかかるので刻みに入らない。

## 1. 量（法則 L-FGT、`s72r2.jl` update2!、初期の数はすべて 0）
- 状態 x = (n[2], n1[2], rn[130], rn1[130])。一歩 = 減衰 D（全成分 ×λ）のあと加算 I_{k,a,y}（n[a] += 1、n1[a] += y、rn[k] += 1、rn1[k] += y）。
- 表 T(x)_k = clip((rn1[k] + α·rate_a)/(rn[k] + α))、rate_a = (n1[a]+1)/(n[a]+2)。尺度 d = L1（S84 と同じ、一度だけ決めたもの）。
- **共通の原点** x∅ = 0（生まれたときの状態で、減衰だけを無限にかけた行き先）。T(x∅) ≡ 1/2（全 130 鍵）。法則だけから書ける。
- **個の距離**（名は「出生時の表からの距離」〔P6〕。G が等しくても表の違う二個体はありうるので、同一性そのものではなく、その目安） G(t) = d(T(x_t), T(x∅)) = Σ_k |p_k(t) − 1/2|。G(0) = 0。
- 一歩の帳簿: G(t) − G(t−1) = ΔG_dec(t) + ΔG_inc(t)、ΔG_dec = G(D x_{t−1}) − G(x_{t−1})（忘却）、ΔG_inc = G(x_t) − G(D x_{t−1})（入力）。和は端点の差に一致（恒等式）。
- **予期の双子**（一歩）: x̂_t = I_{k,a,p̂}(D x_{t−1})、p̂ = (rn1[k] + α·rate_a)/(rn[k] + α) を D x_{t−1} で評価した値（数の模型自身の見込み。**切り詰め前**。切り詰めは採点の出力の側の規則で、見込みの側ではないと読む。切り詰め後にすると、張り付いた鍵で毎歩 |y − p̂| = 1/200 の偽の驚きが出て、定入力でも未訪問の鍵の rate を通じて刻みが溜まる）。**一歩の刻み** τ(t) = d(T(x_t), T(x̂_t))。
- **二点の刻み** Θ(t0, t) = d(T(x_t), T(x̂_{t0→t}))。x̂_{t0→t} は t0 の状態から、同じ鍵の列を受け取り、各歩で自分（双子）のいまの予測 p̂ を結果として受け取った双子（本物の p̂ を渡すと t0 後の実際の y が双子へ漏れるので、双子自身の p̂〔P2〕）。鍵の列は観測の列に固定した、条件つきの定義。減衰は両方に同じくかかる。
- 記述の対照: S84 の N（端点の差）と N_dec（減衰だけの双子）を併記。

## 3. 恒等式と構造の性質（関門。走らせる前に法則から書ける。外れたらコードか定義の誤り）
- (i-1) 帳簿の閉包: 各生・全歩で Σ ΔG_dec + Σ ΔG_inc = G(t) − G(0)（逐次和、相対 1e-9）。
- (i-2) 一歩の刻みの閉じた形: 実際と予期の双子の差は結果の n1[a]・rn1[k] にだけ y − p̂ の差で入る。切り詰め前の表では、訪れた鍵 k の差 = (y − p̂)(1 + α/(n[a]+3))/(rn[k]+1+α)、同じ行為 a のほかの鍵 j の差 = α(y − p̂)/((n[a]+3)(rn[j]+α))、ほかの行為の鍵は 0（rn・n・rn[j] は D x_{t−1} の値、つまり減衰後・加算前）。よって τ(t) = |y − p̂|・g(t)（驚き × 法則で決まる利得）。切り詰めは 1-リプシッツなので、τ ≤ |y − p̂|・g(t)、どの鍵も両側で切り詰めにかからない歩では等号。照合: 切り詰め前の表の差の絶対和 = |y − p̂|・g（相対 1e-12）、切り詰め後の τ ≤ それ（全歩）、さらに両端を個別に切り詰めた差の絶対和として作り直した τ と、双子を回した τ のビット一致〔P3〕。
- (i-3) Θ(t, t) = 0、Θ(t−1, t) = τ(t)（ビット）、各歩で y = p̂ を与えた経路（本物も双子と同じ入力）では全区間で Θ = 0〔P7〕。
- (ii-1) 予期の双子に実際の y を渡すと本物とビット単位で一致（双子の経路の正しさ）。
- (ii-2) 定入力の負の対照（合成、生とは別、鍵 1 つ・行為 1 つ、2 万歩、t0 = 10000）〔P4〕:
  - (a) 飽和: y = 1 を毎歩。法則から Θ = N_dec = 0（終点の n > 1200 で、同じ行為の未訪問鍵まで rate > 199/200 に張り付き、予期の双子でも余裕が保たれる。codex の帰納）。関門: h = 1000 で Θ と N_dec がともに 0。
  - (b) 飽和しない定まった繰り返し: y = 1, 1, 1, 0, …（周期 4、平均 3/4。周期 2 は平均 1/2 で表が原点 1/2 のまま動かず、Θ も N_dec も 0 近くになり比べられないので避けた）。予期の双子との差は揺れの分だけで、減衰で忘れられるので h とともに増えない。減衰だけの双子は離れ続ける。記述: h = 1000・10000 の Θ と N_dec を出し、予測 E6 で向きだけを判定する。確率的なルーティンでは一歩の刻み τ は 0 にならない（揺れそのものは予期を超える）ことも記録する。
- (ii-3) 入力なし: D^h x = λ^h x と T の連続性から、h → ∞ で G → 0（x∅ に戻る）。有限の h では、D^h x を独立に作り直した表と、減衰を h 回かけた表のビット一致を照合する〔P7〕。

### 6.1 確認した事実
- 関門はすべて通過。
- **E1 的中**: Θ(·,200) の中央値 R 0.0332 < C 0.0752 < F 0.5753。
- **E2 的中**: 48/48 生で F の中央値 > R の中央値（欠ける群なし）。
- **E3 的中**: R h=1000 で Θ の中央値 0.197 < N_dec の中央値 0.282（同じ桁）。
- **E4 的中**: ΔG_dec > 0 の歩 674,319 / 2,861,512（23.6%）。窓ごとの ΣΔG_dec の中央値はどの群でも負（C h=1000 の上の四分位だけ正 0.0025）。
- **E5 的中**: F で G(T+200) − G(T) の中央値 −0.209（四分位 −0.449〜0.079）。h=1000 で −0.640、2000 例後 −0.673。縮みの大半は ΣΔG_inc（入力）から（h=1000 で −0.474、減衰 −0.141）。1/2 を横切った鍵は h=200 で中央値 0、h=1000 で 2。

- 一歩の刻みの和 Στ と端点の刻み Θ は近い（R h=200 で 0.042 と 0.033、F で 0.592 と 0.575）。

### 6.2 推論
- 「予期の双子」との差は、閾値なしに形成と通常を分けた（生ごとに 48/48、中央値で約 17 倍）。S84 の端点の差 N（約 4 倍、分布が重なる）より分離がよいのは、減衰の一様な流れが両側で打ち消されるから。つなぎ目は中間で、新しい世界の実際の驚きとして刻まれる。
- ただし通常区間でも h=1000 で Θ は減衰の動きと同じ桁（0.197 対 0.282）。確率的なルーティンでは揺れそのものが予期を超え、一歩の刻みは 0 にならない。E6 の外れは、Laplace の事前（α・rate の +1/+2）が双子の比をゆっくり動かす偏りで説明がつく（codex I-R P5: p̂ − q = α(1−2q)/((m+2)(m+α))。有限の t0 の寄与は未分離）。
- G はほぼ全鍵が切り詰め近くで、未訪問鍵は行為ごとの rate を写す。G は「出生時の表からの距離」としては場の基準率でほぼ決まり、個体差の目安として弱い（推論。codex P4: 基準率をそろえても G の順位が個体ごとに再現するかで確かめる）。
- 形成で G が縮むのは、忘却でなく入力による（ΣΔG_inc が大半）。古い世界の技能が新しい世界の入力で崩される。忘却は 23.6% の歩で G を増やしもする（p_k が rate へ寄るとき）。
### 6.3 提案（未決）
- 個体差の目安は、出生時の表でなく「同じ法則で同じ場を生きたほかの個体」との距離（兄弟の距離）、または基準率をそろえた G にする（codex P4 の確かめを兼ねる）。
- 刻みの定義（予期の双子）は、確率的なルーティンに揺れの分の刻みを残す。それを「時間が進んでいる」と読むか（揺れは世界の新しさ）、揺れの期待分を差し引くか（決定論的に書ける: 期待の驚き = p̂(1−p̂) 系の項）は定義の問い。
- 断片の層は L-FGT にない。二層の学習器の仕様は別に起こす（承認済み）。
