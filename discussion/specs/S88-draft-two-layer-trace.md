# S88 草案: 二層の学習器 L2L-T の痕跡を L-FGT と比べる（既見の生だけ）

- 起こした日: 2026-11-27。ユーザー「r6 に差し替えて、S88 も組んで」。学習器は `specs/L2L-draft-two-layer-learner.md`（codex S-R 2026-11-27 P1〜P7 を取り込み済み）の表の版。TRACE-1 r6（requirements.md、decisions-log #88）の定義 D2・D4 と恒等式 I1〜I5 で測る。BP14・H11、BP13・H10。
- 位置: 数を合わせる試験ではない。断片の層を足したとき、型の中の同じ定義（反転の痕跡 D_s）の上で、痕跡の残り方が作りから見込めるとおりに変わるかを見る。**新しい種子は開けない**。法則の数（λ・α・切り詰め）は変えない。
- 容量 C はユーザーが未決。本走りは **C = ∞（捨てない）** で行い、新しい数を持ち込まない。C = 0 は関門（L-FGT とのビット一致）に使う。生の終わりの断片の件数を記述として出し、ユーザーが C を決める材料にする。捨てる規則 D1 の試験は C が決まってから。

## 1. 学習器
- FGT: L-FGT（S72 r4、λ = 1 − 1/2000）。既見 48 生。一例ずつの更新（update2! と同じ式の順: 減衰 → 加算）。
- L2L-T: 状態 (K, M)。K は FGT と同じ計数で、全例で FGT と同じ更新。M は残した例の列（t, k, a, y）と、その集計 m[k]・m1[k]（鍵ごと）、ma[a]・ma1[a]（行為ごと）。M は減衰しない。
  - 出力 O1: 鍵 k の予測 = clip((rn1[k] + m1[k] + α·rate) / (rn[k] + m[k] + α))、rate = (n1[a] + ma1[a] + 1) / (n[a] + ma[a] + 2)、a = 鍵 k の行為。M が空なら L-FGT の表と同じ式・同じ値。
  - 一歩: (1) 例 t の鍵 k_t の予測 p_t を、更新の前の O1 で読む。(2) 残す規則 R1: y_t = 1 かつ p_t < 1/2、または y_t = 0 かつ p_t > 1/2 なら残す。(3) K を FGT と同じに更新。(4) 残すなら M に足す（C = ∞ なので捨てない）。
- 例の列と切れ目は S84・S86 と同じ（鍵 K[t]、行為 A[t]、結果 Y[t]、各生の 5 つの写像）。

## 2. 観測と痕跡（r6 の D4、二つの観測を併記する。BP14 (b) の 2026-11-27 追記の案）
- 表 T: 全 130 鍵の予測の表。距離は L1 の和（S86 と同じ規約）。
- Q: 場の探り（S87 と同じ 2000 入力、鍵 qkeys で表を読む）。距離は平均の差（S87 と同じ規約）。
- 反転の双子: 原点 t0 の主の状態から、例 s = t0 + 1 の結果だけを 1 − y_s にし、同じ後続の入力を受ける。双子も自分の O1 で R1 を判定する（後続の採否は枝で分かれうる。L2L §4 P4）。D_s(s + h) を読む（S86 の添字の規約）。
- 原点: origins84 の群 F・R・C、h ∈ {50, 200, 1000}。s + h が生に入らない原点は除外して数を出す。
- 「s を残した枝」: p_s ≠ 1/2 なら、主と双子のちょうど一方が s を残す（y_s と 1 − y_s の一方だけが p_s の向きに外れる）。p_s = 1/2 ならどちらも残さない（関門 G5）。

## 3. 関門と予測（走らせる前に凍結）

  - G4 反転なしの双子は、読み取り点で主と表がビット一致（L2L-T・FGT）。
  - G5 R1 の独立の照合〔codex P7〕: 各枝・各歩で、更新前の O1 の予測とその枝の y から採否を別の式で計算し直し、M への実際の追記と照合する。p_s ≠ 1/2 の原点では s を残すのは主と双子のちょうど一方、p_s = 1/2 では両枝とも s を追記しない。p_s = 1/2 の原点の数を出す。
  - G6 FGT の表 T の上の D_s の群・h ごとの四分位が、S86 の出力（`s86_bisim/out/bisim.out` の A の D）と 4 桁で一致。

- 予測（構成からは決まらない）:

  - E3（ルーティンの結果は断片に残りにくい）: 主の流れで、R1 が残した例の割合が、形成の窓（formwin、S83 と同じ）の例のほうが通常の窓（routinewins、S83 と同じ）の例より大きい（48 生をまとめた割合で）。窓は S83 の formwin・routinewins を固定して使う。数える単位は（生, t）で、窓が重なる例は各種類の窓で一度ずつ（同じ種類の窓の重なりは一度）。形成・通常それぞれの採択件数と対象例数を出す。どちらかの分母が空なら判定不能。同値以下は外れ。生ごとの勝ち数も出す（判定には使わない）〔codex P5〕。

## 7. 結果（2026-11-27、`experiments/s88_l2l/out/l2l.out`、freeze-s88 に sha）
### 7.0 経緯
- 手順どおり: 仕様 → codex S-R（P1〜P8）→ 予測の凍結 → コード → 関門だけの小試験と負の対照 2 つ（R1 の不等号を逆にすると G5 が落ちる、加算→減衰の順にすると G1 が落ちる）→ codex I-R（P2 FGT 側を公式の update2! に、P4 窓の数え方）→ 閉じてから本走り。I-R の前に本走りはしていない。本走りは約 1 分。
### 7.1 確認した事実
- 関門 G1〜G7 全通過（FGT の T・Q の上の D の四分位は S86・S87 の出力と 4 桁で一致）。p_s = 1/2 の原点は 0。
- E1 的中: 対象 1229/1277、対応差 D_L2L − D_FGT（表 T、h=1000）の平均 0.1302（四分位 0.048 / 0.059 / 0.268）。
- E2 的中: 対象 1229 のうち L2L-T の D = 0 は 0。
- E3 的中: R1 が残した割合は形成の窓 1221/183000 = 0.0067、通常の窓 1122/720000 = 0.0016（48 生を合算した率の比で約 4.28 倍）。生ごとでも 48/48 で同じ向き（判定には使わない）。
- s を残した枝: 双子 1205（98.0%）、主 24。事後の記述（`branch-posthoc.jl`、`out/branch-posthoc.out`、凍結したコードは不変）: E1 の対応差の総和 160.02 のうち、双子が残した組 160.14（平均 0.133）、主が残した組 −0.114（平均 −0.005）〔codex 結果の読み P2〕。
- 記述: Q の上でも L2L-T の D は FGT より大きい（例 C h=1000 の中央値 0.0003 対 0.0002）。出生時からの距離 G_T は L2L-T が 55 前後、FGT が 63 前後。断片の数は生の終わりで中央値 119.5 件（例の 0.21%）。
### 7.2 推論
- E1・E2 の差はほぼすべて双子の断片から来ている。主の結果は大半が予期どおりなので主は s を残さず、反転した双子では s が予期外になり断片に残る。r6 の痕跡（s ≺ t は双子との差）としては正しい読みで、確かめたのは「s が違っていれば、断片として 1000 例後も残った」ことの証人。「主が s を覚えている」ことではない。主が s を残した 24 組では、L2L-T の差は FGT とほぼ同じか少し小さい。
- C = ∞ では R1 の採否がそのまま残るので、保持の割合は予期外の結果の頻度と同じ。E3 は「形成の窓では予期外の結果が約 4 倍多く、それが断片に入る」ことで、「ルーティンの結果は断片に入りにくい」は R1 の作りによる説明（推論）〔codex 読み P3〕。
- G_T が下がる理由として、断片が表の端の切り詰めを緩める見込みを置くが、未確認。対応する条件で L2L-T の切り詰めによる損失が同等以上なら、この説明は退ける〔codex 読み P4〕。
