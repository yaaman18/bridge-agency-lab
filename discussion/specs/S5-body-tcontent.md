- 状態: **r2 閉**（2026-11-07、claude-lab が書いた。ユーザー指示「今回は代わりにあなたがコーディングしてaをやって」。S-R は省き、codex-lab の I-R 1〜9 を反映: 無変更の対照に q・sg の比較を足した、読みの限定は README 項番91）。
- 目的: S4（README 項番90）で、同じ契約の二つの腕は選択も D・N も同じで、追跡集合 T だけが違った（種子 24・28・29 は {r2,r8} ↔ {r1,r7}、
  種子 26 は {r2,r8} ↔ {r1,r2,r7,r8}）。この T の違いが「価値の見分け方の中身」の違いかを、身体の段階の開始の回路（育成の結果）について測る。
- 出典: S4 の仕様 r2・結果 `experiments/results-dn-body-swap-sf.json`、`lab:core/circuit.jl:13–17`（受容器の特徴）、

## 0. 確認した事実（コードから、claude-lab）

- newborn(false) の受容器（perm は恒等）: r1＝y1≥3、r2＝y2≥3、r3＝y1==0、r4＝y2==0、r5＝ノイズ、r6＝clock3、r7＝y1>y2、r8＝y2>y1。運動の閾値は 2。
- 選択の予定表では y1・y2 は 4 か 5 なので、r1・r2 は二つの予定表の両方で真、r7 は c1-better だけ、r8 は c2-better だけで真（読み）。
- T は「黙らせると二つの予定表のちょうど一方で選択が変わる」単位（核を除く）。T にない側の選択は、その受容器の組がなくても同じに出る。

## 1. 測るもの（腕・種子・H ごと。RULE=sf、種子 21〜30、H 294・392・588、S4 と同じ BodyOrg の作り方）

- C0（S4 との連結）: T と選択（凍結の二つの予定表）を再計算し、S4 の結果ファイルの値と一致すること。再計算を二度して一致（再現の対照）。
- C1（手がかりの活動）: 二つの選択の予定表の窓 5:15 で、各受容器が真だった歩数。「見分ける手がかり」＝一方の予定表だけで真の受容器。
- C2（結びつき）: 身体の段階の開始の回路（raised）で、受容器 r1〜r8 から m1・m2 への結びつきの確かさ q と sg。q≥1 を「確かな結びつき」とする。
- C2b（事後に足した記録、予測なし）: 種子24・H392 の短い走りを見たあとで足した。運動へのすべての結びつき（核→運動を含む）の q・sg と、
  raised の状態のうち二つの腕で違う欄。予測の判定には使わない。
- C3（既定の行為）: T をまとめて黙らせたときの二つの予定表での選択。全受容器を黙らせたときの選択も記録する。
- C4（予定表の外の試し）: 一定の収量の試しの予定表（凍結の予定表にはない、ラボの試しだけ。switch は 20、両半分同じ）:
  eq-high (4,4)、eq-low (2,2)、lo-1 (2,1)、lo-2 (1,2)、hi-1 (3,1)、hi-2 (1,3)。各試しで選択（窓 5:15）。choice_params（豊富）で回す。
- C5（判定の語）: 腕の「中身の型」を T で呼ぶ: P2 検出（T＝{r2,r8}）、P1 検出（T＝{r1,r7}）、両検出（T＝{r1,r2,r7,r8}）、その他。
  二つの腕で C2 の確かな結びつきの集合、C3、C4 のどれかが違えば「中身の違い」。C4 で選択が違えば「中身の違いが凍結の予定表の外の行為の差になる」。
- 負の対照: (i) 片腕の写しで r8→m2 と r7→m1 の q と sg を 0 にしたものは、C2 の比較で元と違うと検出されること、(ii) 何もしない写しは C2〜C4 で元と一致すること。
  負の対照は検査器が働くことの確認で、網羅性の証明ではない。

## 3. 予測（凍結、`experiments/predictions-tcontent.md`）

- CP0（新）: C0 は 60/60（10 種子 × 3 H × 2 腕）で一致、再現の対照も一致。負の対照は検出。
- CP1（新）: 見分ける手がかりは r7・r8 だけ（r1・r2 は二つの予定表の両方で真、窓の 11 歩すべて）。
- CP2（新）: P2 検出の腕では r2→m2・r8→m2 が q≥1、P1 検出の腕では r1→m1・r7→m1 が q≥1。
- CP3（新）: T を黙らせると、P2 検出の腕は二つの予定表とも m1、P1 検出の腕は両方とも m2（既定の行為が反対）。
- CP4（新、主）: eq-high (4,4) で P2 検出の腕は m1、P1 検出の腕は m2。よって種子 24・28・29 では二つの腕の選択が eq-high で違う（各 H）。
- CP5（新）: lo-1 (2,1)・lo-2 (1,2) で、P2 検出の腕は両方 m1、P1 検出の腕は両方 m2（各腕は一方の側でだけ良い区画を選ぶ）。
- CP6（新、弱い）: T が二つの腕で同じ種子（21・22・23・25・27・30）では、C4 の選択は二つの腕で同じ。
- 種子 26 の両検出の腕は予測しない（記録だけ）。
- 反証条件: CP2 か CP3 が偽なら、T の違いを「どちらの区画を見分ける検出器か」の違いと読むことを取り下げる。CP4 が偽なら、
  中身の違いは凍結の予定表の外でも行為に出ない（T の観測差どまり）。
