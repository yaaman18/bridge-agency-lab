## 2. 量と判定（凍結）
- 点ごと: 型（q／sg／他／除外）、latV（V の移りの更新、移らずは ∞）、latN（記述）、answer_d_differs・answer_sign_differs、V・N の死。V か N が窓の中で死んだ点は対象から外す。**比較は窓の中の生存に条件づけた記述の比較**で、外した点を含む全点へは一般化しない。外した数を型別・版別に記録（codex 4）。
- 型ごとの統計（版ごとに別）: 対象の点の数 n と、寄与する走りの数・種子の数（同じ走りの点は独立でない、codex 3）、窓の中で移った率 s＝移った点／n、latV の中央値 med＝∞ を最大として昇順に並べた ⌈n/2⌉ 番目の値（下側の中央値。偶数でも一意、codex 5）。
- 比較の判定（版ごと）: **未判定**＝n_q＜5 か n_sg＜5、または両型とも s＝0（両型の無応答は鈍さの支持に数えない、D4:44）、または med_q と med_sg が両方 ∞。それ以外は med_sg と med_q を比べる（同値も含めて三通り）。
- 候補の条件は t の状態と N の窓だけで決まる（介入の後の選別はしない）。答えの d が N と同じ点（answer_d_differs 偽）は「観測した d の列に差なし」として件数を記述し（解釈はしない、codex 2）、主判定からは外さない（S12 と同じく記録だけ。外すと介入後の選別になる）。

## 3. 予測（凍結の案、`experiments/predictions-blunt.md`）
- 規則からの見込み: 失敗の弱め（`core/circuit.jl:201–204`）は q＞0 なら q を、q＝0 なら sg を 1 ずつ減らす。q・sg とも上限 4（P_SMAX）。V では m* の区画の pool が交換で低くなり、申し出が 0 なら答えがなく失敗になる。sg 型が q 型より価値の変化に遅れて応じる仕組みは規則の上に見当たらない。
- **BP1（SF）**: 未判定でなければ med_sg ≤ med_q（鈍さは支持されない）。外れ＝med_sg ＞ med_q（D4 の鈍さの向き）。
- **BP2（SFD）**: 未判定でなければ med_sg ≤ med_q。外れ＝med_sg ＞ med_q。
- **BP3（数）**: n_sg（SFD）＞ n_sg（SF）（S25 で SFD が沈殿だけの型を保ったことから）。
- **BP4（SF、数）**: SF は未判定になる（n_sg＜5）。S12 の SF は 960 点で sg 型 12（1.25%）だったので外れうる。外れ＝n_sg≥5。
- BP1・BP2 は規則からの見込みに基づく反証可能な予測で、機序の証明ではない（弱めの規則だけでは型の間の順序は導けない。q 型には sg の併存もあり、辺の数・履歴も揃っていない、codex 1）。未判定は的中に数えない。
- 読み: BP1・BP2 が的中しても「この規則・窓・契約・生存に条件づけた対象点で、latV の下側の中央値は sg 型が q 型以下」までで、分布全体や因果の効果に広げず（codex 6）、価値への感度一般や P033 の習慣の鈍さの否定とは言わない。外れても鈍さの機序（なぜ遅いか）は言わない。
