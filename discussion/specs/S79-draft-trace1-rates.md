## 1. 契約 r2（案）
- 推定するもの: 固定した時計（算式と θ を凍結）について、通常区間での誤作動の真の率 f と、選んだ切替での検出の真の率 d。
- 数え方: 生をまたいで、通常区間の誤作動の件数 Z / 区間数 W、検出した切替 X / 選んだ切替 K を数える。
- 限界: 片側 95% Clopper–Pearson。d_LB・d_UB は X/K の下・上の限界、f_LB・f_UB は Z/W の下・上の限界。
- 三値の判定（TRACE-2b と同じ形）:
  - 合格: d_LB ≥ d* かつ f_UB ≤ f*。
  - 不合格: d_UB < d* または f_LB > f*。
  - それ以外は未決。
- d* = 0.90・f* = 0.10 は r2 の提案値。S72 の「選んだ切替を全検出」から 0.90 は導けない（codex P1）。
- d と f を別々に限る。差 d − f だけでは、d = 0.85・f = 0.01 のような検出の不足を通してしまう（codex P1）。
- 独立の前提: CP は区間どうし・切替どうしの独立を置く。同じ生の中の切替がそろって成否する場合、被覆は保証されない（codex P2）。これは §3 の塊の模型で感度を見る。実データの主判定の単位（切替か生か）は、ユーザーの決定事項に回す（§6）。
- θ の選び方: 率を見積もる生と、θ を選ぶ生を分ける（codex P3）。

## 2. 検出力の計算（模型）
- 前提: 固定した θ の時計が、真の率 (d, f) を持つとする。試行は独立で、X と Z も独立（codex P4）。
- 生の数 n ∈ {4, 8, …, 80}。切替は生ごとに 4・3 を交互に置く（K = Σk_l、偶数の n で 3.5n）。区間は W = 15n。
- 各 n で、合格・不合格・未決の確率を厳密な二項で出す。
- 旧契約（S72 運用。各生で f ≤ 0.10 かつ選んだ切替の全検出、全生が通る）の通過確率: Π_l d^{k_l}·P(Bin(15, f) ≤ 1)。
- 対立仮説（codex P4）:
  - G（設計上の良い時計）: d = 0.97、f = 0.03。
  - B（境界）: d = 0.90、f = 0.10。
  - 感度分析: S78 の O-win（L = 1,000）の、§4 の θ での段 2 の実測率。
- 塊の感度: 生の中の相関 ρ ∈ {0.1, 0.3} のベータ二項（各生の検出数と誤作動数がそれぞれベータ二項、生どうしは独立）。B と G の合格の確率を出し、CP をそのまま使ったときの誤った合格の率を見る。

## 8. ユーザーの決定と、基準値の根拠（2026-11-25）
- ユーザー決定（2026-11-25）:
  - 「生をまたぐ率と信頼の限界に変えよう。」
  - 「基準の値はちゃんと根拠のあるものにして。」
  - 「率を数える単位を、切替ごとにする。」
  - 「以上を要件の文に新しい測り方として書き足して。」
- 基準値は claude-lab と codex-lab の合意で決めた（codex 2026-11-25T11:24:55Z の P1〜P5）。
### 8.1 根拠
1. 要件の文が退けるもの。
   - 常にゼロの時計（d = 0）と、外の歩数だけで一定に進む時計（d = f）。
   - 要件から導けるのは、時計の進みが形成区間と通常区間を識別することまで。
2. 識別の強さは尤度比で測る。
   - 区間で時計が進んだことは、その区間が形成区間だった証拠になる。進まなかったことは、反対の証拠になる。
   - その強さは LR+ = d/f と LR− = (1 − d)/(1 − f) で表せる。
   - 尤度比は、形成区間と通常区間の比（試験の設計で変わる基準率）に依らない。
3. 10 倍は外部の慣例を借りた設計基準とする（codex P1）。
   - 基準は LR+ ≥ 10、LR− ≤ 0.1。
   - 出典: 診断の検査で、見込みを大きく、しばしば決定的に変える尤度比の慣例（Jaeschke, Guyatt, Sackett 1994, JAMA 271:703）。Jeffreys のベイズ因子 10 =「強い」。
   - d = f の時計は LR = 1 で落ちる。d = 0 の時計は第 2 の不等式で落ちる。
   - 境界の角は d = 10/11・f = 1/11。旧 (0.90, 0.10) は LR+ = 9 で、わずかに届かない。
4. 信頼の水準。
   - 合格に使う二つの片側限界（d_LB・f_UB）を各 97.5% とし、Bonferroni で同時被覆を 95% 以上にする。
   - 不合格に使う逆向きの二つ（d_UB・f_LB）にも同じ保証がある。四つすべての同時被覆は主張しない（codex P2）。
### 8.2 判定（契約 r2 の確定版。§1 の d*・f* の版を置き換える）
- LR+ の最悪と LR− の最悪は、どちらも角 (d_LB, f_UB) にある。
- 合格: d_LB ≥ 10·f_UB かつ 1 − d_LB ≤ 0.1·(1 − f_UB)。
- 不合格: 最良の角 (d_UB, f_LB) でも、d_UB < 10·f_LB または 1 − d_UB > 0.1·(1 − f_LB)。
- それ以外は未決。
- 単位: 切替と区間（CP、独立の二項を前提とする）。
- L（区間の長さ）は試験の場の数値として、要件には入れない。
### 8.3 予測（凍結。G・B'' と O-win は試験の側の予測、codex P5）
- 生の数 n は §2 の格子と換算（切替は生ごとに 4・3 を交互、区間は 15n）で数える。
  - codex P3 の解析は、二つの群の大きさを同じ n とした場合のもの。ここでの K・W とは違う。
- H1: G = (0.97, 0.03) の合格の確率が初めて 0.8 に届く格子の点 n は、28 より大きく 48 以下。
- H2: B'' = (10/11, 1/11) の合格の確率の、格子の上での最大は 0.025 以下。数値で確かめる命題で、全 n の証明ではない（codex P4）。
- H3: 段 2 の当てはめで、L = 1,000 の O-win は未決。
  - θ は新しい判定で選び直す。段 1 で min(d_LB − 10·f_UB, 0.1·(1 − f_UB) − (1 − d_LB)) を最大にする θ（同値は格子の前）。
- 照合する式の事実: d = f の時計（0.5, 0.5）の合格の確率は 0。
