## 1. 定義（codex V1 を反映）
- 事象: Z の歩 τ で行為が m0 だけ、y1≠y2、conf(m*)＜conf(m0)。conf(m*)＝0 の事象と 0＜conf(m*)＜conf(m0) の事象を分けて数える（V1-1）。
- 対象の辺 E*(τ): m* に入る辺で、τ で回路の規則どおり駆動し（`drove`。駆動は q≥1 か sg≥1 か探索〈stale〉か定位〈onset〉で起き、q と独立ではない）、τ の更新の前の q＝0 のもの。核の辺も同じ条件で選び、別に数える（V1-2）。
- 来歴の期間: 試しの始め（育ちの終わりの回路の状態）から τ の更新の前まで（本走 1〜t、続けて Z の t＋1〜τ−1。τ の更新は含めない、V1-3）。育ちは追わず、試しの始めの q を記録するだけ。Z0 は「この期間ずっと 0」で、育ちで正から 0 に落ちた可能性は残る（生涯の H-disuse の棄却には使わない、V1-9）。
- 辺ごとの分類は「いまの 0 を作った最後の正の区間」で決める（V1-4）: 期間の最後に q＞0→0 となった更新 z を「0 にした更新」とし、その更新で実際に q を下げた操作で分類する（V1-5）。操作の順は規則のとおり: 確かめ（上がるだけ）→ W（`core/circuit.jl:232–238`、行為した区画の運動に答えがなく、駆動した受容器の辺で確かめられなかったもの。W はその運動自身の行為の歩にだけ起きる: `for m in onPatch`、V1-6）→ D（`:289`、now%8==0、確かめられず免除でない辺）。q＝0 のときの W は sg を下げるだけで q の低下に数えない。
- 分類: 「試しの間ずっと 0（Z0）」「D で 0 になり、その更新で m* は行為していない」「D で 0 になり、その更新で m* は行為した」「W で 0 になった」「W と D で 0 になった」「正（τ の前に q＞0）」「未判定」。H-disuse の操作的な来歴＝「0 にした更新 z で D が q を下げ、z で m* は行為していない」（z より前の m* の行為は許し、最後の行為から z までの更新の数を記録する。反実仮想の原因までは言わない。z で m* が行為していた、または W による最後の 0 が、この分類の反証、V1-8、I-R 2 #5）。m* の試しの中の最後の行為（0 にした更新より前）と、試しの中の行為の数を記録（V1-7）。
- 自己照合（V1-10）: 各更新で、規則の写しから q の変化を予測し実際と比べる（確かめられた辺は上がるか同じ）。食い違いの更新を経た辺は、その後一致しても分類を「未判定」にする。
- 数え方（V1-11、I-R 2 #3・#4）: 対象の延べ数と、別の数え方「(種子, 予定表, 辺, 0 にした場所) の組の数」を併記。場所は本走の更新（どの分岐からも共通）か、その Z の分岐の更新で、異なる分岐点から見た同じ 0 化を一つにまとめる。組ごとに分類が一つであることを関門で確かめる。種子別・辺別の内訳も出す。
