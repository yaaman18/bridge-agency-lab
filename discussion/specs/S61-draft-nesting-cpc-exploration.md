## 2. 用語（`discussion/glossary.md` 準拠・生活比喩禁止）
- **身体（Body / コア）**: ユーザー決定 U-NC1(a)(c) により、全体としての機能終了の不可逆性（`alive == false` の吸収状態）と共通維持費プール $R_t$・未払い維持費負債 $D_t$ を担う器。「`bridge-protocol` においては身体をコアに含めることも包含する。`bridge-agency-lab` においてはその条件の一要素として個体同一性・系譜において身体をコアに含める。」
- **モジュール集合 $M_t$**: 時刻 $t$ に身体内部で活性な下位予測モジュールの有限集合。各モジュールは単調増加アロケータによる**再利用不可のグローバル担体 ID**（M1 連続性アンカー）・局所状態 $s_{i,t}$・維持痕跡 $u_{i,t}$・予測残差 $e_{i,t}$ を持つ。
- **隣接時点系譜スパン $L_t$**: 互いに素な時点担体 $V_t = \{W_t\} \cup M_t$ と $V_{t+1} = \{W_{t+1}\} \cup M_{t+1}$ を結ぶ整形式タグ付き関係 $L_t \subseteq V_t \times V_{t+1} \times \{\mathrm{persist}, \mathrm{split}, \mathrm{merge}\}$、および $\mathrm{Death}_t = V_t \setminus \mathrm{dom}(L_t)$・$\mathrm{Birth}_{t+1} = V_{t+1} \setminus \mathrm{cod}(L_t)$。
- **許可入力 vs 禁止入力**:
  - 許可入力: M1 状態 $(R_t, D_t, u_{i,t}, s_{i,t})$、外界環境入力列、宣言済み乱数。
  - 禁止入力: 外部豊かさスコア `Φ_rich`、隠れた固定年齢カウンタ／年齢スケジューラ（外部環境日程の添字 $t$ とは分離）、通訳（LLM）の語り、設計者目標ラベル。

## 4. 要件（検証できる文・1 往復目の全指摘を反映）
- **R1（Stage 0 同型性＋Stage 1 分離）**: 実行時に各歩の $(V_t, \le_t)$・`L_t` を記録し、Stage 0 観測が同型な 2 履歴（存続 vs 全置換／移り変わる連合）を Stage 1 の $L_t$ が分離できること。
- **R2（$L_t$ 整形式則と遷移内 M1 担体連続性の自動検査）**: 全歩で以下を機械検査し違反 0 件であること：
  1. **端点排他・種別混在禁止**: 1→1 `persist`、1→$\ge 2$ `split`、$\ge 2$→1 `merge` のいずれか 1 種のみ（同一步同側の混在禁止）。
  2. **一意継続出力と担体 ID 非再利用（`deepcopy`・スロット再利用すり抜け封鎖）**:
     - `split`（出芽を含む）では継続出力（continuant）は**最大 1 個（出芽ではちょうど 1 個）**に限り、その継続出力のみが親の担体 ID を継承する。他の子出力には必ず単調増加アロケータから**新規・未出の担体 ID** を割り当てる（`deepcopy` によるバイト一致で 2 継続出力が生じることを禁止）。
     - `merge` では**吸収（absorption：入力のうちちょうど 1 つが継続出力として ID を継承し他親 ID は終了）**か**融合（fusion：全親入力 ID が終了し新規・未出 ID を発行。親 ID の継承は継続系譜を曖昧にするため禁止）**かを明示フラグで区別し、この規則を Lean の整形式則にも明記する。
     - 親の破壊後に再利用スロットへ痕跡をコピーする操作はスナップショット比較をすり抜けるため、**遷移ステップ内部での担体生存の中断なし（uninterrupted carrier lifetime）**を遷移関数内で直接検証する（一度破壊されたスロットの再割当は必ず `death + birth` とし、`persist` / 出芽継続を禁じる）。
  3. **身体不可逆性**: 身体ノード $W_t$ は生存中 $(W_t, W_{t+1}, \mathrm{persist}) \in L_t$、機能終了後は再接続 0 件。
  4. **Lean 整形式証明の反証条件**: もし Lean の `L_t` 整形式 statement が 1 つの `split` に 2 つの継続出力を許すなら R2 は不適格（ill-posed）として差し戻す。
- **R3（5 対照群＋隠れ年齢負対照の実装）**: 同一の身体層・環境インタフェース上に次の 6 系を実装する：
  1. `CPC-Prolif`（対象系：共通維持費＋内生的分裂/消滅＋分散残差結合、独占仲介なし）
  2. `Runaway-Cancer`（暴走対照：維持費負債を無視して分裂し続け負債発散・致死）
  3. `Fixed-Core`（固定コア対照：固定ハブが全修正を独占仲介）
  4. `Rotating-Mediator-Failover`（回転＋フェイルオーバー仲介対照：1 経路遮断で即別ホストへ切替する単一必須仲介規則）
  5. `Rotating-Mediator-Redundant`（冗長コピー・冗長リンク認可対照：2 ホスト並列実行／2 重リンクで認可を運ぶ単一必須規則）
  6. `Hidden-Age-Control`（E2 負対照：到達可能な年齢閾値で強制分裂を起こす隠れ年齢スケジューラ内蔵変種）
- **R4（検査 E1：暴走 vs 有界な個体内増殖）**: 親→複数活性子孫の分裂をまたぐ資源摂動下で、未払い維持費負債 $D_t$ と全体生存性（viability）をクラッシュ時刻と独立に追跡し、誕生率と維持費赤字の負相関を測ること。
- **R5（検査 E2：M4 / `Σ-purity` 非干渉＋時間シフト不変性）**:
  1. **外部禁止入力非干渉**: 許可された状態・外界入力列・乱数を一致させ、禁止入力（外部スコア・通訳ダミー出力等）を変えたとき、`CPC-Prolif` の**全状態・turnover 系列・$L_t$** が全歩ビット一致すること。
  2. **時間シフト不変性（内部隠れ年齢カウンタ検出）**: 許可された内部状態と今後の外界入力列を同一に保ったまま、開始時刻を $t \mapsto t + \Delta t$ へシフトしても、`CPC-Prolif` の全状態・turnover・$L_t$ が一致すること。
  3. **負対照の非空疎性**: `Hidden-Age-Control` では、年齢閾値を跨いで turnover の差が観測可能になる**到達可能な閾値跨ぎ対**（同じ閾値未満の 2 点比較は不可）を必ず試験に含め、E2 が不一致を検出すること。
- **R6（検査 E3′：身体隔離＋規則レベル一括無効化＋交換試験＋迂回証人＋独立目録監査）**:
  1. **身体隔離**: 共通身体状態 $(R_t, D_t)$ を一致・固定した上で情報処理経路を検査する。
  2. **連合入替・位相切替をまたぐ残差伝播**: 維持費一致下のモジュール $i$ 残差摂動が事前宣言窓 $\Delta$ 内に他モジュール $j$ の次予測へ伝播することを、$L_t$ によるメンバー交代およびローテーション位相切替の前後で反復検証する。
  3. **粒度固定＋規則レベル一括無効化＋交換試験**:
     - 有効修正グラフの**ノード粒度（ホスト粒度 vs 規則粒度）を明示固定**する。冗長対照はホスト粒度で最小頂点カット $\ge 2$ を満たしうるため、最小頂点カット $\ge 2$ は必要条件にとどめ、必ず **規則レベルの一括無効化**（候補認可規則 $R$ を全ホスト・全冗長コピー・全キャッシュ済み認可にわたって一括無効化し下層輸送は保持）および **時間固定切除（フェイルオーバー禁止）＋規則出力 $z_t$ の交換試験（Interchange Test）** を併用する。
     - `Fixed-Core`・`Rotating-Mediator-Failover`・`Rotating-Mediator-Redundant` の **3 負対照すべてを「コアあり」として棄却**すること（U-NC1(b)）。
  4. **正の迂回証人と独立目録監査による `unresolved` 判定**:
     - 各候補規則を迂回する有効修正の正の証人を確認する。
     - 認可生成器・読取器・初期キャッシュの網羅目録は系内部から自己証明できないため、**コード・仕様レベルの独立目録監査表**を必須とする。(a) 目録の網羅が欠落している場合、または (b) 列挙した全候補規則を無効化した後にも説明不能な残余依存（キャッシュ貫通など）が残る場合、E3′ は「コアなし」と認証せず **`unresolved`** を返すこと（および意図的に認可キャッシュを目録から抜いた負試験で確実に `unresolved` を返すこと）。
