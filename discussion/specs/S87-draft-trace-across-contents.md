- codex S-R 2026-11-26（P1〜P8）・neon-lab 注記（N1〜N10）を取り込み（〔P・N 番号〕）。
- 位置: 数の大小を合わせる試験ではない。型の中の一つの定義（反転の痕跡）を、法則の違う 5 つの個体に同じ形で当て、構造の性質（痕跡が残る・消える・遅れて見える）が中身ごとに法則どおりに出るかを見る。**新しい種子は開けない**。法則の数（λ・α・切り詰め・窓の長さ・TRM の設定）は変えない。

## 1. 個体（中身）
- FGT: L-FGT（S72 r4、λ = 1 − 1/2000）。既見 48 生。
- CUM: L-CUM（同じ表、λ = 1、忘れない）。既見 48 生。
- WIN: 窓の表（S72 r4 の WinL、直近 WINLEN = 1000 例だけを数える）。既見 48 生。
- TRM: L-TRM（S72 r4 の設定、ブロック 8 例ごとに輪 512 から 64 例を引いて 1 回学習）。TRM の主の流れを保存してある 4 生（段 2 の生 1〜4）だけ。
- F0: 固定のプログラム（入力を読まず、予測は常に 1/2）。
- どれも S72 r4 の主の流れと同じ切れ目（main_points）で例を受ける。

## 2. 型の中の定義（5 個体で同じ式）
- 観測 O(x): 試験の場が固定した探りの入力の集合 Q への予測。Q = 生ごとの保持の探り（S72 r3 `probe_life`、400 例）を、その生の 5 つの写像のそれぞれで符号化した 2000 入力。学習器によらず同じ Q。距離は Q の上の平均の差 dist(p, q) = mean |p − q|（2000 入力は重複込みで等重み。Q の各要素は入力の型の要素で、像の定義の許容入力〔P4〕）（尺度は全個体で一つ。BP14 (b) の持ち上げが決まったら合わせる）。
  - FGT・CUM・WIN では O は鍵の表を Q の鍵で読んだもの（S84〜S86 の表の L1 を Q の上に移したもの）。
  - TRM では O はパラメタだけで決まる。輪とブロックの途中の例は O に出ないが状態には入る（O は像の下からの近似。§3 E3）。
- 反転の痕跡 D_s(t) = dist(O(x_t), O(x_t^{¬s}))。x^{¬s} は例 s の結果だけを 1 − y_s にした双子（文脈・行為・後続の結果は同じ。TRM の符号化の文脈も変えない）。TRM の双子は s を含むブロックの頭 al(s − 1) の主の状態から走らせ、s − 1 までは主と同じ例を再生する。
- 原点: S84 の origins84（群 F・R・C、h ∈ {50, 200, 1000}、s = t0 + 1）。D_s(s + h) を読む（S86 の添字の規約）。s + h が生に入らない原点は除外して数を出す。
- 記述だけ: 二点の差 N(t0, t0 + h) = dist(O(x_{t0}), O(x_{t0+h}))、出生時からの距離 G(t) = dist(O(x_t), O(x_0))。

## 3. 予測と関門（走らせる前に凍結）
- 構成から決まるもの（関門。外れたら実装の誤り）:
  - G1 再生: FGT・CUM・WIN・TRM の主の流れの予測が、保存してある S72 r4 の P とビット一致（保存のある生）。FGT は S84 の replay84 の関門も引き継ぐ。
  - G2 反転なしの双子は、全読み取り点で主の流れと O がビット一致（全個体）。
  - G3 双子と主の入力の差は例 s の結果 1 個だけ（列の照合）。
  - G4 FGT の O は、S84 の表を Q の鍵で読んだ値とビット一致。
  - G5 F0 では D・N・G がすべて 0。
  - G6 WIN: D_s(s + 1000) = 0、かつ s + 1000 で双子と主の状態（数と窓の中身）がビット一致（像の同値の証明。結果 s が窓を出る）。
  - G7 探り（O の計算）で主の状態が変わらない（状態の要約の照合）。
  - G8 TRM の双子は、反転の直前（s − 1 の後）で、パラメタ・最適化器・輪・輪の頭と数・抽出の乱数の状態が主とビット一致〔P3〕。
- 予測（構成からは決まらない）:
  - E1（忘れない個体の痕跡は消えない）: CUM の D_s(s + h) > 0 が、全原点・全 h で成り立つ（切り詰めが差を隠す原点が 1 つでもあれば外れ）。反転で変わる行為 a の率は同じ行為の全鍵に効くので、反転した鍵そのものが Q になくても差は出うる〔P4〕。
  - E2（遅れて見える痕跡）: TRM で、D_s(s + 50) = 0 かつ D_s(s + 1000) > 0 の原点が 1 つ以上ある（O は像の下からの近似で、0 は忘却の証拠にならないことの実例）。同じ原点の両時点で判定する。s + 1000 まで追える TRM の原点が 0 なら判定不能〔P5〕。
  - E3（TRM の痕跡は 1000 例後も残る）: TRM で D_s(s + 1000) > 0 の原点が 1 つ以上（対象があって全件 0 なら外れ、対象が空なら未決〔P5〕）。
  - E4（忘却の法則は痕跡を早く薄める、同じ入力の列で対にする）: 同じ生・同じ原点で FGT と CUM を対にし、同じ（生, s）を一対として一度だけ数える（群をまたいで同じ s が出ても一度）。分母は、両地平を読めて両個体で D_s(s + 50) > 0 の対（同率は分母に残す、除外数を出す、分母が空なら未決）。比 D_s(s + 1000)/D_s(s + 50) が FGT < CUM の対が分母の半分を超える〔P6〕。
  - E5（つなぎ目の結果が強く残るのは場の構造で、中身によらない）: h = 200 で、群 C の D_s の中央値が群 R の中央値を上回る。CUM と TRM のそれぞれで（FGT は S86 で既見なので予測でなく再掲）。
- 反証の読み: E1 が外れたら、忘れない法則でも Q の上では切り詰めで痕跡が見えなくなる。E2 が外れても、言えるのは「この場の TRM では、50 例で 0 の原点が 1000 例で正になる例がない」まで（引かれずに輪から出れば両時点で 0 もありうる）〔P5〕。E4 が外れたら、この尺度では減衰の法則と累積の法則の痕跡の薄まり方を分けられない。E5 が外れて言えるのは、指定した個体・生・Q で C > R の予測が外れたことまで（表に固有とは識別できない）〔P7〕。CUM でも C > R なら、群の差は個体の選択的な記憶ではなく場の構造から来うる（N3）。
