## 1. 学習器（中身）
- 呼び方の注（2026-11-26 ユーザーの問いを受けて）: ここの「個体」は余代数としての学習器の意味。ラボでは TRM は個体の内側の臓器（BP10・H7）で、この試験は学習器を体から切り離して当てたもの。
- FGT: L-FGT（S72 r4、λ = 1 − 1/2000）。既見 48 生。
- CUM: L-CUM（同じ表、λ = 1、忘れない）。既見 48 生。
- WIN: 窓の表（S72 r4 の WinL、直近 WINLEN = 1000 例だけを数える）。既見 48 生。
- TRM: L-TRM（S72 r4 の設定、ブロック 8 例ごとに輪 512 から 64 例を引いて 1 回学習）。TRM の主の流れを保存してある 4 生（段 2 の生 1〜4）だけ。
- F0: 固定のプログラム（入力を読まず、予測は常に 1/2）。

## 2. 型の中の定義（5 個体で同じ式）
- 観測 O(x): 試験の場が固定した探りの入力の集合 Q への予測。Q = 生ごとの保持の探り（S72 r3 `probe_life`、400 例）を、その生の 5 つの写像のそれぞれで符号化した 2000 入力。学習器によらず同じ Q。距離は Q の上の平均の差 dist(p, q) = mean |p − q|（2000 入力は重複込みで等重み。Q の各要素は入力の型の要素で、像の定義の許容入力〔P4〕）（尺度は全個体で一つ。BP14 (b) の持ち上げが決まったら合わせる）。
  - FGT・CUM・WIN では O は鍵の表を Q の鍵で読んだもの（S84〜S86 の表の L1 を Q の上に移したもの）。
  - TRM では O はパラメタだけで決まる。輪とブロックの途中の例は O に出ないが状態には入る（O は像の下からの近似。§3 E3）。
- 反転の痕跡 D_s(t) = dist(O(x_t), O(x_t^{¬s}))。x^{¬s} は例 s の結果だけを 1 − y_s にした双子（文脈・行為・後続の結果は同じ。TRM の符号化の文脈も変えない）。TRM の双子は s を含むブロックの頭 al(s − 1) の主の状態から走らせ、s − 1 までは主と同じ例を再生する。
- 原点: S84 の origins84（群 F・R・C、h ∈ {50, 200, 1000}、s = t0 + 1）。D_s(s + h) を読む（S86 の添字の規約）。s + h が生に入らない原点は除外して数を出す。
- 記述だけ: 二点の差 N(t0, t0 + h) = dist(O(x_{t0}), O(x_{t0+h}))、出生時からの距離 G(t) = dist(O(x_t), O(x_0))。

  - E2（遅れて見える痕跡）: TRM で、D_s(s + 50) = 0 かつ D_s(s + 1000) > 0 の原点が 1 つ以上ある（O は像の下からの近似で、0 は忘却の証拠にならないことの実例）。同じ原点の両時点で判定する。s + 1000 まで追える TRM の原点が 0 なら判定不能〔P5〕。

### 6.1 確認した事実
- 関門 G1〜G8 全通過。G1: FGT 48 生・CUM と WIN 8 生・TRM 4 生の主の流れが保存 P と全例でビット一致。G6: WIN は全原点で D_s(s+1000)=0、双子と主の数と窓の中身がビット一致。丸ごと落ちた原点 0。
- E1 的中: CUM の D_s(s+h) > 0 は 4066/4066。ただし値は小さい（R・C の中央値は 4 桁で 0.0000）。
- E2 的中: TRM で両時点を読めた 96 原点のうち、D(s+50)=0 が 51、そのうち 50 で D(s+1000)>0。E3 的中: 95/96。残る 1 原点（群 F）は 1000 例後も Q の上で 0（未決。忘却の証明ではない）。
- E4 的中: 分母 1229 対（除外 203）、FGT の比 < CUM の比が 1062。比の中央値 FGT 0.622（λ^950 ≈ 0.62 と同じ桁）、CUM 0.948。
- E5 外れ: h=200 の中央値 C/R は CUM 0.0000/0.0000（C は R を上回らない）、TRM 0.0019/0.0031。FGT（再掲のつもり）も Q の上では 0.0003/0.0003 で外れ。
- 記述: F 対 R（形成対ルーティン）は FGT・CUM で h=50・200 とも F > R、TRM は h=200 で F > R、h=1000 で R > F（0.021 対 0.043）。WIN は h<1000 でも D=0 の原点がある（R h=50 で 35/684）。F0 はすべて 0。
### 6.2 推論
- 型の中の一つの定義が、中身ごとに法則どおりの形を出した: 忘れない CUM は消えない（ただし薄まる）、減衰の FGT は λ^h の速さで薄まる、窓の WIN は窓を出たとき状態ごと消える（証明つき）、TRM は学習に引かれるまで Q の上に出ず、引かれた後は 1000 例後も残る。
- S86 の「つなぎ目の結果が最も強く残る」は、130 鍵の表の L1 という観測に依っていた。Q の上では群の差は消える（探りにほとんど出ない鍵の分が表の L1 を押し上げていた見込み）。尺度（BP14 (b)）の選び方が、群の比較の結論を変える実例。
- TRM の h=1000 で R > F は、元の TRACE-1 の向き（形成 > ルーティン）と逆。尺度の前なので判定ではなく記述（r6 で S2 を保留にした理由と合う）。

### 6.4 事後の記述と codex の相談（2026-11-27、ユーザー「E5 の外れの原因と、それが良いのか悪いのかを codex と相談して」）
