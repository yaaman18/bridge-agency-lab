## 2. 第 2 部: TRACE-1 の読み直し（codex 10:19Z P1〜P6 と合意）
- **要件の文は変えない**（R-AUE-TRACE-1 のまま）。運用（生ごとに f ≤ 0.10・d ≥ 0.90、d_i ≥ 3ε の全切替、L = 500）も主判定として変えない。
- 生をまたいでまとめる判定（4 生を通して f ≤ 0.10）は採らない。例えば各生 10 区間で誤作動が (4, 0, 0, 0) なら、全体は 4/40 = 0.10 で合格するのに、第 1 生は 0.40 になる（codex P6、10:20Z P1 で例の分母を直した）。
- 主の結論（〔推論〕、範囲を限る）: 試した C0〜C6 と、区間の長さ 500・1,000・1,500 では、4 生共通の設定は見つからなかった。この場では、切替の証拠はほぼ Y = 0 の数例に乗っている（B1）。
  - 「自分の量だけの時計は満たせない」とは言わない。未試験の算式や区間の長さを含んでしまう（codex P3）。
  - 希少性が原因だというのは、次の試験の仮説 H-S77r にとどめる。Y = 0 の頻度を上げた場で、算式・区間の長さ・契約を固定しても分離が良くならなければ、希少性だけで説明する案は退ける。
- 副仮説（codex P4・P5）: 「流れが L-REF の差として証拠を出した切替に限れば、自分の量だけの時計で検出できる」。
  - e_i ≤ e* が示すのは「基準に届かない」ことまでで、「形成がなかった」とは言わない。
  - 主判定と並べて、対象の数／全切替の数、対象の中での検出の数を記す。対象が 0 本の生では、副判定はできない。

## 3. 第 3 部: 検証し直し（凍結してから計算する）
- e*（段 1 で数値として固定、codex P5）: 段 1 の 4 生 × 通常区間 15 本（L = 500 の区間）での、L-FGT の L-REF の超過損失（ℓ − ℓ_ref）の区間平均の最大値。確認の生では、この数値をそのまま使い、確認の生で較正し直さない。
- 副判定の対象: 各生で、d_i ≥ 3ε かつ e_i > e* の切替（e_i は [T_i + 1, T_i + 500] の平均）。

- 候補: C0（w = 500）、C4（δ = 0.005、0.01）、C6（w = 500）。格子は S75・S76 のまま。
- e* は算出の規則を凍結し、実数値は確認の前に出力と freeze に記録する。e_i = e* の切替は対象外（codex 10:20Z P2）。
- 選び方: 副判定で 4 生すべてが合格する最小の閾値を、構成ごとにとる。順位は S75 §5（誤作動の最大値 → 遅れ → 候補の番号 → 格子の位置）。遅れは対象の切替で測る。格子の位置は、閾値以外の構成が外、閾値が内（C4 は δ = 0.005 が δ = 0.01 より前、codex P3）。勝者一つ、繰り下げなし。
