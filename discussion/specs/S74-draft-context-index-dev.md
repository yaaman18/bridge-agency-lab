## 1. 学習器 L-IDX（数を捨てない表を、文脈ごとに分ける）
- 状態は三つの部分からなる。
  - 活性の表: L-CUM と同じ式。忘れない。
  - 書庫: 封じた表の並び。学ばないが、予測は出し続ける。
  - 挑戦者: 直近 W = 500 例だけを数える窓の表。
- 表ごとに、直近 W 例の前向きの損失を持つ。どの表も、例を見る前に予測して採点する。L-REF・写像・探りの情報は使わない。
- 判断: 8 例の区画の更新の後に、前回の判断から W 例以上たっていれば判断する（不応期 W）。損失の平均を ℓ_act・ℓ_ch・ℓ_arch(j) とする。
  - 復帰: 書庫のうち最良の表 j で ℓ_act − ℓ_arch(j) > η かつ ℓ_arch(j) ≤ ℓ_ch なら、活性の表を書庫に封じて、表 j を活性に戻す（読み直し）。
  - 分割: そうでなく ℓ_act − ℓ_ch > η なら、活性の表を書庫に封じて、挑戦者の数を写した新しい表を活性にする。
  - どちらでもなければ何もしない。
- 予測は活性の表で出す。区画の順序（予測 → 採点 → 更新）は S72 と同じ。
- 表は鍵の付け替えについて等変なので、S72 r4 の難度の対照の関門（全年齢でビット単位の一致）がそのまま使える。

## 5. codex S-R（14:34Z）で決めた細部
- 分割（P1）: 区画の終わりで更新を済ませた挑戦者の、直近 500 例の数を、新しい活性の表に一度だけ写す。次の更新からは、窓の最古の例を落とすのは挑戦者だけ。
- 復帰（P2）: ℓ_arch ≤ ℓ_ch の条件を残す。等号のときは既存の表を使う。書庫の中で同点なら、作った順が早いほうを選ぶ。
- 不応期（P3）: 起点にするのは分割と復帰だけ（何もしなかった判断は起点にしない）。どの表も直近 W 例の損失がそろってから判断する。
- 表の識別（P4）: 表には作った順の番号をつける。S73 B では、H の π_1 区間の終わり（T_2）の活性の表の番号を記録し、出来事の間にその番号の表に復帰したかを照合する。D > 0 とは別に、同じ表を再び使ったかを確かめる。
