# S10 道を切る診断: 沈殿だけで生き延びる腕（T2）と、同点の腕の差を運ぶ r5 の道（T3）

- 状態: r2（2026-11-07、妥当性の議論 V1 の 8〜12・V3 の 5〜10 を反映）。
- 共通: 切る＝結びつきの q と sg を 0 にする（受容器側も核側も同じ、V1-9）。一回だけ（t0 の後に一度 0、以後は規則どおり再形成しうる）と、
  持続（最初の更新の前に 0 にし、以後は各更新の後に実験スクリプトが 0 に戻す。更新の中で生じる駆動・再形成までは止めない。差し込み口は読むだけのまま）の 2 通り（V1-10、V3-7）。無介入の写しと比べる。
  注意: q＝sg＝0 の辺も、定位反応（onset かつ h＝0）や古さの規則（stale）で駆動しうる（`core/circuit.jl:105–110`）。切ることは受容器の黙らせ（sil）と同じではない。
## A. T2 沈殿だけで生き延びる腕（見た物、事後の診断。予測は弱いが凍結する）
- 物: 種子 35・37 の :swap（DC 不成立、S7）と、比べる :std（同じ種子、r2→m2・r8→m2 が q4）、p2-high、H 392。
- t0＝64・192（本走の更新の後）。切る組: R（r2→m2・r8→m2）、C（c2→m2）、RC（両方）。期限 t0＋392（D2 と同じ絶対時刻の型）。
- 記録: 生存と死の時刻、t0＋1〜t0＋392 の m1・m2 の行為の歩数、一回だけの版の終わりの切った辺の q・sg。
- 問い: 指定した辺の q・sg を消去・抑制したとき、生存と行為にどう影響するか（この腕・この時点に限る。「道の遮断による必要性」とは言わない。0 にすると stale・onset の駆動条件が成り立つこともある、V1-8・V3-6）。
## B. T3 同点の腕の差を運ぶ r5 の道
- 物: S8 で J0 の同点に腕の差がある組（H 392、種子 21〜40）。試しは S8 と同じ同点 5 つ（choice_params、窓 5:15）。
- 切る組: r5 を源とするすべての辺の、Q（q だけ 0）・G（sg だけ 0）・QG（両方 0）。試しの走りの始め（育ちの状態の写し）に一回だけと、各更新の後に持続。
- 記録: 腕の差のある試しの集合、同点で行為があった試しの数、窓の中の行為の総数（V1-12）。試しの走りは AS.choice と同じ定義の自前の関数（無介入で AS.choice と一致することを C0 で確かめる）。
- 比較の集合は無介入（J0）で腕の差がある組と試しに固定し、介入の後に絞らない（V3-9）。C0: 全腕・全同点の試しで、自前の関数の選択と窓の中の行為の数が AS.choice の走りと一致。
- 判定（凍結前に固定、V3-10）: 「活動を保ったまま差が消えた」＝その組で腕の差の試しが空になり、かつ両腕とも、同点で行為があった試しの数が無介入の半分以上。
  差が消えても活動が半分未満に落ちた組は「活動とともに消えた」と分け、r5 が腕の差を運ぶ裏づけには数えない。
- 反証（V1-11、V3-8）: QG の持続でも腕の差が残れば「育ちの後の試しで r5 を源とする辺の q・sg がこの腕の差に必要」は支持されない（育ちの履歴での必要性、onset・stale を含む r5 の道全体の必要性には広げない）。
