## 3. 判定の量と予測（走らせる前に凍結）
- 各生 ℓ で r_a(ℓ) = med(rn_t : t ∈ (a)) / med(rn_t : t ∈ (b))、r_c(ℓ) = med(rn_t : t ∈ (c)) / med(rn_t : t ∈ (b))。
- 該当がない生（codex S-R 2026-11-26 P3）: (b) が空または med(b) = 0 の生は r_a・r_c とも未定義。(a) が空（S が空）の生は r_a が未定義、(c) が空の生は r_c が未定義。未定義の生は分母から除き、理由ごとの件数を書く。有効な生が 0 なら、その K は判定不能。1 以上なら、丸めずに「10 × 適合した生の数 ≥ 9 × 有効な生の数」で 90% を判定する。
- K1（Fable の予測 (a)）: 生の r_a の中央値 ≤ 0.1、かつ r_a ≤ 0.1 の生が分母の 90% 以上。
- K2（Fable の予測 (c)）: 0.5 ≤ r_c ≤ 2 の生が分母の 90% 以上、かつ生の r_c の中央値が [2/3, 3/2] の中。
- 反証の読み（Fable §2・§3、codex P6）: 外れたときは、外れた条件と方向（r_c なら上か下か）を報告する。K1 が外れたら、Fable の案 1 の一手の予測が外れたと記録する。「受容器の鍵の分布がほぼ対称」などの説明は仮説にとどめる。K2 が外れたら、つなぎ目は (b) に近い負の対照にならなかった、とだけ書く。
- 言える範囲（codex P3）: 外れても、鍵を使う時計の全般の反証にはならない。当たっても時計の成立ではない（閾値も K/W の判定もない）。

## 6. 結果（2026-11-26。`experiments/s83_key/out/key.out`、sha は `experiments/freeze-s83.txt`。予測は走らせる前に凍結、codex I-R P1〜P3・P6 取り込み）
### 6.1 確認した事実
- 関門: 48 生で、回し直した P が保存の P とビット一致。記録した rn・rn1・rate から P を組み直してビット一致。Y 反転で rn と鍵は全例同じ、rn1・rate は変わる。(b) の所属を元のつなぎ目から独立に照合。(d) の件数が組ごとに一致。K = 183、W = 720。未定義の生は 0。
- **K1 的中**: r_a の生の中央値 0.0325（四分位 0.028〜0.042）、48/48 生で ≤ 0.1（最大 0.066）。形成の頭の rn の中央値は 11〜33、通常は 400〜550。
- **K2 外れ（下向き）**: r_c の中央値 0.362（四分位 0.30〜0.58）。[0.5, 2] に入ったのは 16/48 生、0.5 未満 32、2 超 0。つなぎ目の頭でも rn は通常より低いが、形成の頭ほどではない（rn の中央値 116〜438）。
- 記述（予測なし）: 200 例の区画の w̄ は、形成の頭（183）で中央値 0.152（最小 0.067）、つなぎ目の頭を含まない通常の区画（3,341）で中央値 0.006（最大 0.097）。AUC は 4 桁で 1.0000、通常の最大以下の形成の頭は 9/183。つなぎ目の頭の w̄ は計算していない。
- (d) Y = 0 の例の rn の中央値: 形成区間で、C4 と O の両方が検出した組 1.81（1,188 例）、O だけ 0.97（303 例）、どちらも検出なし 72.7（2 例）。通常区間 6.5（5,728 例。通常の例全体では約 490）。
- (a′) 選ばなかった切替 9 本の r_a の中央値 0.035（最大 0.084）。
### 6.2 codex の読み（P1〜P6）
- P1: K1 は 48 生すべてで成立。選ばなかった 9 本は中央値だけ書き、すべてが閾値内とは書かない（最大 0.084 は ≤ 0.1）。
- P2: K2 は下側に外れた（16 / 32 / 0）。
- P3: w̄ は形成の頭で高い傾向。9/183 が通常の最大以下なので、AUC の表示 1.0000 を完全な分離とは読まない。つなぎ目の頭は比べの外。
- P4: 通常の Y = 0 は浅い鍵に寄る（6.5 対 全体 490）。形成の組ごとの違いから、原因は特定できない（どちらも検出なしは 2 例）。
- P5: つなぎ目の頭の w̄ を計算する前に、時計が「形成の頭」と「境界一般」のどちらを検出するかを決める。形成を的にするなら、形成と重なるつなぎ目の扱い、境界をまたぐ窓の集め方、閾値、許す見逃しと誤作動を先に凍結する。
- P6: 形成と重ならないつなぎ目を、独立の対照群として採点する。そこで誤作動が凍結値を超えれば、「この時計は形成の頭を境界一般から分ける」という読みを退ける。
### 6.3 推論
- 全反転の切替では、鍵の経験の数は T + 1 の直後に約 1/30 に落ちる。Fable の「鍵の通路ではおそらく自明に届く」の側に近い（未検証。時計も閾値もない）。
- つなぎ目でも鍵の分布は変わる（新しい種子で受容器の出方が変わる）。つなぎ目は (b) に近い負の対照にはならない。鍵の時計は、つなぎ目で誤作動しうる。
- 通常区間の Y = 0 が浅い鍵に寄ることは、Fable 案 2（ℓ·w）の反証条件「通常区間の Y = 0 の塊が浅い鍵に集まる」に部分的に当たる。ただし形成区間の Y = 0 はさらに浅い。
### 6.4 提案（ユーザー判断）
- 鍵の時計を確かめるなら、codex P5 の点（的は形成の頭か境界一般か、つなぎ目の扱い、閾値、許す誤作動）を先に決め、既見 48 生で閾値を選び、未使用の種子で確かめる。
- つなぎ目を誤作動に数えるかは要件の読みの問題（TRACE-1 の「ルーティン区間」に種子のつなぎ目を含めるか）。3 者の合意か、ユーザーの判断が要る。
