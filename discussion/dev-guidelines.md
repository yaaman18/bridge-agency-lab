## 1. 外の人への要約（5 行）

この系では、身体の物質は回路の行為を通してしか入らない。だから「行為が要る」（a）は**設計で成り立つ**ことで、発見ではない。
問うのはその上の二つ: （b）**状態に適合した行為の選び方が効くか**＝同じ駆動のもとで、自分の状態に応じて選んだ行為が、よそから写した行為より長く身体を保つか（時機だけの効果とは言わない）。
（c）**学習が固定の反射に足すか**＝学習する回路が、同じ受容器を読む固定の規則（GREEDY）より長く生きるか。
外れうる予測は（c）: 先例（主に項番81。項番46 は寿命でなく身体の大きさの差）から、受容器の意味が変わらない世界では「学習する回路は GREEDY より長くは生きない」と予測する。ORG が GREEDY より長く生きれば予測は外れ、（c）が支持される。差を検出できなければ予測の成立とはしない。
これを、まず作者が書いた合成の世界の格子の上で地図にし（どこで学習が自分の維持費を払えるか）、方向性が定まったら現実の音響・記号・光景を感覚器官から記録した世界で確かめる（証拠は写しで取る）。
そのうえで、自分の感覚器官で現実から取り入れて生きる、作者が書き込めない一体を切り出す（その一生は試験の対象にしない）。

## 2. 目標と仮説

- **製作目標**（主張ではない）: 自分の感覚器官で現実から取り入れて生きる一体を、作者の書き込み経路を閉じて切り出す（再計算による再構成・継続は構造で塞いだかを確かめておらず、約束として禁じる。BP5・H3 案）。約束（promise-cutout.md）は変えない。変えるのはユーザーだけ。
- **仮説**（科学的主張はこの形でだけ立てる。各仮説は対象集団・駆動条件・対照・判定時点・統計量・境を仕様で凍結する）:
  - **H-E3a（a）活動の寄与**: 回路を黙らせ行為もしない写し NONE は ORG より早く死ぬ。設計で成り立つので**健全性の確認**に限る。
  - **H-E3b（b）応答的選択の利益**: 同じ窓 B の駆動のもとで、ORG_B と YOKE-x_B（別の窓 A の ORG_A の実行された行為の列を受け身で再生）を比べる。
    比べる区間は**供与元の死で打ち切る**（min(T_A, 地平) までにどちらが先に死ぬか）。供与元の死の後に再生側が死ぬのは H-E3a の側に数える。
    帰無の点検の腕を同じ統計にかける: 駆動にも状態にも依らず窓ごとに違う乱数の列で動く RAND（行為率と種類の分布は評価に使わない較正の走りから先に凍結）と、その YOKE-x(RAND)（交換可能性は自動には得られず、打ち切りは両側に同じ規則で課し、実行できない行為を含めた扱いを仕様で決める。r2 の OPEN は窓の数え方しだいで YOKE-same と同じになるか REPLAY 型になるので置き換えた、fable r2 の N2）。
    推定の対象は打ち切った区間の中に限り、全寿命へ一般化しない。両方が生き残る組・同時の死・打ち切りの時刻ちょうどの死の扱いは仕様で固定する。
    支持できるのは「指定した条件・判定時点での、状態に適合した行為選択全体の利益」まで。「時機」の単独の効果とも「必要性」とも言わない。
    差の源として残るもの（供与元で実行できた行為が受け手では実行できず、実効の行為数・取得量・費用が変わる）は閉じていない（codex r2 の指摘 2）。
    **実行できなかった行為の割合・実効の行為数・取得量・費用の差を凍結した報告項目にする**。これらが揃った組だけを比べるのは行為の選択の後の選別になりうるので、機序の補助の点検に限る。そこで差が残っても、代替の説明を除いたことにも時機の単独の効果を示したことにもならない（codex r2 確認 6）。
  - **H-E3c（c）学習の上積み**: ORG 対 GREEDY を**独立の凍結予測**で判定する（報告だけにしない）。予測の向きは格子の点ごとに凍結する（意味の変化が 0 の点では GREEDY 以下、意味の変化がある点では ORG が長い、手順 §5）。
    点ごとに「予測と一致／不一致」と「上積みあり／なし／検出不能」を別の欄にする（codex r3 の 8）。
    結果は三つに分ける: ORG が GREEDY より長く生きる（予測の外れ、上積みを支持）／ORG が GREEDY より早く死ぬ（予測の向きどおり）／差を検出できない（検出不能。予測の成立にしない）。
    GREEDY が地平の内で死ぬ単位が凍結した最小数に満たなければ、寿命の判定は検出不能とし、打ち切りの時点の身体の大きさを副の統計量として先に凍結する（fable r2 の N1）。
    同じ回路で更新だけを止めた ORG-FIX を足す: ORG 対 ORG-FIX は「更新を許す総効果」（規模・維持費の変化を含む）、ORG-FIX 対 GREEDY は「固定した回路と固定の規則の差」（大きさと選び方の両方を含む）。
    学習の純利益と大きさの費用を分けたとは言わない（fable r2 の N3、codex r3 の 6・7、ORG-FIX が作れるかは未確認）。
    進行を塞ぐかは手順 J1-11 の事前の決定に従う（仮置きは塞がない）。
- 先例（同じ型の比較はすでにある。蒸し返しでなく、ここから始める）: 項番45 は台本の世界で ORG・REPLAY・NONE を比べ、7/7 的中（REPLAY 約476歩・NONE 196歩で死、README.md:542-552）。
  項番46 は乱れのない世界で GREEDY のほうが身体が大きく、学習が勝ったのは受容器の意味を入れ替えたときだけ（README.md:553-560）。
  項番81 は無作為の世界で ORG 1/10・GREEDY 10/10（README.md:1175-1202、維持費が原因というのは推論）。S28/S28b と D3b は軛の作法（除外は入力の列だけで決める、提供元の死の扱いは先に固定）。

## 3. 厳密さの置き場所

- 証明は定義した命題を、凍結は事後の変更の禁止を保証する。どちらも現実への妥当性は保証しない。外れうる主張は凍結した予測で立てる。
- **新しい Lean は切り出しの臨界経路に要る三つの statement に限る**（手順 P1）。既存の 107 件はそのまま。
- **煙の走りも凍結する**: 走らせる前に煙用の予測と反証条件を書き、`experiments/freeze-*.txt` に SHA-256（decisions-log #31）。結果を見ないことは凍結の代わりにならない。
- 仕様の「対象集団」の必須欄（decisions-log #34 に足す）: 反復の単位、単位どうしの依存の扱い（重ならない窓と間隔。ただし独立の保証とはしない）、一般化の範囲（その宿主・信号・期間）、
  **判定の統計量、成立・不成立・検出不能の境、最小の単位数**。記録の長さは P-pre で測った分散から決める（手順 §5）。
- 位相の罠: 日周の信号では、窓の開始位相で再生が介入にならないことがある（項番45 の探索、S28 で列が同一）。**有効な組の基準を駆動の列どうしの距離で先に凍結し、除外は入力の列だけで決める**（S28b の作法）。
