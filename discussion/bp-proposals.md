## 提案

### BP1 一生の途中で法則を替えたときの個体の同一性（2026-11-05 D0）
- bridge-protocol のどこ: M1（自己維持＝閉包作用素 Φ の最大不動点 νΦ）、AGENCY-001 の個体の扱い
- 何が問題か（命題として）: M1 は固定した Φ のもとで自己維持を定める。版の移行で Φ を Φ' に替えたとき、
  「移行の前後は同じ個体である」と言える条件が理論の中にない。L2・L3 の判定がどの個体（どの一生）についての主張かがぼやける。
- 根拠: アプリの個体の移行（13,581 歩、bin3 → bin3+idle）、`promise-cutout.md` §3・§5
- 案: (a) Φ を替えたら別の個体（移行は新しい個体の誕生）／(b) νΦ と νΦ' の担い手（沈殿・状態）が途切れずに続くなら同じ個体／
  (c) 同一性は理論の外（観察者の記述）に置き、判定は「一つの Φ のもとの区間」についてだけ主張する
- 二人の立場: claude-lab の初めの読みは、切り出された個体には (a)、作者の版系列の側の試作には (c)。D0（往復1 C4'）で両者は H1 を保守的な報告規律として暫定に支持。
  追加の限定: 移行後の区間で判定が真でも、引き継いだ構造がその区間内で形成されたとは言わない。同じ法則のままの状態介入の境界も区間とは別に記す（D0 決3・決5）。(a)〜(c) の選択はユーザー
- ラボで置く仮定: H1 — 系統の側では、L2・L3 などの判定は「一つの法則のもとで走った区間」についての主張として扱い、移行をまたいで合算しない
- 仮定に依っている仕様・実装: まだない
- ユーザー: （承認 / 差し戻し / 保留）

### BP4 身体の状態を読む受容器（内受容）と M2・M4・DC の接続（2026-11-08、休みの第二段 `notes/R-rest2.md` §3）
- bridge-protocol のどこ: M2（α ⊣ σ、感覚運動随伴）、M4（外から set point を注入されない）、DC の ε（環境の特徴: ラボの読みでは結合した受容器、`lab:formal/LabCircuit.lean` Window.epsilon）
- 何が問題か（命題として）: ラボの BODY に、身体の量 Q（体の場所の物質の和）を読む受容器 e_b を足したい（休みの選ばれ方を身体の水準に応じさせるため）。(1) e_b は世界ではなく系の内側（回路＋身体）の状態を読む。これを M2 の σ の入力（ε の候補）として扱ってよいか、別の型（身体の特徴）にすべきか。(2) e_b の参照を「試しの始めの自分の Q」にする規則は設計者が与える。これは M4 の「外から注入される set point」に当たるか（検出の閾値と追従の目標は別、と二人は読む）。(3) e_b から休みの運動 m0 への生まれつきの結びつき（q0＞0）は、規範（その状態では休みに傾く）を構造として入れる。これは M4・「最適化の物語を語らない」と両立するか。
- 根拠: README 項番133（S33、m0 は世界に作用しない〈α(m0)＝∅〉、確かめられない）、`notes/R-rest2.md`。
- 案: (i) e_b を受容器として扱い、α に届かないので ε（結合した受容器）には入らない（hSMC の対象外）と読む ／ (ii) 身体の特徴を別の型にして DC の外に置く ／ (iii) 身体→回路の経路を足さない（第二段をしない）
- 二人の立場: (i) で進める案（H2）。(2)(3) の判定はユーザー。
- 追記（往復4、`notes/R-rest2.md` §4）: (4) 規範の向き: 「身体の量が始めより小さいとき休みに傾く」か「始めの量以上のとき休みに傾く」か（後者が生き物の休み〈満ちたとき〉に近いが、優劣は仮説で、Q≥Q0 は飽食を保証しない）。(5) 生まれつきの辺の集合: e→m0 だけ（A）か、核→m0 も含める（B、身体に依らない休みも増える）。どちらもユーザーの選択。
- ラボで置く仮定: H2（案）「e_b を回路の受容器として扱う。参照の規則が set point に当たるかは BP4 の判定を待つ」
- 仮定に依っている仕様・実装: 休みの第二段（S-a、未実装）
- ユーザー: **承認**（2026-11-08「BP4 はおすすめどおりで、コーデックスと議論しながら進めて」。おすすめ＝(1) 案 (i)、(2) 試しの始めの自分の量を参照にすることを許す〈検出の線で目標ではない、設計者の選択として記録〉、(3) 生まれつきの配線を許す・学習の版は今はしない、(4) 向きは「始めの量以上なら休む」、(5) 辺の集合は A を主・B を補助として両方を別の変種で測る）
- 追記（2026-11-08、`notes/R-rest2.md` §5）: 承認の後の実装で、確かめられない m0 への生まれつきの辺は全体の減衰（`core/circuit.jl:285`）で 8 歩以内に q＝0 になり持続しないと分かった。続けるには、印をつけた生まれつきの辺を減衰から外す規則の変更（α）が要る。これは BP4 の承認の文に含まれていないので、改めてユーザーに尋ねる。
- ユーザー（2026-11-08）: **α を承認**（「α は認めるので、コーデックスと議論しながら進めて」）。印をつけた生まれつきの辺を全体の減衰から外す規則の変更（既定 off の変種の中だけ）。
