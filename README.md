# bridge-agency-lab

Bridge Protocol（`~/bridge-protocol`）の AGENCY-001 試作基体（`tools/AgencySubstrate`）を使って、
「自己を維持し、外界の環境に応答し続ける」回路を設計できるかを検証する実験場。
出発点は `~/bridge-protocol/docs/20261029日のメモ.md`（LLM に Bridge Protocol を操作させて主体を作らせる案）。

- bridge-protocol の凍結済みファイル（判定、正解の型、登録物）は一切変更しない。判定を変える案はここで
  「試算版」として別ファイルに書き、上書きで読み込んで比べる。
- 設計した回路は、判定を走らせる前に予測ラベルを書き、SHA-256 を `freeze-*.txt` に記録する。

## 実行

```bash
cd ~/bridge-agency-lab/experiments
julia --project=.. eval_adapt2.jl     # 例。各スクリプトは数秒〜1分半
```

規則の正本は Julia の `core/`（2026-10-31 から。`core/README.md`）。アプリ（v3.6）は Rust の `rust/`（WebAssembly、`sh rust/build.sh`）。
JavaScript の `memory/`・`matter/` は v3.5 までの来歴の写し。どの写しも正本とビット単位で一致させる（`sh core/check/run.sh`）。

```julia
include("../core/LabCore.jl"); using .LabCore
```

`Project.toml` は AgencySubstrate を `../bridge-protocol/tools/AgencySubstrate` から develop で参照する。
スクリプトの一部は bridge-protocol の fixtures と `logs/gates/AGENCY-001/sweep-and-search-generator.jl`
（無作為回路の生成器）を絶対パスで読む。

### 確認した事実

1. 主体性・構造の自己産出・自己修復をすべて満たす回路（`selfloop-pair-agent`）を設計できた。予測 12/12 一致。
   ただし設計者は判定のコードを読んでいるので、自律の証拠ではない。
2. 凍結済みの環境（60歩、入れ替わり1回まで）にない環境（200歩、入れ替わりの繰り返し）では、主体の回路は
   無作為な入れ替わりで死ぬ。使われない運動結線が「使わなければ消える」規則で強さ0になり、二度と育たない。
3. 通訳は読み取り専用なら非干渉。結果を知らない2体の LLM は主体を正しく選んだが、40歩の軌跡から
   応答性を過大評価した。
4. リハーサル（使っていない運動を時々動かす）は、今の判定では主体性を偽にする（窓に映る／感覚器なしで生き延びる）。
5. 試算版（選択を「窓で最も多く動いた運動」で測る）では、凍結した正解の型 63/63 が一致したまま、
   リハーサルする回路が主体性を満たす。無作為回路の主体性は 74 → 126。
6. 適応的リハーサル v2（満腹のときだけリハーサル。交互発振器を核と時計に兼用）は、試算版で主体性を満たし、
   7歩・13歩の入れ替わりと一定の環境で生き延び、リハーサルの割合は速い環境で低い（0.22）、一定の環境で高い（0.47）。
   無作為な環境 5 つのうち 4 つと、速い→遅いの環境では死んだ。原因: リハーサルが片方の時計相でしか起きないため、
   もう一方の相の結線が長い休止中に減衰し、採餌が半分になり、満腹に届かず、リハーサル経路も消える連鎖。
7. 訂正: 「200歩後に残った結線だけで判定し直す」方法は、強さ0の結線を削除してしまい、実際には育ち直せる結線を
   失わせていた。行動で測り直す（老化した状態から選択試験を続ける）と、凍結判定で頑健だった無作為回路 k=3123 は
   7環境すべてで価値に応じた選択を保っていた。以前の「主体であることをやめて生き延びた」は撤回する。

8. 段7（ユーザー決定 2026-10-29: L3 の不安定さを「確かさの散逸」と読む／能動的推論から選好なしの認識的な部分だけを
   自分の感覚運動の予測に限って借りる）。結線の強さを予測の確かさと読み直し、結線は削除しない。追加した規則は一つだけ:
   入ってくる予測がすべて確かさ0になったユニットは、それらを使って試す（認識的サンプリング）。予測8件のうち7件が一致。
   - 自己結線つきの主体と凍結済みの `agent` は、保留中の9環境すべてで生き延び、200歩後も選び分けを保つ。
     リハーサルは不要で、一定の環境での無駄な運動は0。規則を外すと以前どおり無作為な環境で死ぬ（除去試験で効果を確認）。
   - 区画が戻った直後に、確かさ0の予測を通って運動が発火して回復することを軌跡で確認（`dbg_precision.jl`）。
   - 凍結した選択の測り方（集合）でも主体性は真。対照の型（反射、サーモスタット、発振器、閉路なし）は偽のまま。
   - 無作為回路: 頑健かつ200歩後も選び分けを保つ主体が 1 → 13。
   - 外れた予測（V1）: 正解の型 62/63。`partially-repairing` の自己修復が偽→真に変わった。c3 を止めて失われた c4 への
     予測が、c3 の再開時に試されて戻るため。新しい読みでは修復が本物になったとも読めるが、ラベルの読み替えはユーザー判断。

9. 段8（ユーザー決定 2026-10-29: `partially-repairing` の L3R を確かさの読みで真に読み替え。本ラボの
   `labels-precision.toml` で上書きし、bridge-protocol のラベルは変えない。63/63 一致）。
   枯渇する世界: 区画ごとに在庫（上限50）があり、収穫で減り、毎歩再生する。季節は 1-300 歩 (再生 3,2)、
   301-600 歩 区画1の干ばつ (0,5)、601-1000 歩 区画2の干ばつ (5,0)。感じるものが自分の行為に依存する初めての世界。
   - 第1版の失敗: 在庫が両方満杯だと収量が同点になり、「厳密に豊か」でしか点かない感覚器はどちらも点かず、
     感覚を持つ主体はすべて 6 歩で飢えた。感覚器を「劣っていない」で点く形に改めた第2版を登録し直した。
   - 第2版: 自己結線つきの主体は 1000 歩生存し、季節1で自分の枯渇によって区画を 92 回切り替え（環境側の入れ替えなし）、
     備蓄は上限付近を保った。干ばつ明けの 603 歩目に、確かさ0の予測を通って区画1の運動が再開した。
     規則を外すと 613 歩目に死んだ。反射は干ばつで死に、サーモスタットは予測より早く 116 歩で死んだ（外れ）。
     発振器と構造を外から与えた型も生存したので、この世界の生存は主体性も自己産出も判別しない。
   - 行為から感覚への感受性: 登録した測り方（運動を全期間止める）は飢え死にで交絡した。事後の短い介入（10 歩）では、
     区画2の運動を止めると区画2の感覚器の発火率が +0.43 上がった（自分の収穫が自分の見えを変えている）。

10. 段9（ユーザー依頼 2026-10-29「スペランカーのように死なないように」）。摂動の電池（各部位の発信停止 1/3/10/30 歩、
   飢饉 1/3/10/30 歩、在庫の盗難を 11 の時刻で）で弱さを測った。元の状態では飢饉 10 歩で 11/11、運動の停止 10 歩で
   6/11 が死んだ。原因は (a) 備蓄の上限 30 が消費 4〜6/歩の 6〜7 歩分しかないこと、(b) 飢饉で収量が (0,0) の同点になると
   「劣っていない」感覚器が両方点き、両方の運動まで動かして最も速く燃えていたこと。
   - 感覚器を「何か採れて、かつ劣っていない」で点く形に改め（`variant_hardy.jl`）、備蓄の上限を 30/60/100/200 で比べた。
     予測5件すべて一致。上限 100 で残る死は運動の 30 歩停止の 3/11 だけ、200 で電池の死は 0。正解の型は全設定で 63/63。
   - それでも不安定さは残る: 耐えられる最長の飢饉は 上限30 で 11〜13 歩、100 で 42〜47 歩、200 で 65〜97 歩。
   - 世界での振る舞い（92 回の自発的な切り替え、603 歩目の古い予測による再開、規則を外すと 613 歩で死亡）は変わらない。
   - 残る弱点: 止められた運動を動かし続けて燃える（無益な行為を検出できない）。空腹で別の区画を試す仕組みを主体に
     足すと、感覚なしでも生き延びて主体性の ValueNeeded が偽になる（段3で確認済みの衝突）。

11. 段10（ユーザー決定 2026-10-29: 物性のない系に備蓄はそぐわない。新しさの消費＝学べる驚きで支える。語は慎重に、
   「好奇心」ではなく予測誤差の消化として記述する）。備蓄と活動の費用を削除。区画の在庫を「未消化の予測誤差」と読み、
   そこで行為すると消化され（減り）、世界の変化で戻る。予測の確かさが上がるのは、消化が起きた歩だけ（三要素則）。
   死は置かず、「形」（窓内で活動した非感覚ユニットと確かさ1以上の予測の間に有向閉路がある）を保てない状態を崩壊とする
   （選択1aはエージェントの推奨で、ユーザー未確認）。基体は自由エネルギーを計算しない。感覚器の報告を期待自由エネルギーの
   認識的項に、消化を変分自由エネルギーの低下に対応させるのは名前付きの意味同定仮定である。予測8件中6件一致。
   - 自己結線つきの主体: 主体性・自己産出ともに真。世界の 1000 歩すべてで形を保ち、603 歩目に古い予測で区画1を再開。
     消化をやめた世界（行為しても誤差が減らない）では区画の切り替えが 92 → 0 回。消化が切り替えを駆動している。
   - 形の保持は今回は判別力を持つ: 主体 1000、反射 726、発振器 387（最後は形なし）、閉路なし 0。
   - 外れ: 構造を外から与えた型は主体性も偽になった（予測は真）。確かさが散逸しないので感覚なしでも形を保ち、
     価値の追跡が必要でなくなるため。新しい読みでは筋が通る結果。
   - 外れ: 世界が 30 歩何も与えないと、毎回いったん形を失う（予測は保つ）。ただし 30・60 歩のどちらでも 1000 歩目までに
     11/11 で形を取り戻した。古い予測を試す規則を外すと 11/11 で戻らず、消化の許可を外すと形は一度も失われない。
   - 感覚器を全期間止めると 32 歩目に形を失い、戻らない。

14. 段13（事後の点検）。主体性の判定には「価値の高い結合の側を選ぶ」という向きの条件がない。
   - 無作為回路で主体と判定されたもののうち、豊かな区画の運動を選ばない回路: 採用版の読み 74 中 15、消化の読み 182 中 78。
     組で探す方法とは無関係に、採用版の判定にもある問題。
   - 試しに向きの条件（各文脈で、自分の選択がもう一方の文脈での選択より、その文脈で多く採れる）を事後に当てると、
     通るのは 採用版 74 中 6、消化の読み 182 中 15。ラベル付きの型の主体はすべて通る。
   - より深い問題: 消化の読みでは行為に費用がないので、両方の区画で行為することが常に損にならない。結合の間で
     選ぶ理由が基体にない。選択を意味あるものにするには、結合どうしを競わせる情報的な制約が要る（推論）。

15. 段14（ユーザー決定 2026-10-29: 主体性に向きの条件を足す／1歩で消化できる予測誤差に上限を置く）。容量は 5

   予測4件のうち2件一致、2件外れ。
   - 正解の型 36/36。無作為回路の主体は 182 → 15 に絞られ、15 個すべてが豊かな区画を選ぶ。向きの条件は効いている。

## 用語と状態の場（2026-10-31 起草。軸と測り方は案、ユーザー判断待ち）

### 統合度 Φ（定義のみ。計算しない：ユーザー決定 2026-10-31）
- 統合度 Φ: IIT 4.0（Albantakis ら 2023）の系の統合情報 φ_s を、感覚以外の核（c・m の各ユニット、確かさ1以上または沈殿のある結線を
  仕組みとし、受容器は背景条件として固定）について、その時点の状態で定めた量。Φ>0「統合あり」、Φ=0「分解可能」、要素がないとき「不定」。
- 計算量が膨大なので、このラボでは計算しない。存続の判定には使わない。
- Φ と意識の関係は主張しない（名前付きの仮定としても採らない）。phenomenal_claim は not_certified のまま。

### 状態の場（案）
状態を表の分類として並べず、軸を持つ空間の中の位置として表し、個体はその中の軌跡、死は戻れない領域（吸収集合）として扱う。
理論上の対応: 存続可能性理論（Aubin の viability kernel、capture basin）、Di Paolo の適応性（存続の境界に対する自己調整）、
姫岡の「生きた状態への制御可能性」。
- 軸 M（物質）: 部品（ユニット・結線・材料）がどれだけ残っているか。0 で物質の死。いまの基体では常に 1（物質を持たない）。
- 軸 F（現前の形）: 窓の中で活動した感覚以外のユニットが、確かな予測で作る閉路の強さ（0〜1）。0 で形の喪失。いまの form() の連続版。
- 軸 R（戻りやすさ）: 最も好ましい世界（凍結する）を与えたとき形が戻るまでの歩数 T から、1 − T/N（N は凍結する上限）。
  形があれば 1、N 歩で戻らなければ 0（組織の死）。救出試験で測る。沈殿まで含めた閉路の強さ（潜在する形）は R の安い近似として並記する。
- Φ は測らない第4の座標として定義だけ置く。
- 領域: 生存 F>0。休眠 F=0 かつ R>0。組織の死 F=0 かつ R=0（吸収集合）。物質の死 M=0（このとき F=0、R=0、Φ は不定）。
- 場: 各位置で、実際の世界のもとでの平均の移動（軌跡から経験的に求める）。存続の境界（F=0）へ向かう流れの強さが不安定さ（L3）の読み。
