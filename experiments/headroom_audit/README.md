### P2: G3 の BAYES の後続変化を 3 区分に分けた（確認した事実）

改訂前は、元の履歴で有限な後続例だけで定義域を選んでいた。そのため、反転後に NaN になった例も「変化」に数えられ、有限な予測が一度も変わらなくても合格しえた。
改訂後は、反転した例 i ごとに後続例 j > i を次のように数える。

- (a) 比較可能: 両履歴とも有限な後続例がある件数 `by_both_tot`。そのうち有限の p が変わった件数 `by_both_chg`。
- (b) 定義域からの離脱: 元では有限、反転後に NaN（全仮説の尤度 0）になる後続例がある件数 `by_exit`。
  これを「離脱の前に有限の p が変わった」（`by_exit_after_finite_change`）と「離脱だけ」（`by_exit_only`）に分けた。
- (c) 未検証: 比較可能な後続例が 0 件の件数 `unverified`。有限変化の合格には混ぜない。
- 参考: 元が NaN で反転後が有限になる件数 `nan_to_finite`（全組で 0）。

合格条件は、すべての組で `by_both_chg == by_both_tot`、かつ exo の 4 種子 × 2 族のすべてで `by_both_tot > 0`。
exo で `by_both_tot == 0` が一つでも出たら、そこで止めて報告する形にした（今回は出ていない）。

| 組 | 反転 | (a) 比較可能 / 有限の p が変化 | (b) 離脱（離脱前に有限変化 / 離脱だけ） | (c) 未検証 |
|---|---|---|---|---|
| exo stat | 100 | 40 / 40 | 96（36 / 60） | 60 |
| exo rev | 100 | 55 / 55 | 96（51 / 45） | 45 |
| obs stat | 100 | 20 / 20 | 31（18 / 13） | 80 |
| obs rev | 100 | 19 / 19 | 31（17 / 14） | 81 |

exo の種子ごと（比較可能 / 変化 / 離脱 / 離脱だけ / 未検証）: stat は u1006 8/8/25/17/17、u1007 8/8/24/17/17、u1008 11/11/23/14/14、u1009 13/13/24/12/12。

読み（推論）: exo では反転した履歴の 96/100 が、どこかで全仮説の尤度 0 になる。exo の Y は表 g > 0 で決まり、同じブロック内の既に観測した値と、反転した値とがどの θ でも両立しなくなるためと見られる。
「離脱だけ」の件は、反転の直後から次の後続例までにもう矛盾になっていて、有限の値を比べる例が残らない。そのため未検証は「離脱だけ」と同じ数になる（exo では、離脱しない反転 4 件はどれも比較可能だった）。
G3 の BAYES の後続について確かめたのは、比較可能な 134/400 件で「有限の予測が変わる」こと。それ以外は「全仮説の尤度 0 への遷移」として別枠に記録した。

### P3: B1 の診断 99/100 の 1 件（確認した事実）

obs rev の種子 1009 で反転した例 s = 3603（行為の次の例は s = 3885、その間に例でない同じ行為の更新が 275 回）を、実際の予測列と痕跡で調べた。

- 反転した歩の更新直後の B1 の状態は変わる（G3 の 400/400 に含まれる）。
- 痕跡の差は、反転のあと同じ行為の更新 **248 回目（s = 3856）** で消え、もとと同じ浮動小数 0.9999999999999996 になった。直前の差は −1.1e−16（1 ulp）。
  これは次の例 s = 3885 より前で、以後は入力が同じなので差は戻らない。
- そのため、この反転の後続の評価例 2259 件の**どこでも B1_raw は変わらない**（`any_later_example_B1_raw_differs = false`）。
- 全体の数: 後続のどれかの例で B1_raw が変わった反転は exo 100/100・100/100、obs stat 100/100、obs rev 99/100。欠けた 1 件はこの例だけ。

つまり 99/100 は「状態は取り込んだが、例でない更新で飽和して、予測列には一度も差が出なかった 1 件」を意味する。
r3 の G3 の文言「次歩以降が変化」は、関門としては更新直後の状態の差（400/400）で読んでいる。予測列で読むならこの 1 件は満たさない。これは記録として残し、関門の判定は変えていない。

## 仕様の欠け: obs トラックの BAYES_raw は定義できない（確認した事実）

- 仕様 §2 は「`clamp(round(x), 0, 5) > 0 ⇔ x > 0.5`」から、Y = 1 ⇔ z > c とする。これは exo（Y = g > 0）では厳密に成り立つ。
- 一方、obs の Y は `y = min(5, floor(pool/U + 1e−9))`（`core/body_org.jl:107`）で、**体の池の残量**から来る。池は前の歩までの流入で満ち、収穫で減り、50U で頭打ちになる。
  T0 以降の更新歩で Y ≠ (g[s, a] > 0) だったのは、stat で 1177/353739、rev で 1293/356619。
- 例: 種子 1025 の obs stat。ブロック 1 の s = 303 と 305 で、表の上では g = 0 なのに、池の残りのため Y = 1 が観測された。
  そのため閾値の区間が全仮説（θ 1000 通り）で空になり、s = 307 で尤度がすべて 0 になる。
- eval では、**obs の BAYES は stat 24/24・rev 24/24 の種子で途中から未定義**になった（最初の歩 s は 307〜6103）。exo は 0/48。
- これは予測の外れではなく、r3 の obs トラックの前提の欠けである。obs の BAYES_raw・BAYES_clip、Δ、STAT_PSEUDO は「未定義」と記録した（`results.tsv` の `undefined`、`summary.json` の `null`）。
  RATE・B1・TAB4 の obs の数は定義されているので出している。

## 解釈

- 確認した事実:
  - exo（行為が世界から独立）では、世界の生成の形（周期・位相・ブロックの雑音）を知る逐次ベイズが、単一の痕跡 B1 より 1 例あたり約 0.048 nat 小さい損失で、24 種子すべてで勝った。
  - TAB4（W = 4 の経験表）も B1 より小さい（exo 0.0509 対 0.0630、obs 0.0349 対 0.0451）。
  - exo の BAYES の予測の約 85% は [1/200, 199/200] の外にある。クリップした BAYES_clip でも 0.019 で、B1 の 0.063 よりずっと小さい。
- 推論: exo の余地の大半は「逆転の検出」ではなく、定常の周期構造（θ の同定とブロックの雑音の推定）から来ている。
  根拠は、Δ_all ≈ Δ_shuf − 0.009 で、真の窓の特異利得 win_spec が CI の上で 0 と区別できないこと。
  この exo の余地が、(a, Y) だけを入力とする seq_len = 47 の TRM で取れるかどうかは、この監査の外。BAYES は世界の生成式を知っている上限である。
- 言えないこと:
  - obs（正本の L2 UNI の身体の軌道）での余地。仕様の BAYES がそこでは定義できないため。
  - 閉ループ・受容器入力・S52 の電波換算・`phenomenal_claim`。

## 提案（未実施、3 系統とユーザーの判断）

1. **S63 r4 で obs トラックの基準を決め直す**。案は二つ。
   - (i) obs の BAYES に池の動き（流入 g・収穫・50U の頭打ち・1 歩の遅れ）を入れた状態空間フィルタにする。
   - (ii) obs では Y の代わりに、表の g[s, a] > 0（体が読む前の世界の値）を採点の的にする。
   (ii) は予測の対象を変えるので、C0 の問いに合うかどうかの判断が要る。
   反証条件: (i) を入れても obs で全仮説の尤度 0 が残れば、池のモデルが足りない。
2. 全体の PROCEED を C0 への進行として採るかどうかは、obs が未定義のままの判定であることを踏まえて決める。保守的な読みは「exo では余地あり、obs は未判定」。
3. P-S63-4 の外れ（定常の余地が大きい）から、C0 の TRM の比較の相手として TAB4 を足す案。TAB4 は B1 より強い、学習のいらない基準になる。
