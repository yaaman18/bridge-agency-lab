## 予測（P-S62-1〜P-S62-5）

- **P-S62-1（GB1：B-Test 1 有限表 6 ケース）**:
  - 6 つの厳密有限同時分布表すべてで、`exclude_support_bijection` と `exact_copy_filter`（$H(\mu|b)=0 \lor H(\eta|b)=0$）の出力が BP7 および `D-BOUNDARY-OA-SYNTHESIS.md` §2 の理論予測と 6/6 一致する。

- **P-S62-2（GB2：B-Test 2 実 AUE `LawL2` 双方向 D-BaSS＋群最小性＋2 歩履歴）**:
  - 全 20 評価種子（`938..957`）で起点 $s_{40}$ が生存・非空身体かつ正本 `24×24` で `|far1| > 0`（20/20）。
  - `b_naive`（`ring1` のみ）では `mid1` 摂動による内部 $\mu_{41}$ 漏れが **20/20** 検出される。
  - `b_shell`（厳密 1 歩閉包 `halo1`＋ポート）では、`far1` 摂動による内部 $\mu_{41}$ 漏れが **0/20**、外向き `far1` 漏れが **0/20**。
  - 2 歩履歴（`39→41`）：`W=40, H=40` 格子で `|far2| > 0`（20/20）かつ `far2` 摂動による $\mu_{41}$ 漏れが **0/20**（正本 `24×24` の `|far2|` 飽和状況も併記）。
  - 群非冗長性（最小性）：`ring1` 除去 20/20 漏れ、`mid1` 除去 20/20 漏れ、低貯留フィクスチャ（`reservoir = 0.02` vs `0.08`）での `port` 除去 20/20 漏れ。

- **P-S62-3（GB3：B-Test 3 読み書き・RNG 分離監査）**:
  - `core/one_life.jl`・`core/matter.jl` の 1 歩更新で未申告の共有書き込み・共有乱数参照が 0 件、`noise` は内部回路選択のみに局所化され、決定的ステップの補助診断 $\mathbb{E}[\xi_t] = 0$ が成立する。

- **P-S62-4（GB4：B-Test 4 3 分離介入対照・恒等ラッパ一致）**:
  - 介入なし恒等ラッパが正本 `onelife_step` と 20/20 種子×20 歩でバイト一致する。
  - **(4a)** P-04 運動発信停止（送信端遮断）で外向き差（プール・支払・身体物質）が **20/20** 検出される。
  - **(4b)** 軛対照（逆位相 Donor 行為列再生・同一初期乱数）で、非ゼロの随伴性差（$\Delta_{\mathrm{taken}} \neq 0 \lor \Delta_B \neq 0$）が過半数（$\ge 11/20$）の種子で観測される（あわせて勝ち／分け／負けと乱数消費一致歩数をそのまま報告。もし Live の勝ちが負け以下なら「40 歩育成の LawL2 には適応優位は未検出」と正直に記録）。
  - **(4c)** 低プール区別対（`(5,0)` vs `(0,5)`）で歩 $t+1$ の `y` 不一致かつ $\mu_{t+2}$ 不一致が **20/20**、高プール飽和同一視対（`pool=[0.06,0.06]` で `(4,4)` vs `(5,5)`）で歩 $t+1$ の `y = [5.0, 5.0]` 一致かつ回路出力一致かつ生プール不一致が **20/20** 成立する。

- **P-S62-5（GB5：決定性・凍結整合・`core/` 非変更）**:

## 反証条件
1. GB1 の 6 ケースで 1 件でも理論予測と食い違う。
2. GB2 で `|far1| == 0`（24×24）、`|far2| == 0`（40×40）、`far1`/`far2`/外向きのいずれかで漏れ $\ge 1/20$、または `b_naive`/最小性 3 群のいずれかで漏れ $< 20/20$。
3. GB3 で未申告の共有書き込みまたは RNG 漏れが見つかる。
4. GB4 で恒等ラッパ不一致、(4a) 外向き差 $< 20/20$、(4b) 非ゼロ随伴性差が過半未満、(4c) 区別対または飽和同一視対が $< 20/20$。
5. 決定性不一致、凍結 SHA-256 不一致、`core/` 変更、`phenomenal_claim` 逸脱。
