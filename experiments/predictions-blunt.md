# S31 予測（凍結、`discussion/specs/S31-body-blunt.md` r2）

対象: 種子 381〜400、腕 :std・:swap、生存の予定表 4、H 392、t∈32:32:392、窓 15。SF（主）と SFD（別枠の補助、SEDFADE_DRIVE を育ちと試しで on）。

定義（判定に使うもの）:
- 型・m*・対象の条件・条件 V・移りは S12 Q-C と同じ（仕様 §0）。移らずは latV＝∞。
- V か N が窓の中で死んだ点は除外（窓の中の生存に条件づけた記述の比較）。除外数は型別・版別に記録。
- n＝型ごとの対象の点の数。s＝窓の中で移った率。med＝∞ を最大として昇順に並べた latV の ⌈n/2⌉ 番目（下側の中央値）。
- 未判定＝n_q＜5 か n_sg＜5、または両型とも s＝0、または med_q・med_sg が両方 ∞。未判定は的中にも外れにも数えない。

予測:
- BP1（SF）: 未判定でなければ med_sg ≤ med_q。外れ＝med_sg ＞ med_q。
- BP2（SFD）: 未判定でなければ med_sg ≤ med_q。外れ＝med_sg ＞ med_q。
- BP3: n_sg（SFD）＞ n_sg（SF）。外れ＝n_sg（SFD）≤ n_sg（SF）。
- BP4: SF の n_sg ＜ 5。外れ＝n_sg ≥ 5。

根拠（推論）: 失敗の弱めは q＞0 なら q を、q＝0 なら sg を 1 ずつ減らし、上限はどちらも 4。sg 型が遅れて応じる仕組みは規則の上に見当たらない（機序の証明ではない）。BP3 は S25 で SFD が沈殿だけの型を保ったこと、BP4 は S12 の SF で sg 型が 960 点中 12 だったことから。
関門: C0 再生の照合（種子 381・両腕・4 予定表で、N が窓の中で生きて yN が揃う全点について、両方を軛した版が N と、行為した運動の列・窓の終わりの回路の全欄・乱数の状態で一致。負の対照: 感覚だけを軛した V が少なくとも一点で N と違う）、C1 再現（種子 381 :std・最初の予定表の点の列が二回で同じ）、C2 SFD の過程で切替を off に戻して作り直した同じ走りが SF の C1 と同じ。どれかが偽なら判定を出さない。
