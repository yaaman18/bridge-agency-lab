# S32 予測（凍結、`discussion/specs/S32-body-activity.md` r2）

対象: SF 版、種子 401〜410、腕 :std・:swap、生存の予定表 4、H 392、試しは無介入（sil なし）。予測は試しの全歩（生きている更新）について。育ちは記述だけ。

- QP1: 試しの全歩で核 c1・c2 が点いている（違反 0）。
- QP2: 試しで S(m) が真の歩はすべて m が候補（違反 0。A2 の実装の照合）。
- QP3: 試しで候補が空でない歩はすべて、行為する区画運動がちょうど一つで、それは記録から計算した順位（key・前の歩の点灯・小さい patch、idle の優先の集合があればその中）の最大（違反 0。試しは sil なしなので A3 の前提を満たす。違反が出たら sil の有無を分けて報告する）。
- QP4: 試しで候補が空の歩（P1 の偽）は 0。
- QP5: 試しで候補が空の歩があれば、その歩で行為する区画運動はない（違反 0。行為の列＝[]、候補外の行為の反証）。

根拠（推論）: 核の輪と核→運動の辺の q は生きている間に減らない（弱めは受容器の辺だけ、sed_fade は sg だけ）。凍結なしの事後の診断（R-rest.md F4、主張に使わない）で行為なしの歩が 0 だったこと。QP4 は全到達状態の主張ではない。一歩の反例で外れる。
関門: G0・G1・G2（仕様 §3）。どれかが偽なら判定を出さない。
- 来歴: QP5 は使用済みの種子 1 の煙試験を見た後、凍結の前に codex の I-R（往復2-2）で足した。煙試験は予測の検証に数えない。
