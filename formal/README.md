## 対応づけ（案）

一つの「出来事」は回路の一歩とする。その証拠は、その歩で終わる長さ `L` の窓の記録とする。
`L = smax × decay = 32` で、確かさが確かめられずに生き残れる最長の歩数にあたる。回路自身の定数で、外から選んだ数ではない。

| DC の成分 | 回路での読み（`Window`） |
|---|---|
| 行為 `M` | 運動（m1, m2, m3） |
| 環境 `E` | 受容器の特徴（r1〜r11） |
| 構成素 `C` | 結びつき（辺） |
| 状態 `S` | `Unit`（その出来事） |
| `κ` 自己 | その歩で確かさ ≥1 の、受容器から出ていない結びつき（核どうし、核→運動）。D3 |
| `ρ` | 確かな結びつきが駆動する運動。直接か、確かな結びつきを一段経由する |
| `π` | 窓の中で、運動 `m` が行為して答えられた歩に確かめられた結びつき。呼びかけ m3 は、W 歩以内の答えで確かめられたもの |
| `σ` | 受容器 `e` が、確かな結びつきで運動 `m` を駆動する |
| `α` | 運動 `m` の行為が、受容器 `e` の読む特徴を変える（世界の構造。回路には知らされない）。D4 |
| `ε` | 結合している（どれかの行為が届く）受容器のうち、点いているもの。D4 |
| 境界 | 運動に入る結びつき |

statement は二層に分けて書いた。`ElemDC` は、有限の単位と辺についての量化だけで書いた初等形で、Julia はこの形を計算する。
もう一層は DC の4つの欄（hSelf・hSMC・hAct・hBound）そのものである。

- **hSelf：** 確かな自己の結びつきはどれも、確かな自己の結びつきが駆動する運動の答えられた行為で、窓の中で確かめ直されている。
  （推論）確かさは確かめ直されなければ8歩ごとに1減るので、確かさ ≥1 の結びつきは窓の中で確かめられているはずである。
  したがって hSelf の中身は「確かめた行為が、自己の確かな結びつきに駆動されていたか」になる。
  定位反応や「試していない」ことによる試しで行為した歩の確かめは、この意味では自己産出に数えない。
- **hSMC：** 点いている結合した特徴はどれも、点いている結合した受容器が確かに駆動する運動の行為が届く範囲にある。
- **hAct：** 自己に駆動され、かつ点いている結合した受容器にも駆動される運動がある。
- **hBound：** 運動に入る自己の結びつきが確かである。

## bridge-protocol を動かして分かった「採ってはいけない機構」（2026-10-31、項番64の監査から。項番65）

出典は3種類あり、区別して書く。**[走]** は監査で走らせて得た結果（事実）、**[規]** は bridge-protocol の規律や Lean の定理、**[推]** は私の推論。

| | 採ってはいけないもの | 出典 |
|---|---|---|
| X1 | **沈殿を構成素の存在（強さ）に数えること。** 沈殿は失敗でしか減らない。そのため、すべての活動を止めても残り、「活動がなければ構造は保たれない」（precariousness、M1）が成り立たなくなる。外から与えた構造（AgencySubstrate の static-agent、L3 偽）と同じ形になる | [走] A の qsg で、すべて止めても構造が残った。[規] M1 |
| X2 | **AgencySubstrate の資源の規則（活動する単位ごとに 1 の費用）を、組織の層の死の基準として当てること。** 単位が 17 個あり、費用が収量を上回るので、どの予定表でも必ず死ぬ。測っているのは基体の大きさで、主体性ではない | [走] A の agency001 で、4つの予定表すべてで死んだ |
| X3 | **死のない系で主体性（L2）を判定すること。** 生存表の両列（切除なし／あり）が常に真になり、ValueNeeded は判定する前から偽に決まっている。アプリの存在には今、死がない | [走] A の none で、生存がすべて真。[規] ValueNeeded の定義 |
| X4 | **求めの図式 D を単純な到達可能性で読むこと。** 死がどこからでも到達できる終対象になり、不安定な系では M4b が必ず破れる | [規] `reachability_terminal_of_absorbing`（証明済み） |
| X5 | **消化の量の比較で学習を駆動すること。** 維持でなく最大化に向かい、M1 と緊張する。learn2/learn3 で起き、bin3 で外した | [規] M1、項番57 (1) |
| X6 | **観察（ページの表示、監査、LLM の語り）が存在の状態に書き戻すこと** | [走] N で書き戻しがないことを確認済み（今は守れている）。[規] SigmaPure、M4a |
| X7 | **「構成体が残る」（生存の代用）を DC の代わりに使うこと** | [規] 「viable と DC の同値は未証明、代用禁止」 |

監査では決まらなかったもの: α（どの行為がどの特徴に届くか）の決め方、時間（共通の刻み）の扱い。
もう一つの観察: 回路の運動は閾値 2 で、受容器の入力が要る。外界の入力を止めると行為できず、確かさが散逸する（[走] A の q で L3 偽）。
これは「採ってはいけない機構」ではない。ただし、組織の層の回路だけでは、L3（自分の活動だけで構造を保つ）は成り立たない作りだということを示す。

## 組み直した D1〜D6（2026-10-31、項番65。項番66 で推奨どおりに決定。ただし D6 の地平は未決）

X1〜X7 に反する選択肢は外した。各項で「外したもの」と「残したもの（推奨を先頭）」を示す。

**D1 個体（どの《系 S, 分解 D》で、どの述語を判定するか）**
- 外したもの:
  - アプリの存在（組織の層だけ）で L2 と L3 を判定すること（X3。L3 は上の観察から）
  - 回路に資源の規則を足して死を作ること（X2）
- 残したもの（推奨）: 述語ごとに判定する系を分ける。
  - DC と M4 → 組織の層の回路（今の `formal/LabCircuit.lean` の組①）。アプリの存在も含む。
  - L2 主体性 → 回路と物質の身体を合わせた系（body_org）。死は物質の死で、公理 A-gen により戻れない（段32 の X3）。
  - L3・L3R 自己産出・自己修復 → 物質の身体の構成体。構成体は物質を自ら結合し続けないと消える。
  - 個体か群体かの判定 → 組② S＝body_org、D＝構成体ごと。上の判定がそろってから。
  - アプリの存在の扱い: 報告では、L2・L3 を「対象外（死も身体もない）」と表示する。
- 残したもう一つの案: アプリの存在に物質の身体を与え、アプリでも L2・L3 を判定できるようにする。アプリの規則を変える大きな変更で、別に判断が要る。

**D2 時間**
- 外したもの: 監査や判定の側が、外から窓の長さを決めること（[規] TemporalDC）。L = smax×decay = 32 は回路自身の定数なので外さない。
- 残したもの:
  - 推奨: 今は共通の刻みを「出来事の時計」とみなし、`TemporalDC.GeneratedTrace` で認証する。共通の刻みであることは仮定として名前をつけて明示し、TemporalDC に完全に沿うとは主張しない。
  - 回路が自分で刻みを生む作り（出来事駆動）に直す。規則の変更になる。

**D3 κ（自己の構成素）**
- 外したもの:
  - 沈殿だけで働く結びつきを κ に入れること（X1）
  - 強さを確かさ＋沈殿で測ること（X1）
- 残したもの:
  - 推奨: κ＝確かさ ≥1 の、受容器から出ない結びつき（今の statement のまま）。沈殿は「自己の外に置かれた記憶」として扱い、κ にも L3 の強さにも数えない。
  - 受容器→運動の結びつきも κ に含める（hSelf が厳しくなる）。
  - 沈殿を、使われなければ減るように変える。規則の変更で、予測を凍結してからの実験が要る。そうすれば沈殿も precarious になり、κ に数えられる。

**D4 α と ε**（項番67 で改訂）
- 決定（2026-10-31）: α は世界の規則から宣言する（組織の層の世界はこのラボが作ったもので、規則が分かっている）。介入による測定は照合に使う。
  - 宣言する α：m1→r1・r3・r7・r8、m2→r2・r4・r7・r8、m3→r9（相手が生で答えるときだけ）。
  - ε からは雑音 r5・時計 r6 を外す（どの行為も届かない）。
- 改訂（ユーザー 2026-10-31、項番67）: r10「待っている」と r11「待っていない」は**内部**とし、ε に入れない。
  - 2つが読むのは回路自身の答え待ちの呼びかけで、単位体自身の構成素の状態（内部の相関）であり、媒質ではない。
  - オートポイエーシスとの対応（媒質、構造的カップリング、内部の相関）は項番67 に書いた。
- 改訂（ユーザー 2026-11-01、項番69）: α を状態に依存させた。m1・m2 は世界の相でその区画の収量が正のときだけ届く（Lean `gatedAffects`・`labGate`、
  `no_dc_before_world_without_partner`）。DC は保存 v518 で 0.1% → 68.1%、新生の学校期の DC（固定の α の産物）は 0 に。
- 改訂前の記録（項番67 の結果から。推論）: α を状態に依存させる案（介入による測定）。
  - 空の区画への行為は収量を変えないので、そのとき m1 は r3（y1==0）に届かない、という読みにする。
  - 今の固定の α では、区画が空のあいだ「空」の受容器が ε に入り続ける。その区画の運動は回路が駆動しないので、hSMC が成り立たない。

**D5 M4b の求めの図式 D**
- 外したもの: 単純な到達可能性（X4）。
- 残したもの:
  - 推奨: D の対象を「DC の証明書がある出来事」（生きている状態）に限る。「到達する」は回路自身の更新による到達とする。set point は「生きたまま行為が止まり、そこから動かない状態」とする。M4b は、そういう状態がどこからでも到達できるようには存在しないこと。死は DC がないので D の対象に入らず、終対象にならない。`TemporalDC` の終止と、一時停止の区別とも合う。
    - （推論）今の回路は毎歩行為する（監査の走りでも、項番60 の 5000 歩でも）。このため、この読みでは M4b は満たされる見込み。ただし証明が要る。
  - 求めの図式を別の形で与える（案はまだない）。

**D6 主体性の試行**
- 外したもの:
  - X2 の資源の規則で死を作ること
  - 強さに沈殿を数えること（X1）
  - 死のない系で L2 を判定すること（X3）
- 残したもの（推奨）:
  - 系: D1 の推奨どおり、L2 は body_org、L3・L3R は物質の身体。
  - 生存: 地平で構成体が残ること（AGENCY-001 の「生存は代用」に沿う。DC とは呼ばない、X7）。
  - 切除: 価値を追う受容器を `sil` で黙らせる（AgencySubstrate と同じく、測って特定する）。
  - 強さ: 確かさ（q）。
  - 予定表: AgencySubstrate の凍結した予定表（区画の収量）を、body_org の溜まりの成長率として与える。
- 注意:
  - 凍結した選択の窓（5〜15 歩）は短い。学習する回路では、それまでの習慣が出る（[走] 両方の予定表で m1）。窓は凍結されていて変えられないので、結果はその条件つきで読む。
  - AgencySubstrate のアダプタを body_org に広げる作業が要る。
- 地平の決定（ユーザー 2026-11-01、項番70）: 凍結の 60 歩は残し、L2・L3 を「この地平では測れない」と表示する。ラボ変種
  `experiments/variant_horizon.jl` で地平 392（＝身体の飢え死に 196 の 2 倍）、感度 294・588。結果: 構成体の L3 真（地平に依らない）、
  L2 偽（価値で行為が分かれない）。L3R は protocol の自己修復が核の単位の結びつきで定義されるので、構成体には当てていない（q の読みでは偽）。
