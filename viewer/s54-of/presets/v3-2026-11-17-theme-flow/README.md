# S54 garden（試運転の見張りの絵と音、openFrameworks 0.12.1）

読むだけの見張り。Pi には触れず、ラボにも書かない。読むのは Mac の `experiments/s54-watch.tsv`（1 時間ごとの見張りの行）、
`experiments/trial-data/ref-669-L2{,SF}.sha`（毎歩の状態の基準の sha）、`experiments/trial-data/drives-669.txt`（毎歩の二つの区画の収量）だけ。

- 左＝試-1（L2、左チャンネル）、右＝試-2（L2+SF、右チャンネル）。
- 見張りの行の間の n は**推定**（最後に観測した n ＋ 経過秒/10）。色と旋律は、その n の**基準の**状態の sha から作る（試運転は確かめるたびに基準と一致してきた。一致しなくなったら赤く乱れ、不協和音になる）。
- 音（コードの中で合成。元の音のファイルはラボに置かない。解析は `tools/analyze.py`、数値は `tools/analysis.json`、表は `src/instrument_tables.h`）:
  - **ピアノ**（University of Iowa MIS、制限なしで利用可。pp/mf/ff × A2〜A5 の 12 音）＝10 秒に 8 音の旋律（音 k は sha の 4k〜4k+3 バイトで音高〈五音音階〉・オクターブ・強さ・休符）。倍音 16 本それぞれの初めの強さ・二段の減衰・非調和の係数 B・打鍵の雑音を、強さと音域の表から内挿。
  - **鐘**（2026-11-17 にバイオリンから替えた。ユーザーが選んだ YouTube の動画「Italian Church Bells Ringing | Stress Relief | Sounds of Earth」〈q0Zn66gvp1w、ナポリの教会の青銅の鐘〉の 5:00〜10:00 を解析。この録音の利用の許諾は自由なものと確かめられていない。音のファイルはラボに置かず、数値だけを `tools/bell_analysis.json` と `src/bell_tables.h` に残した。解析は `tools/analyze_bell.py`）＝一歩に一回打つ（sha の最後のバイトで prime の音高。前の音の響きは残ったまま次の鐘が鳴る）。区画の収量が高いほど強く打つ。基準と一致しないと響きがうなる（毎秒 2.5 回）。
    - 録音では何個もの鐘が絶え間なく重なって鳴る（5 分に 318 打）。打つたびに一番強い倍音（nominal、718 Hz）が最も増える鐘を一つ選び（96 打）、その倍音 20 本を使った。比は prime（369 Hz）に対して hum 0.50・tierce 1.17・nominal 1.94・2.91・4.01 など。それぞれの強さは打った直後に増えた分から測った。
    - 減衰は、打つ前の響きより 6 dB 以上持ち上がった倍音だけで測れた（0.25〜0.75 秒。打った瞬間の速い減衰）。測れない倍音には測れた分の中央値を入れた。長く残る響きは録音の中で鐘が止まないので**測れず**、仮の値にした（prime で 9 秒、高い倍音ほど (prime/f)^0.7 で短く、hum が一番長い）。残る分の割合は、打って増えなかった分（10^(−持ち上がり/20)）とした。打つ雑音（舌の当たり）は 4 kHz より上の増え方から −34 dB。
    - 倍音の揺れ（2026-11-17）: 本物の鐘は真円でないので一つの倍音が近い二本に分かれ、ゆっくり膨らんでは痩せる。各倍音を 0.25〜1.15 Hz 離れた二本（強さ 0.68 と 0.32、谷は約 9 dB）にした。離れ方は倍音ごとに黄金比で散らした**仮の値**（録音からは測っていない）。
  - 空間（2026-11-17）: 前の左右に返すやまびこを外し、Freeverb（Jezar、public domain。櫛形 8 本＋全域通過 4 本、帰還 0.92、減衰 0.3）の残響を全体の下に混ぜた（`v` で入り切り、`S54_REVERB=0`）。バイノーラル（`b`、`S54_BINAURAL=1`、ヘッドホン用、既定は切）では、二つの命を正面から左右 35 度に置く。反対の耳には球の頭の式（Woodworth）の時間差（約 0.3 ms）と、1.2 kHz より上を落とす頭の陰を付けた。測った頭の伝達関数（HRTF）ではない簡単な模型。
  - 釣り合い: 鐘だけ・ピアノだけの rms を測り（`S54_SOLO=bell|piano`、デモを実時間で 22 秒。鐘 0.0185、ピアノ 0.061）、`bellGain`＝2.0 を置いた（鐘はピアノの約半分）。打鍵の雑音の大きさの換算の係数（40）と、打つ雑音の係数（4）は耳で決めていない仮の値。`instrument_tables.h` のバイオリンの数値は使わなくなった（ピアノの元の音がないので表は作り直していない）。
- 輪: 基準の死の歩（試-1 20515、試-2 11343）までの進み。基準の死に達すると体がほどけて音が消える（unit が止まったのを見張りが観測するまでは「awaiting a check」）。
- Pi の具合: throttled → 揺らぎとパチパチ音、ext4・ファイル系の誤り → 赤いひびとノイズ、起動し直し → 光の輪、見張りの行が 75 分より古い・Pi が応えない → 灰色とこもった音。
- キー: f 全画面、h 文字、m 消音、+/- 音量、d デモ（時間を 600 倍で流す。試運転ではない）、r 読み直し、v 残響、b バイノーラル。

作る: `cd viewer/s54-of && make -j8 Release`。動かす: `open viewer/s54-of/bin/s54Garden.app`。
環境変数（試験用）: `S54_MUTE=1`、`S54_DEMO=1`、`S54_DEMO_WARP=<倍率>`、`S54_SHOT=<png>`（300 フレーム目を保存して終わる）、`S54_WAV=<wav>`（S54_SHOT と一緒に。約 25 秒の音を書き出して終わる。音はスピーカーからも出る）、`S54_SOLO=piano|bell`、`S54_REVERB=0`、`S54_BINAURAL=1`。

一式の保存と差し替え: `sh tools/preset.sh save <名前>`・`restore <名前>`（先にいまの一式を `_before-restore-<時刻>` に保存してから戻す）・`list`・`check <名前>`。保存先は `presets/`。2026-11-17 の一式（ピアノ＋鐘）は `presets/v1-2026-11-17-piano-bell/`（ビルド済みアプリ `bin/s54Garden.app` つき、そのまま開ける）。

## 見せ方の調整パネル（2026-11-17）
`g` でパネル、`1`〜`5` で見せ方（光 v1・升目・場・回路の網・トーラス）、`h` で HUD。体の絵は `data/body-669-*.{json,bin}`（Mac で基準を計算し直した値、6 歩ごと。Pi の観測ではない）から描く。
調整した形は パネルの「保存」で `bin/data/looks/<名前>.json`、「起動時の形にする」で `default.json`。文字は ofxImGui＋FreeType で Retina の密度に描く（`openFrameworks-Info.plist` の NSHighResolutionCapable を true に）。

## 暗い・明るいの画面と流れの見せ方（2026-11-17）
- 画面: パネルの一番上「画面」で 暗い／明るい／Mac に合わせる（システム設定の外観を 3 秒ごとに読む）。キー `l` で暗い↔明るい。形の保存（looks の json）に `theme` として入る。試験用に `S54_THEME=0|1|2`。
  - 明るいときは、絵はいつもどおり暗い地の光として描き、最後に `bin/data/shaders/paper.frag` で紙の上の墨に置き換える（光がない所は紙、光のある所はその色相の顔料、白い光は墨）。色相は変えないので、色のもとの値は暗いときと同じ。パネルと HUD の文字、回路の網の線は明るい用の配色にした。
- 見せ方 6「流れ（流体）」（キー `6`、ofxFlowTools）: 場と同じ体の絵（C・B・A）を流体に注ぎ、絵が変わったところ（光学流）で流体を押す。**渦・浮力・広がりは流体のシミュレーションの動きで、命の値ではない**。命から来るのは注ぐ絵と押す向きだけ。パネルの「流れ」で注ぐ量・押す強さ・速さ・渦・ねばり・浮力・消え方、「流体を空にする」。流体は 1 つの命につき 128×128（色は 256×256）。トーラスのつながりは流体の箱にはない（箱の壁で止まる）。
